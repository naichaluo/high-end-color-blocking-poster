# Landmark Geometric Poster / 几何地标艺术海报

把普通海报/产品描述/营销主视觉，重绘成 **一张高雅风格的几何地标艺术海报**。

**最终效果**：像**艺术博物馆里的精品印刷品**——源海报自身的视觉主体（产品 / 门店 / 建筑 / 场景）被当作"地标"来描绘，**主体占 70%、几何简化占 30%**；上方 40–50% 是宁静的天空与大面留白，顶部中央只放一行干净的标题；下方构建景观。**斯堪的纳维亚编辑插画 × 中世纪几何艺术 × 建筑插画 × 博物馆精品印刷。高雅、宁静、克制、有文化感。**

**🅰 核心原则一：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**🅰 核心原则二：「地标」＝源海报自身的视觉主体。docx 原文的「［城市名称］」是占位模板，本 skill 中**不填任何虚构内容**——顶部标题位只放**源海报自身的标题文案**（保持简洁字体 + 宽字距的排版形式），**绝不编造城市名、地名或英文副标题**。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `art-deco-travel-poster`（装饰艺术旅行）、`layered-papercut-poster`（分层剪纸）、`paper-collage-poster`（纸艺拼贴）、`flat-spot-poster`（留白平涂小景）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **★ 70/30 比例（风格灵魂）**：**主体 70% 可识别的现实世界形态 + 几何简化 30%**。**先画识别度，再做艺术简化**——观众一看到主体就能立刻认出"就是它"。**几何形态具有组织性，但从不占据主导。**
- **★ 上方 40–50% 留白（风格灵魂）**：上方 40–50% 的空间留给**宁静的天空和空白区域**，不要用密实花纹填满。
- **顶部中央**：**只放一行**标题——**简洁的大写字体 + 宽字距**，无复杂字体。**文字内容逐字取自源海报自身文案**（中文就用中文，不强行改英文，**不编造地名**）。
- **主体优先级**：**1–2 个**具有独特形状的主要主体（主角）＋ **3–5 个**围绕排列的支撑元素（屋顶、河流、桥梁、山丘、树木、街道布局等，必须是源海报场景中真实存在的）。
- **下方部分构建景观**，让主要主体吸引观众的目光。
- **配色**：**有限精致的 6–10 色**——先明亮的/清新的色调，再六到八种柔和的颜色；**不过饱和**，博物馆版画 / 水彩气质。
- **材质**：**细腻的手工制作表面**——纸张纤维、干刷笔触、水彩、彩色铅笔、丝网印刷。
- **风格**：斯堪的纳维亚编辑插画 × 中世纪几何艺术 × 建筑插画 × 博物馆精品印刷。
- **画布**：保留源海报**原始尺寸与宽高比**。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**，也不得把文字当作几何形状去简化。
- **功能性资产保护**：二维码/条码/logo 必须**完整、可识别、可扫描**，**不得被几何形态覆盖、简化、错位**。
  > ⚠️ 本风格的负面清单含"不得出现水印或标志"——那约束的是**画面风格**（不让模型自己画标志）；**源海报自身的 logo 与二维码是必须保留的商业资产**，两者不冲突。
- **负面清单**：不得过度夸张或渲染；不得出现过大的圆形元素；不得照片写实；不得卡通；不得 3D；不得霓虹色彩；不得金色元素；不得复古滤镜；不得水印或标志（模型自绘）。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度、地名。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义（含 70/30 与留白比例）、构图、文字与品牌处理、工作流、质量门、边界（含旅行地标三兄弟对照表）。
- `palettes.md`：6–10 色有限精致调色板、用色规则、五种手工材质、构图比例示意图、限制条件核对表。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `landmark-geometric-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，填三处：**主要主体形状描述**、**支撑元素**、**源海报文字逐条清单**。
3. 出图后按自检表核对：**70/30 比例**是否守住、**上方 40–50% 留白**是否够、标题是否**只有一行且内容来自源海报**、**有没有被编造出地名**、配色是否 **6–10 色且不过饱和**、材质是否**细腻手工**、**文字/价格/二维码/logo 是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图（标题位与其他文字区留干净浅色空区）→ 排版叠回原文字与二维码。

## 与旅行地标三兄弟的区别（易混淆，务必分清）

| 维度 | 本 skill（几何地标艺术） | `art-deco-travel-poster` | `layered-papercut-poster` |
|---|---|---|---|
| 造型 | 主体高度写实可辨（70%）+ 组织性几何（30%） | 流线型宏伟造型、完美弧线、阶梯退台、同心光束 | 六到八层单色剪纸堆叠 |
| 视角 | 稳定正面的建筑插画视角 | 低角度仰视、向上汇聚 | 平视堆叠，无透视 |
| 深度 | 靠几何结构、色彩层次与留白 | 靠硬朗戏剧性光影与对角线 | **只靠层间柔和投影与堆叠顺序** |
| 材质 | 纸张纤维/干刷/水彩/彩铅/丝网印（细腻手工） | 平整印刷油墨，干净现代 | 哑光艺术纸、切割边缘、纸张厚度 |
| 光影 | 柔和、宁静、博物馆感 | 硬朗戏剧性、明亮平面 vs 单一色调阴影 | 单侧柔和光 + 层间漫射影 |
