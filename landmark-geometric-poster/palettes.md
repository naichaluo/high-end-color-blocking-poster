# 几何地标艺术 · Palettes

**有限的、精致的色彩调色板，包含 6 到 10 种颜色。** 不会过于饱和，具有类似**博物馆版画或水彩画**的风格。

**结构**：**先指定明亮的或清新的色调，然后列出六到八种柔和的颜色。**

## 色盘

### 第一层：明亮的 / 清新的色调（1–2 种，定调）

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 清透天青 | `#9CC9DE` | 天空主调 | 上方 40–50% 天空区的底色，清新通透 |
| 明亮薄荷 | `#A8D5C4` | 清新点缀 | 植物的受光面或水面，带来清爽感 |

> 这一层只放 1–2 种，负责"明亮/清新"的第一印象——**不要**做成高饱和撞色。

### 第二层：六到八种柔和的颜色（主体层）

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 米白 / 纸白 | `#F5F1E8` | 留白与纸底 | 天空留白、文字承载区、建筑受光面 |
| 浅沙 | `#E4D5BC` | 暖中性 | 墙面、路面、土色结构 |
| 柔和赭石 | `#C9A27E` | 暖中性 | 木质、砖石、屋檐 |
| 灰蓝 | `#8FA8B8` | 冷中性 | 远景轮廓、阴影面、次要结构 |
| 深灰蓝 | `#5A6E80` | 结构线 | 轮廓、窗洞、檐口的分界 |
| 柔和鼠尾草绿 | `#93AA8C` | 绿 | 树木、植被、次要支撑元素 |
| 深橄榄绿 | `#5F7355` | 绿（暗部） | 树冠暗部、远处植被 |
| 柔和陶土 | `#D08C7A` | 暖强调 | 屋顶、招牌、主体的暖色块 |
| 淡雾紫 | `#A99BB5` | 冷强调 | 远景空气感、天空层次 |

> 色值为**参考范围**，不是死值。同一色族内明度/饱和度上下浮动 5–10% 都是正常的。
> **总色数控制在 6–10 种**（含留白纸色），不要超出。
> 若源海报有品牌色，**品牌色优先**：以**低饱和但可识别**的方式纳入这个有限色盘。

## 用色规则

- **不过饱和**：所有颜色都要**降纯度**，呈现博物馆版画 / 水彩的温润气质。避免高纯度、避免撞色冲突。
- **明亮感来自"清新"而不是"艳丽"**：天青、薄荷等清透色负责明亮，柔和色负责层次。
- **明确不要**：
  - **不得出现霓虹色彩**；
  - **不得出现金色元素**；
  - **不得有复古滤镜**（棕褐色、泛黄、做旧色调）；
  - **不得有老化的纸张或发黄的背景效果**。
- **品牌色**：以低饱和但可识别的方式保留。
- **文字承载区**：保持干净、低细节的米白/纸白或浅色区，保证叠加的精确文字有足够对比。

## 70/30 比例规格（配色层面的落实）

- **可识别的主体与建筑/结构元素占 70%**：使用色盘中的**柔和实色**，形状清晰、轮廓明确、保留现实世界形态。
- **几何抽象形态占 30%**：使用**更浅或更淡的同族色**，作为组织性结构（地平线、色带、轮廓分割、背景色块）。
- **几何形态具有组织性，但从不占据主导**——它的色彩重量必须低于主体。

## 材质规格（细腻的手工制作表面）

五种材质可以叠加使用，但都必须是**细腻的**，不要厚涂或粗糙：

| 材质 | 表现 |
|---|---|
| **纸张纤维** | 底纸上极细的纤维感，浅色区域能看出纸的纹理 |
| **干刷** | 色块边缘带**干刷笔触**——颜料在纸纹上断开，出现细微的飞白 |
| **水彩** | 色块内部有**透明的水彩层次**与轻微的水痕、边缘积色，不均匀但柔和 |
| **彩色铅笔** | 局部细节用**彩铅细线**刻画，有颗粒感与手绘痕迹 |
| **丝网印刷** | 大色面有**均匀细腻的丝网印质感**，色块边界干净，偶有极轻微的印刷密度不匀 |

**明确不要**：老化的纸张、复古的棕色滤镜、棕褐色或发黄的背景效果。

## 构图比例规格（本风格的灵魂）

```
┌─────────────────────────────┐
│                             │
│   宁静的天空 + 大面留白      │  ← 上方 40–50%
│                             │
│       〔源海报标题文案〕      │  ← 顶部中央，简洁大字 + 宽字距
│                             │
├─────────────────────────────┤
│                             │
│      主要主体（主角）         │  ← 下方构建景观
│   三到五个支撑元素围绕排列      │     主体吸引观众的目光
│                             │
└─────────────────────────────┘
```

- **上方 40–50%**：宁静的天空与大面留白。**不得**用密实花纹填满。
- **顶部中央**：只放**源海报自身的标题文案**（简洁字体 + 宽字距）。**不得**编造城市名、地名或装饰小字。
- **下方部分**：构建景观，让主要主体吸引目光。

## 限制条件核对（负面清单）

- [ ] 无过度夸张或渲染
- [ ] 无过于庞大的圆形元素
- [ ] 无照片般的写实效果
- [ ] 非卡通风格
- [ ] 非 3D 效果
- [ ] 无霓虹色彩
- [ ] 无金色元素
- [ ] 无复古滤镜（棕褐/泛黄/做旧）
- [ ] 无老化的纸张
- [ ] 未由模型自行绘制水印或标志
      （注意：**源海报自身的 logo 与二维码必须原样保留、完整可扫描**，不受此项约束）
