# 示例：移动「请你喝奶茶」促销海报 → 几何地标艺术风

## Brief

- 源海报：中国移动云南公司促销海报「移动请你喝奶茶」（1060×1440 竖版）
- 需求：重绘成**几何地标艺术**风，**保留全部文字与商业信息**，**保留原图尺寸比例**

> ⚠️ **本示例的关键改造**：docx 原文是「［城市名称］」旅行地标模板。
> 本 skill 把**「地标」对应为源海报自身的视觉主体**——这里就是**两只奶茶杯（主角）+ 老虎吉祥物**。
> 顶部中央的「城市名」位 → 对应为**源海报标题区**，排版形式（简洁字体 + 宽字距）保留，
> **文字用源海报自身的「移动请你喝奶茶」**，**没有编造任何城市名或地名**。

## 一、地标优先级（「地标」＝源海报自身视觉主体）

| 层级 | 内容 |
|---|---|
| **主要主体（主角）** | **两只并排的奶茶杯**——独特的形状：略收窄的圆台杯身轮廓、圆顶杯盖的弧形转折、斜插的粗吸管直线；杯身上的内容物分层（杯底果肉层 / 中段茶汤层 / 顶部奶盖层） |
| **次要元素（3–5 个）** | ① 哈密瓜（椭圆 + 网纹平面）② 葡萄串（成串的小圆群）③ 老虎吉祥物（圆头 + 三角耳 + 身体轮廓）④ 缎带横幅（两端燕尾的横带）⑤ 前景台面线与产品小卡区域 |

## 二、70/30 比例落实

**识别度优先（约 70%）**：

- 奶茶杯保留**圆台轮廓、杯盖弧度、吸管角度、内容物分层高度比例**——只简化不必要的摄影微细节，**不改变杯型与比例**
- 老虎吉祥物保留**头形、耳朵角度、身体姿态与朝向**，条纹用简洁的短笔触带表现
- 哈密瓜保留椭圆比例与网纹密度感；葡萄串保留**成串的挂垂轮廓与颗粒数感**
- 缎带横幅保留两端燕尾形状与水平走向

**几何简化（约 30%，具有组织性但从不主导）**：

- 天空与背景用**平整的横向色带**组织
- 地面/台面用一条**清晰的水平分界线**稳定构图
- 杯身结构用**简化的垂直分割面**概括明暗
- 背景留白处点缀 2–3 个**小型几何色块**（非庞大圆形元素）

```
│   （源海报标题，不改成英文，     │    （中文标题保持简洁排版形式）

│                               │
├───────────────────────────────┤
│                               │
│   〔产品小卡〕  〔徽章〕         │
│     两只奶茶杯（主角，居中）      │ ← 下方构建景观
│  哈密瓜 葡萄串 吉祥物 缎带       │
│  优惠条 / 扫码办理区 / 服务条     │
└───────────────────────────────┘
```

- **上方约 45%**：宁静的天空与留白（清透天青 → 米白），**不用密实花纹填满**
- **顶部中央**：只有一行标题「移动请你喝奶茶」，**简洁字体 + 宽字距**
- **下方**：构建景观，两只奶茶杯为主角居中偏上，支撑元素围绕排列，形成稳定的垂直构图
- 保留源海报的信息顺序与层级（品牌/标题 → 主体场景 → 卖点/优惠 → QR/行动区 → 服务/法务）

## 四、配色（有限精致的 6–10 色）

| 层 | 色 |
|---|---|
| 明亮的/清新的色调（先定） | **清透天青 `#9CC9DE`**（天空主调）、**明亮薄荷 `#A8D5C4`**（品牌绿的低饱和可识别版） |
| 六到八种柔和的颜色 | **米白 `#F5F1E8`**（留白/纸底）、**浅沙 `#E4D5BC`**（台面）、**柔和赭石 `#C9A27E`**（杯身暖面/哈密瓜）、**灰蓝 `#8FA8B8`**（远景与阴影面）、**深灰蓝 `#5A6E80`**（轮廓与窗洞式分界）、**柔和鼠尾草绿 `#93AA8C`**（叶片/次要元素）、**柔和陶土 `#D08C7A`**（吉祥物暖色/缎带） |

合计 9 色。**不过饱和**，博物馆版画/水彩气质；无霓虹、无金色、无复古滤镜、无做旧泛黄。

## 五、材质（细腻的手工制作表面）

- **纸张纤维**：米白留白区与天空区可见极细纸纤维
- **干刷笔触**：天空色带与地面分界的边缘带轻微干刷飞白
- **水彩**：杯身与吉祥物色块内有透明水彩层次与轻微水痕，不均匀但柔和
- **彩色铅笔**：杯盖弧线、吸管、哈密瓜网纹、葡萄颗粒用彩铅细线刻画
- **丝网印刷**：大面积色带（天空、台面）有均匀细腻的丝网印质感，边界干净

## 六、文字处理

- 首选**两层流程**：先出「纯视觉底图」（顶部标题位与其他文字区留成干净浅色空区），再把原海报的标题、优惠数字、二维码、服务信息**精确叠回**。
- **标题位只放「移动请你喝奶茶」**——中文标题就排中文，**不改成英文，不编造地名或副标题**。
- 若直接让模型渲染：提示词里**逐字引用**全部文案与数字（含 `15`、`15GB`、`20`、`10086`），出图后逐项核对。
- 正文字体保持**简洁 + 宽字距**的排版形式，**必须清晰可读**；**不得把文字当作几何形状去简化**。
- **源海报的 logo 与二维码必须原样贴回、完整可识别可扫描**；模型**不得自行绘制**任何水印或标志。
