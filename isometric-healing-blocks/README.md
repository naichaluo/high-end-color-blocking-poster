# 等距治愈积木

把普通海报重绘成 **等距治愈积木**。

独立 Skill，不与其他海报 skill 合并规则（除非明确要求）。

## 关键点

- **内容隔离**: 只用当前源海报；不混入其他项目品牌/文案/额度。
- **两层流程**: 视觉层(材质/道具/装饰)交给模型；受控层(精确标题/价格/品牌/二维码)用原素材叠加。
- **构图**: 保留源海报信息层级，留出平静区域给文字。

## 配套文件

- SKILL.md / palettes.md / prompt-templates.md / examples

## 快速上手四句话

1. skill 加载 $(System.Collections.Hashtable.n)。2. 以原海报为参考图(image)。3. 出图后核对文字。4. 零误差用两层流程。
