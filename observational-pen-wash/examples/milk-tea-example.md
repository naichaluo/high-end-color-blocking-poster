# 示例：奶茶卖点海报 → 钢笔淡彩写生风

## Brief

- 产品：某奶茶（低温鲜奶 + 当季水果）
- 卖点：新鲜、自然、轻负担、好心情
- 品牌色：奶油白 + 薄荷绿 + 蜜桃粉
- 类型：竖版促销海报
- 需求：把普通奶茶海报重绘成 钢笔淡彩写生风，保留原有文案与信息层级

## Locked (保留)

- 品牌名 / 文案 / 价格 / 优惠额度 / 图标 / 底部服务与法务信息
- 原有信息层级：顶部标题 → 中部奶茶场景 → 下方优惠模块 → 底部服务条

## Reinterpret (重释)

- 材质：钢笔淡彩写生 的材质与构成（详见 SKILL.md 的 visual specification）
- 场景：把奶茶主体做成 钢笔淡彩写生 视觉语言下的主件
- 构图：保留源信息层级，用该风格的视觉语言组织质量与留白

## Verdict

钢笔淡彩写生风只改变视觉语言——信息层级、文案、Logo、二维码、价格全部按源海报锁定，文字用精确叠加层处理，绝不让模型去重画商业文字。
