# Dopamine Abstract Vector Poster / 多巴胺抽象矢量海报

把普通海报/产品描述/营销主视觉，重绘成 **一幅精致、先锋艺术导向的多巴胺抽象矢量插画**。

**最终效果**：像当代先锋艺术家的矢量版画作品——以极简主义为核心基调，富有韵律感的抽象线条与曲面线条，色彩饱满的多巴胺色系，形态各异的不规则弧形色块，线条与色块相互映衬，层次分明，兼具自然的柔和质感、精致的装饰元素与超现实派的奇幻表达。**现代、精致、愉悦、高级、有收藏感。**

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `high-end-color-blocking-poster`（高级撞色）、`flat-spot-poster`（留白平涂小景）、`riso-print-redesign-poster`（RISO 丝网印刷）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：保留原图的主体、人物/动物/建筑/物体的**身份特征、动作姿态、空间关系、主要构图和视觉焦点**，**不改变原图所表达的场景内容**。抽象化只作用于**造型语言与背景装饰**，主体必须仍然一眼可辨。
- **媒介**：真正的**矢量插画**——边缘干净利落、**纯色平面填充**；**不要**笔刷毛边、纸张颗粒、颜料噪点、半色调网点。
- **线条**：**富有韵律感的抽象线条与曲面线条**——粗细变化明确、成组成束、有流动方向；曲面线条**平滑流畅、弧度舒展、收放有致**，避免机械等距套环。
- **色块**：**形态各异的不规则弧形色块**（肾形、泪滴形、云朵瓣形、半月形、有机不规则形），大小与方向各不相同，相互**叠压、穿插、留缝**，**层次分明**；不要标准正圆、正方、等宽条带。
- **相互映衬**：线条进入色块 / 勾勒色块边缘 / 沿外缘流淌——两者互相成就，不是各画各的。
- **配色**：**色彩饱满的多巴胺色系**（亮橘、柠檬黄、珊瑚粉、天青蓝、薄荷绿、葡萄紫、洋红、电光青）；明度高、纯度高、色相跨度大。**主色大面积 + 强调色小面积点亮**，绝不平均铺满。线条用深墨蓝/近黑炭撑结构。
- **质感与装饰**：既保留自然的柔和质感，又融入**精致克制的装饰元素**（细点阵、短线组、小几何符号），合计不超过画面 8%，不堆砌。
- **超现实奇幻表达**：比例与空间的轻度错置、悬浮元素、不合物理的色块流动——**克制、优雅**，不是怪诞。
- **构图**：**保留大量留白与干净浅色底**；保留源海报的信息顺序与层级；**留白靠布局，不靠删信息**。
- **画布**：保留源海报**原始尺寸与宽高比**。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**，也不得把文字做成抽象线条/弧形色块；文字承载区必须干净低细节、对比充足。
- **功能性资产保护**：二维码/条码/logo 必须**完整、可识别、可扫描**，**不得被线条穿过、被色块覆盖、被旋转或裁切**。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：多巴胺色盘（主色族/辅色/强调色 + 参考色值）、配色三层结构、线条规格、弧形色块形态库、质感与装饰规则。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `dopamine-abstract-vector-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：是否真是**干净矢量**（无颗粒/网点）、线条是否有**韵律与粗细变化**、色块是否**形态各异的不规则弧形**、色彩是否**够饱和且层级分明**、留白是否够、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图（文字区留干净浅色空区）→ 排版叠回原文字与二维码。
