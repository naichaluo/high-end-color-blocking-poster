# 多巴胺抽象矢量 · Palettes

**高饱和、高明度、愉悦明亮的多巴胺色系**。多巴胺感来自**饱和度与明度的饱满 + 色相跨度大**，不是荧光刺眼，也不是灰调莫兰迪。

## 色盘

### 主色族（大面积场域，选 1–2 个）

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 亮橘 | `#FF7A33` | 主色 | 多巴胺最具代表性的暖色，能量场 |
| 柠檬黄 | `#FFD93D` | 主色 | 明亮欢快，常做大色块或背景场域 |
| 珊瑚粉 | `#FF6F91` | 主色 | 甜而不腻，与青绿形成互补张力 |
| 天青蓝 | `#4EC5F1` | 主色 | 清爽通透，平衡暖色 |
| 薄荷绿 | `#3ED9A4` | 主色 | 清新有生命感 |
| 葡萄紫 | `#8E6BFF` | 主色 | 增加色相跨度与先锋感 |

### 辅色与强调色（小面积点亮，选 2–4 个）

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 洋红 / 火龙果红 | `#F2457E` | 强调 | 最强视觉心跳，用于焦点 |
| 电光青 | `#18C8D8` | 强调 | 冷调跳跃，与暖色撞出张力 |
| 青柠黄绿 | `#C3E82B` | 强调 | 酸性亮色，先锋感 |
| 深墨蓝 | `#16304F` | 线条/文字 | **线条主力色**，撑住明亮色场，保证结构可读 |
| 近黑炭 | `#14161A` | 线条/文字 | 极细线与文字，最稳的对比 |
| 纯白 / 暖白 | `#FFFFFF` / `#FDFBF7` | 底与留白 | 极简主义的呼吸区 |

> 色值为**参考范围**，不是死值。同一色族内明度/饱和度上下浮动 5–10% 都是正常的。
> 若源海报有品牌色，**品牌色优先**：以高饱和、可识别的方式保留，作为主色或强调色之一。

## 配色结构（三层，必须分明）

1. **场域层（55–70%）**：1–2 个高明度主色 + 白色/浅色留白，构成大面积的干净底。
2. **形体层（20–35%）**：2–3 个辅色构成不规则弧形色块，颜色之间要有**明确对比或互补关系**。
3. **心跳层（5–12%）**：1–2 个最强强调色，小面积、成群或成点，负责第一眼焦点。

**不要平均铺满**：每个颜色面积差异要明显，色块大小与色彩权重都要拉开层级。

## 线条规格

- **线条色**：优先深墨蓝 `#16304F` 或近黑炭 `#14161A`；也可用**深色主色的同色系加深版**（如深橘棕、深青），比纯黑更高级。
- **线宽**：主线约为主体高度的 1/80–1/120；细线为主线的一半以下；极端细发丝线用于装饰。
- **线条节奏**：同一区域内线宽稳定，不同区域之间要有**明显粗细对比**；成组线条要做**疏密变化**（密→疏→密），不做等距平行阵列。
- **曲面线条**：弧度舒展、连续、有收放，避免等宽同心套环与机械重复。

## 弧形色块形态库

从下面形态中选取若干种，**每个色块形状都不同**：

- 肾形 / 豆形（kidney）
- 泪滴形 / 水滴形（teardrop）
- 云朵瓣形（cloud lobe，连续多弧叠合）
- 半月形 / 弦月形（half-moon arc）
- 花瓣形 / 叶片形
- 液体流淌形 / 波浪带形
- 柔软的有机不规则形（soft organic blob）

**明确不要**：标准正圆、正方、等宽条带、等边三角形、机械等距网格。

## 质感与材质

- **纯矢量平面**：干净利落的边缘 + 纯色平面填充。
- **不要**笔刷毛边、纸张颗粒、颜料噪点、半色调网点、套准纸缝（那是 RISO / 版画 / 纸艺 skill 的语言）。
- 柔和的自然质感靠**弧线本身与色彩过渡关系**表达，不靠纹理滤镜。
- 允许**极少量的柔和透明叠加**（同色系深浅两块叠压产生第三色感），但不要渐变网格与光晕。

## 装饰元素（精致、克制）

可用：细点阵、短线组、小几何符号（圆点、细十字、小三角）、微小的放射短线、细波纹线、小星形。

规则：
- 装饰面积**合计不超过画面的 8%**；
- 与线条同系统（同线宽量级、同色系）；
- 分散在留白与主体外围，**不进入文字承载区**，不压主体识别特征。

## 用色规则

- **饱和度优先**：宁可鲜亮，不要灰。多巴胺风最常见的失败是"太淡、太灰、没劲"。
- **明度控制**：所有主色明度保持在较高的区间（浅色场域），避免整幅偏暗。
- **对比保证**：文字承载区的底色必须干净、低细节，且与之上的文字有足够对比度。
- **品牌色**：以高饱和、可识别的方式保留。
- **超现实表达用色**：可以用"不符合物理的颜色流动"（如暖色渐变进入冷色场域且没有过渡）制造奇幻感，但保持矢量平面的干净边缘。
- **文字承载区**：保持干净、低细节的浅色或纯色区域，保证叠加的精确文字有足够对比。
