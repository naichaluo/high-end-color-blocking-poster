# 示例：移动「请你喝奶茶」促销海报 → 多巴胺抽象矢量风

## Reinterpret（视觉重释）

- **媒介**：纯矢量插画，边缘干净利落、纯色平面填充；**无颗粒、无网点、无笔刷毛边**
- **线条语言**：以深墨蓝 `#16304F` 为主线色，主线略粗 + 发丝细线成束；曲面线条自画面左下向右上舒展贯穿，形成明确的韵律与流动方向；杯身轮廓用弧线勾勒，吸管与缎带处用成组短线
- **弧形色块**：奶茶杯主体用**珊瑚粉 + 暖黄**的肾形与云朵瓣形色块叠压；哈密瓜用**薄荷绿 + 青柠黄绿**的半月形弧块；葡萄串用**葡萄紫**的泪滴形小色块群；老虎吉祥物用**亮橘 + 近黑炭**的有机不规则形
- **相互映衬**：细线进入色块内部切分体积、线条沿色块外缘流淌，缎带处线条被色块切分
- **配色**：主色场域用**暖白 `#FDFBF7` + 天青蓝 `#4EC5F1`** 大面积铺底；强调色用**洋红 `#F2457E` + 青柠黄绿 `#C3E82B`** 小面积点出焦点（品牌绿以高饱和薄荷绿保留可识别）
- **装饰**：留白区散落细点阵与短放射线组（合计约 6%），集中在主体外围，避开文字区
- **超现实奇幻**：两颗杯身之间嵌入一处不合物理的色块流动（暖色直接切入冷色场域、无过渡），上方悬浮一枚小弧形色块，制造梦境感
- **构图**：保留大量留白（约占 30%）；主体偏中上部，抽象线条与色块围绕展开但不覆盖杯身识别特征与 logo 完整性

## 文字处理

- 首选**两层流程**：先出「纯视觉底图」（文字区留成干净浅色空区），再把原海报的标题、优惠数字、二维码、服务信息**精确叠回**。
- 若直接让模型渲染：提示词里**逐字引用**全部文案与数字（含 `15`、`15GB`、`20`、`10086`），出图后逐项核对。
- 文字用**几何无衬线、克制的字重、干净宽字距**排版，**必须清晰可读**；**不得把文字做成抽象线条或弧形色块**；**不新增标题**。
