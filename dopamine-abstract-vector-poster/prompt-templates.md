## 现有海报 → 多巴胺抽象矢量风（主模板）

```text
把提供的源海报重绘成「精致先锋艺术导向的多巴胺抽象矢量插画」风海报，Image 1 是唯一内容与视觉参考。

【画布】保留源海报的原始尺寸与宽高比（不要改成正方形，不要裁切版式）。

【严格保留原图内容】保留原始图片的主体、人物/动物/建筑/物体的身份特征、动作姿态、空间关系、
主要构图和视觉焦点，不改变原图所表达的场景内容。抽象化只作用于造型语言与背景装饰，
绝对不能把主体抽象到无法辨认。

【商业内容必须完整保留】务必保留源海报的全部商业内容与文案：品牌 logo 与字样、主标题、
全部副标题与卖点、价格与券额数字、日期、电话、URL、二维码及其位置、底部服务与法务信息、
以及所有产品/规格标签文字。逐字列出：[把源海报上的文字逐条填在这里]。
所有文字必须清晰准确、可读，数字一个都不能改。不得把文字或 logo 化为不可读色块，
不得把文字做成抽象线条或弧形色块的形状。
不要新增、编造或改写任何文案。不要添加任何装饰性英文标题、标语、花体字或作者署名。
【功能性资产保护】二维码/条码/logo 必须保持完整、可识别、可扫描：二维码保持完整清晰可扫描，
不要被线条穿过、不要被色块覆盖、不要旋转或裁切、不要改变配色、不要做成抽象图形。

【视觉语言】精致先锋艺术导向的矢量插画（vector illustration），以极简主义（minimalism）为核心基调。

线条：运用富有韵律感的抽象线条与曲面线条。线条要有明确的粗细变化与节奏——细线如发丝、
主线略粗，成组、成束、平行或同心展开，形成明显流畅的视觉流动方向与韵律感。
曲面线条要平滑流畅、弧度舒展、收放有致，避免机械等距套环与呆板重复。

色块：形态各异的不规则弧形色块——弧边、肾形、泪滴形、云朵形、半月形、水滴形与柔软的有机不规则形。
色块大小、比例、方向各不相同，相互叠压、穿插、留缝，形成层次分明的视觉效果。
不要标准正圆、正方、等宽条带等僵硬几何。
线条与色块必须相互映衬：留白处的线条进入色块、色块边缘被线条勾勒或切分、线条沿色块外缘流淌。

【色彩】色彩饱满的多巴胺色系：明度高、纯度高、愉悦明亮，色相跨度大且有对比。
可用色：[从 亮橘 #FF7A33 / 柠檬黄 #FFD93D / 珊瑚粉 #FF6F91 / 天青蓝 #4EC5F1 /
薄荷绿 #3ED9A4 / 葡萄紫 #8E6BFF / 洋红 #F2457E / 电光青 #18C8D8 / 青柠黄绿 #C3E82B /
深墨蓝 #16304F / 暖白 #FDFBF7 中选定本张海报的用色，填入这里]。
层次必须分明：主色占大面积（55–70%），辅色与强调色小面积点亮（5–12%），不要平均铺满。
线条用深墨蓝或近黑炭，保证结构清晰可读。品牌色以高饱和、可识别的方式保留。

【质感】纯矢量语言：边缘干净利落、色块为纯色平面填充。
既保留弧线自然的柔和质感，又融入精致的装饰元素（细点阵、短线组、小几何符号、微小放射与波纹），
装饰要克制、精致、有设计感，合计不超过画面 8%，不做无意义堆砌。

【超现实奇幻表达】加入克制的超现实派奇幻感：比例与空间的轻度错置、悬浮的元素、
不符合物理的色块流动、梦境般的空间逻辑。必须是克制、优雅的超现实，不是怪诞或恐怖。

【构图】保留大量留白与干净的浅色底，极简主义基调要求画面有呼吸区。
抽象线条与弧形色块围绕主体展开，可以叠压主体边缘与背景，但不得覆盖主体的识别特征
（五官、姿态、产品轮廓、logo 完整性）。
保留源海报的信息顺序与层级关系（品牌/标题 → 主体场景 → 卖点/优惠 → QR/行动区 → 服务/法务），
但可按矢量海报的现代版式重新排布；不得为了极简美学删减或弱化必需信息。
避免填满画面、避免色块平均铺满、避免装饰堆砌、避免机械居中和模板化版式。

【最终效果】像当代先锋艺术家的矢量版画作品：现代、精致、愉悦、有设计感与收藏感的先锋艺术气质。

【约束】不要混入其他项目或其他参考图的内容；不要改变价格、券额、套餐值、电话号码、二维码、品牌名与活动口径。
避免：照片写实、3D 渲染、立体感与投影、渐变网格、霓虹光晕、模糊、平面化的图标套装、
水彩、蜡笔、纸张颗粒、颜料噪点、半色调网点、RISO 套准纸缝、卡通幼稚感、画面杂乱、
标准正圆与方正色块、把文字变成色块、改成正方形。
```

## 出图前自检

| 检查 | 期望 |
|---|---|
| 画布尺寸 | **保留源海报原始尺寸与比例** |
| 内容保真 | 主体、身份特征、姿态、空间关系、主要构图、视觉焦点**严格保留**；场景内容未改变 |
| 主体可辨 | 抽象化后主体在缩略图下仍**一眼可辨**，识别特征未被覆盖 |
| 媒介 | 真正**矢量**：边缘干净利落、纯色平面填充 |
| 线条韵律 | 线条有明确**粗细变化与节奏**，成组展开，有流动方向 |

| 相互映衬 | 线条进入色块 / 勾勒色块边缘 / 沿外缘流淌，**非各画各的** |
