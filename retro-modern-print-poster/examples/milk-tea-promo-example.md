# 示例：移动「请你喝奶茶」促销海报 → 复古现代艺术版画风

## Brief

- 源海报：中国移动云南公司促销海报「移动请你喝奶茶」（1060×1440 竖版）
- 需求：重绘成**复古现代艺术版画**风，**保留全部文字与商业信息**，**保留原图尺寸比例**，**不新增任何原图没有的物体**

## Reinterpret（视觉重释）

- **造型语言**：把照片复杂性转化为**精心设计的绘画形状**。奶茶杯简化为圆柱体平色块 + 清晰轮廓；杯盖与吸管简化为几何形状；哈密瓜简化为几何化的网纹平面；葡萄串简化为密集的小圆形图形块（保留成串的轮廓与比例）；老虎吉祥物保留标志性的头形与姿态轮廓，条纹用**重复的小笔触**表现；缎带横幅简化为干净的二段式图形带
- **前中后景图形分离**：背景大色场 → 中景桌面与道具的图形块 → 前景两只杯身与吉祥物
- **调色板转换**（保持原有色彩关系与视觉层次）：
  - 大面积背景与冷调区 → **钴蓝 `#1B4FA8` + 青 `#1FA3C3`**
  - 桌面与中景 → **绿松石 `#20B2A6` + 奶油 `#F2E4CE`**
  - 杯身与吉祥物暖面 → **珊瑚粉 `#F4736B` + 鲑鱼粉 `#F5A38C` + 暖黄 `#F2B33D`**（品牌绿转为可识别的**翠绿 `#1E8A5F`**）
  - 葡萄 → **群青 `#2B3A8F`**
  - **所有阴影统一深蓝黑 `#101A2E`**，包括杯底、桌面投影、吉祥物暗部
  - **偶发洋红 `#D6336C`**：仅用在优惠条的一处小面积心跳点
  - **纯白点缀**：仅用于杯盖高光与"扫码办理"区周边的最亮点
- **光影图形化**：保留原图光照方向（左上受光），把摄影柔光简化为**大面积图形化色调区域**；用可控的阴影轮廓 + 克制高光 + 极少中间色调表现，不做过渡渐变
- **深度**：靠透视、重叠轮廓、相对比例、桌面水平面与背景垂直面、色彩对比、有序图层——不使用摄影景深虚化

## ★ 颗粒质感（本风格关键）

- **每个色块都含可见但精细的模拟表面纹理**：细腻丝网印颗粒 + 石版画颜料纹理 + 胶印噪点 + 克制的不规则半色调
- **大面积纯色区**（钴蓝背景、青底色、奶油桌面、杯身珊瑚粉）**绝不光滑、不数字平坦、不像矢量**
- **颗粒融入色彩之中**：深蓝黑阴影保留细腻颗粒变化；钴蓝与绿松石表面呈精致斑驳纹理；珊瑚粉/鲑鱼粉/奶油/暖黄/翠绿呈微观颜料不规则
- **颗粒度中等至细**：近看清晰、正常观看距离略可辨，**不粗到遮盖杯形、条纹或文字**
- **融合方式**：颗粒是每种颜色自带的颜料波动，**不是叠在最终图像上的透明噪点滤镜**
- **边缘干净利落**，仅在边界处允许微小颜料不规则
- **不做旧**：无污渍、刮痕、破损、褐变纸张、VHS/JPEG 伪影、大块人工胶片颗粒

## 文字处理

- 首选**两层流程**：先出「纯视觉底图」（文字区留成干净、低细节的大面积色块空区），再把原海报的标题、优惠数字、二维码、服务信息**精确叠回**。
- 若直接让模型渲染：提示词里**逐字引用**全部文案与数字（含 `15`、`15GB`、`20`、`10086`），出图后逐项核对。
- **文字本身不加颗粒、不加半色调、不做旧**；文字与底色对比充足（深蓝黑字压在奶油底上，或纯白字压在深色块上）；**不新增标题**。
