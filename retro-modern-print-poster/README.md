# Retro Modern Print Poster / 复古现代艺术版画海报

把普通海报/产品描述/营销主视觉，重绘成 **一幅精心制作的复古现代艺术版画**。

**最终效果**：像**一件真正的实体绘画或高质量模拟版画**——大胆平色块、简化几何形状、清晰轮廓、减少色调层次、前中后景强烈图形分离、具象与抽象平衡，调色板为浓郁的钴蓝/群青/青/绿松石/深蓝黑阴影/翠绿/深绿/珊瑚粉/鲑鱼粉/偶发洋红/暖黄/奶油/纯白点缀，表面带着**融入色彩之中的模拟印刷颗粒**。**宁静、饱和、几何控制精准、略带怀旧气息、视觉简洁、色彩丰富、触感微妙。**

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `riso-print-redesign-poster`（RISO 丝网印刷）、`high-end-color-blocking-poster`（高级撞色）、`flat-spot-poster`（留白平涂小景）、`paper-collage-poster`（纸艺拼贴）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容绝对参考原图**：主题、身份特征、物体数量、姿势手势、相机视角、透视、构图与裁剪、相对比例、物体位置、空间关系、前中后景组织、基本光照方向**全部严格保留**。
- **不得新增原图中不存在的物体**（不得添加汽车、建筑物、海滩、山脉、飞机、植被等）。
- **造型语言**：**大胆的平色块 + 简化的几何形状 + 清晰的轮廓 + 减少色调层次 + 前中后景强烈图形分离 + 具象与抽象平衡**。简化物体但保留标志性轮廓、比例、方向、位置、透视与可识别特征。
- **调色板（指定）**：钴蓝、群青、青、绿松石、**深蓝黑阴影（唯一阴影调性）**、翠绿、深绿、珊瑚粉、鲑鱼粉、**偶发洋红**、暖黄、奶油、**纯白仅作点缀**。在保持原有色彩关系和视觉层次的前提下做转换。
- **光影图形化**：摄影光照简化为**大面积图形化色调区域**；保留原始光照方向与逻辑，用简化色块、可控阴影轮廓、克制高光和极少中间色调表现。
- **深度**：靠透视、重叠轮廓、相对比例、水平与垂直平面、色彩对比与有序图层，**不用摄影景深**。
- **★ 颗粒质感（本风格的灵魂）**：每个色块都必须含**可见但精细的模拟表面纹理**——丝网印颗粒、石版画颜料纹理、胶印噪点、克制半色调、油墨密度变化、纸张与颜料的相互作用。**大面积纯色区（天空/水面/墙/路面/立面）绝不能光滑、数字般平坦或像矢量一样干净。**
- **★ 颗粒必须融入色彩之中**，不能像透明数字噪点滤镜一样覆盖在最终图像上；每种颜色自带微妙的颜料波动（暗部有细腻颗粒、蓝/绿松石有斑驳、粉/珊瑚/奶油/绿/黄有微观颜料不规则）。
- **★ 颗粒度中等至细**：近看清晰、正常距离略可辨，绝不粗到遮盖形状。边缘干净利落，边界仅有微小颜料不规则。
- **★ 不做旧**：无污渍、破损、刮擦、严重风化、人工胶片颗粒、VHS/JPEG 伪影。
- **最终判定**：必须像**把原始照片从零重建为实体绘画/高质量模拟版画**，**不像加了滤镜的照片**。
- **画布**：保留源海报**原始尺寸与宽高比**。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**；**文字本身不加颗粒、半色调、做旧**，保持干净边缘与充足对比。
- **功能性资产保护**：二维码/条码/logo 必须**完整、可识别、可扫描**，**不得被颗粒化、半色调化、覆盖、错位或旋转**。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义（含完整颗粒质感规格）、构图、文字与品牌处理、工作流、质量门、边界（含与 RISO 的对照表）。
- `palettes.md`：指定版画调色板（含参考色值）、配色结构、三色关系规则、★ 印刷颗粒材质规格、造型材质规则。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `retro-modern-print-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：造型是否**平色块+几何简化**、阴影是否统一**深蓝黑**、**每个色块是否都有颗粒**、**颗粒是否融入色彩**（而不是浮在表面的滤镜）、颗粒度是否**没有粗到遮盖形状**、是否**没有做旧感**、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图（文字区留干净低细节色块）→ 排版叠回原文字与二维码。

## 与 RISO 的区别（易混淆，务必分清）

| 维度 | 本 skill（复古现代艺术版画） | `riso-print-redesign-poster`（RISO） |
|---|---|---|
| 造型 | **绘画性平色块**，精心设计的绘画形状 | **硬边轮廓**，低频谱轮廓抖动 |
| 色彩 | 12 色丰富调色板 | **2–3 种限色油墨** + 中性纸底 |
| 印刷痕迹 | **模拟颗粒**融入色彩 | **套准纸缝**、露纸底白边、套印错位、缺墨擦痕 |
| 黑色 | **深蓝黑作为阴影调性** | 黑色为次要色，≤25% 画布 |
