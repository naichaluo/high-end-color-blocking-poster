# 复古现代艺术版画 · Palettes

**指定调色板：鲜艳饱和、源自参考美学**。这是一套**明确指定、不可随意替换**的版画色板——宁静、饱和、几何控制精准、略带怀旧气息。

## 色盘

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 钴蓝 | `#1B4FA8` | 主调蓝 | 最饱和的蓝，天空、水面、受光立面 |
| 群青 | `#2B3A8F` | 主调蓝 | 偏紫的深蓝，中景与阴影过渡区 |
| 青 | `#1FA3C3` | 冷调辅助 | 通透的冷色，水面、玻璃、空气感 |
| 绿松石 | `#20B2A6` | 冷调辅助 | 与珊瑚粉形成互补张力 |
| 深蓝黑 | `#101A2E` | **阴影（唯一阴影调性）** | 所有阴影统一用它，不用暖褐/灰调 |
| 翠绿 | `#1E8A5F` | 绿 | 植被、受光叶片 |

> 色值为**参考范围**，不是死值。同一色族内明度/饱和度上下浮动 5–10% 都是正常的。
> 若源海报有品牌色，**品牌色优先**：转换到本调色板时以可识别的方式保留，作为主色或强调色之一。

## 配色结构

1. **大色场（45–65%）**：钴蓝/群青/青/绿松石/奶油构成天空、水面、墙面等大面积平面。**这些大面积纯色区是颗粒质感最重要的落点**——绝不能光滑、数字般平坦、毫无生气或像矢量一样干净。
2. **图形块（25–40%）**：翠绿/深绿/珊瑚粉/鲑鱼粉/暖黄构成中景与主体的简化几何形状，边界清晰。
3. **阴影层**：统一用**深蓝黑**；通过**可控的阴影轮廓**表现，不做柔和摄影过渡。
4. **心跳层（≤8%）**：洋红（偶发）+ 纯白点缀，只用于最亮点与视觉焦点。

**色彩关系**：在**保持原有色彩关系和视觉层次**的前提下，把源色彩**转换到本调色板**——即色相可以换，但**明暗关系、冷暖关系、主次关系不变**。

## 三色关系规则

- **阴影＝深蓝黑**：全画面阴影统一调性，这是本风格最强的"版画感"来源之一。不要出现暖褐色阴影。
- **洋红＝偶发**：一张海报里洋红最多出现 1–2 处小面积，不可成为主色，不可大面积铺。
- **纯白＝点缀**：只用于选择性高光与最亮点，不铺大面积底色。

## ★ 印刷颗粒材质规格（本风格的灵魂）

**纹理必须融入色彩之中，而不是像透明的数字噪点滤镜一样覆盖在最终图像上。**

### 颗粒来源

| 来源 | 表现 |
|---|---|
| 丝网印刷颗粒 | 细腻、均匀、略有方向性的细颗粒 |
| 石版画颜料纹理 | 颜料在版面上的细微堆积与斑驳，边缘略有不齐 |
| 胶印噪点 | 极细的随机噪点，分布柔和 |
| 半色调 | **克制的、不规则**的半色调纹理，不要规则网点阵列 |
| 油墨密度变化 | 同一色块内密度轻微不均 |
| 纸张与颜料相互作用 | 颜料吃进纸纹的感觉，微弱吸收与堆叠 |

### 按颜色分层的颗粒规则

- **暗部**：保留**细腻的颗粒变化**，不能死黑成一片。
- **饱和的蓝色和绿松石色表面**：呈现**精致的斑驳纹理**。
- **粉色、珊瑚色、奶油色、绿色和黄色区域**：呈现**微观的颜料不规则性**。

### 颗粒度与分布

- **颗粒度：中等至细**——**近距离观察时清晰可见，正常观看距离下略微可辨**。
- **绝不能粗到遮盖形状或重要细节**。
- 整体纹理**大致均匀**，但允许**不同色块之间自然地存在轻微的密度变化**。

### 边缘

**保持边缘干净利落**，同时允许**边界处存在微小的颜料不规则性**，使其看起来不显得过于完美或电脑生成。

### 明确不要（做旧与伪影）

- **不要**做旧纸张、污渍、破损、刮擦、严重风化；
- **不要**人工胶片颗粒、大块噪点、极端的半色调网点；
- **不要** VHS 噪点、JPEG 伪影、数码故障；
- **不要**厚重的纸纤维、过多的划痕、灰尘覆盖层、人为做旧。

作品应具有**触感和物理质感**，而不是"被做旧"。

## 阴影与轮廓

- **图形化光影**：摄影光照简化为**大面积图形化色调区域**。
- **保留原始光照方向和逻辑**，但用**简化色块、可控阴影轮廓、克制高光、极少中间色调**表现。
- **不要**：光泽感强的 CGI 照明、过度光晕、体积效果、现代电影调色、柔和摄影过渡。

## 造型材质规则

| 对象 | 处理 |
|---|---|
| 植物/有机形态 | **密集笔触 + 深色轮廓 + 选择性明亮点缀**构成的密集图形块 |
| 水/玻璃/铬/波浪/倒影/窗户/远景灯光 | 简化为**有节奏的重复笔触和简洁高光**，保持同样颗粒感 |
| 建筑立面与结构 | 简化为干净彩色平面，**保留几何形状和透视** |
| 人物/车辆/产品/动物 | 保留**足够的轮廓信息**，与原始素材保持清晰联系 |

## 文字承载区

- 保持**大面积的干净、低细节色块**，避免密集纹理与高频笔触。
- **文字本身不加颗粒、不加半色调、不做旧**，保持干净边缘与充足对比。
- 文字与底色之间要有明确对比度，建议用奶油/纯白底 + 深蓝黑字，或深色块 + 纯白字。
