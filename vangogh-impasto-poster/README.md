# Van Gogh Impasto Poster / 梵高厚涂油画海报

把上传的海报 / 主视觉，**以原图为绝对结构参考**，重绘成 **19 世纪末后印象派厚涂油画**。

**最终效果**：必须像**一张真实的、实体存在的厚涂油画**——可见笔触、厚重颜料、画布纹理、丰富色层、手工不规则边缘、强烈而自然的后印象派绘画感——**而不是给照片套一个滤镜**。

**🅰 核心原则：只改变视觉媒介，不改变任何叙事内容与商业内容。**

**不需要风格参考图。源海报是唯一内容源与绝对结构参考。**

这是一个**独立** Skill，不与 `impasto-miniature-landscape`（厚涂微缩景观）、`ghibli-animation-poster`（吉卜力手绘）、`observational-pen-wash`（钢笔淡彩）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **绝对结构参考（第 1 条也是最重要的一条）**：严格保留原图中的**主体身份、人物五官、表情、姿态、手部、服装、物体、物体数量、建筑、景观、构图、裁切、透视、拍摄视角、空间关系、前中后景结构、光线方向与主要色彩关系**；**不得新增、删除、替换、移动或重新设计任何叙事元素**。
- **只改变视觉媒介**：重绘为 19 世纪末后印象派厚涂油画，参考梵高式绘画语言，**但不复制任何具体作品构图**。
- **⭐ 方向性笔触是本风格的灵魂**：**笔触顺着物体结构和体积运动**——人物/面部=**短促轮廓笔触**；衣物/物体=**有节奏的重复笔触**；建筑=**较有秩序的线性笔触**；自然元素=**更流动有机的笔触**。
- **厚涂材质**：厚涂颜料、**断色**、层叠色块、**局部颜料隆起**、**真实画布肌理**。
- **配色**：群青、钴蓝、蓝绿、赭石、金黄、暖橙、橄榄绿、熟褐、红棕；**保留原图色彩逻辑并增强冷暖与互补关系；不得强行改变原物体颜色**。
- **明暗方式**：用**色彩关系 + 方向性笔触**塑造明暗，**避免平滑数字渐变**。
- **人物硬约束**：所有人物**严格保持原始身份、脸型、五官、表情、姿态、手部、身体比例与位置**，**不得为了风格而改变人物结构**。
- **画布**：保留源图**原始尺寸与宽高比**；**不改构图、不改裁切、不改透视、不改视角**。
- **⭐ 文字走受控层**：docx 明确禁止画面出现**文字、签名、边框、水印**，因此**油画本体不画任何字**，源海报全部文案、价格、二维码、logo 一律**由原素材精确叠加**——这也天然满足「不得把文字或 logo 化为不可读色块」。
- **功能性资产保护**：二维码、条码、logo 必须**完整、可识别、可扫描**，不得被厚涂颜料、笔触或颜料隆起覆盖、模糊、变形、错位；最佳做法是**从源海报原样贴回**。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度；**不得凭空加入原图不存在的梵高元素**（星空、向日葵、柏树、麦田、乌鸦等）。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：后印象派色盘、断色与厚涂材质、画布肌理、笔触分工表。
- `prompt-templates.md`：主模板 + 纯视觉底图模板（**首选**）+ 出图前自检表。
- `examples/`：示例需求与应用。

## 与最易混淆 skill 的区别

| skill | 实质 | 深度/体积来源 | 结构自由度 |
|---|---|---|---|
| **本 skill**：梵高厚涂油画 | **后印象派方向性笔触 + 忠实原图结构** | 笔触方向 + 色层 + 画布肌理 | **零改动**：不改构图、不改主体、不增删元素 |
| `impasto-miniature-landscape`：厚涂微缩景观 | **调色刀堆出的微缩立体景观雕塑** | 明亮雕塑性体积、调色刀痕 | 画面重构为一个微缩景观 |

本 skill 最终交付的是**一张真实存在的实体油画**，**不是微缩立体景观**；两者**互不合并**。

## 快速上手

1. 先 `skill` 加载 `vangogh-impasto-poster`。
2. **建立结构锁定清单**：逐项列出必须保留的主体、人物五官/姿态/手部、物体与数量、建筑、构图、透视、视角、前中后景、光线方向与主要色彩关系。
3. 以源海报为参考图（`image`），用 `prompt-templates.md` 的**纯视觉底图模板**（首选）生成油画视觉层，并**明确分配四类笔触**。
4. 出图后按自检表核对：结构/数量/视角/光线是否一致、笔触是否顺结构、是否厚涂断色、是否有畸形或多指缺指、是否被强塞梵高元素、是否像实体油画。
5. 把原海报的标题、价格、日期、二维码、服务信息与 logo **精确叠回**（不要让模型画字）。
