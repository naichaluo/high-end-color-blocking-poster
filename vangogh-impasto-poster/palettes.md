# 梵高厚涂油画海报 · Palettes

**后印象派色盘：冷色骨架 + 暖色受光 + 补色对比**。

铁律只有一条：

> **保留原图的色彩逻辑，同时增强后印象派式的冷暖与互补色关系——但不得强行改变原物体的颜色。**
> 物体原本是什么颜色归属，绘制后仍是什么颜色归属。

## 色盘结构

| 角色 | 色 | 用法 |
|---|---|---|
| **冷色骨架** | 群青、钴蓝 | 阴影、暗部笔触、结构转折的冷侧 |
| 冷色延伸 | 蓝绿 | 水面、天空、织物暗面的冷暖过渡 |
| **暖色受光** | 金黄、暖橙 | 受光面的厚涂高光笔触、光源方向 |
| 土地色 | 赭石、熟褐 | 结构面、地面、木材、皮肤中间调 |
| 暖深色 | 红棕 | 暗部暖侧、衣物深色、物体转折 |
| 中性绿 | 橄榄绿 | 植物、器物、需要压住纯度的中间调 |
| 画布底色 | 亚麻画布本色（米灰/浅褐） | 从颜料缝隙中透出，构成整体温度 |

## 三套可直接选用的方向

### A. 冷暖对峙（最典型的后印象派）
**阴影走群青/钴蓝，受光走金黄/暖橙**，两组互补色在主体上直接对撞；
赭石与熟褐做中间调过渡；橄榄绿压住过饱和处。

### B. 蓝绿主导（冷调原图）
蓝绿 + 群青承担大面积结构与暗部，钴蓝加深转折；
暖橙与金黄只出现在**受光面**与**视觉焦点**上，面积小但纯度略高，形成冷暖爆点。

### C. 土地暖调（暖调原图）
赭石、熟褐、红棕、橄榄绿构成主体，
**用群青与钴蓝的笔触画阴影与冷侧**，把原本容易发闷的暖调重新拉开冷暖关系。

> 三套方向都**不改变原物体的色相归属**：原图是绿的就仍是绿，只是用群青画它的暗、用金黄画它的受光。

## 用色规则

- **断色（broken colour）**：相邻色块**不完全调和**，靠并置的小色块在观者眼中混色，而不是把颜料在调色板上调匀。
- **层叠色块**：多层颜料叠压，**下层局部透出**，产生真实的色层深度。
- **用色彩关系塑造明暗**：明暗由**色相对比 + 笔触方向**建立（冷暗 vs 暖亮），**不用明度渐变**。
- **避免平滑数字渐变**：任何平滑过渡都必须由**笔触的并置**来完成，而不是由软件羽化。
- **不改变物体原色**：不得因为「梵高爱用黄色」就把蓝色物体画成黄色。
- **主体色准优先**：品牌色、产品包装色、人物服装色、识别色保留源海报的主要色彩信息。
- **文字承载区**：预留区域用**较匀、较薄、低笔触密度**的颜料（例如一段平涂底色），保证叠加文字对比度；不要让厚涂隆起穿过文字区。

## 颜料与肌理

| 项 | 要求 |
|---|---|
| **厚涂（impasto）** | 颜料有明显厚度，**局部隆起**，可见颜料脊与堆叠 |
| **画布肌理** | **真实亚麻画布纹理**，经纬织纹从颜料层中透出，尤其在薄涂处 |
| **笔触可见** | 每一笔都可辨认方向与起止，**笔触顺物体结构与体积运动** |
| **色层丰富** | 多层叠压，局部下层色透出，边缘有颜料干接痕 |
| **手工边缘** | 颜料层的收边**略微不齐**（真实绘画感）——注意这是**画布边缘的颜料处理**，不是版式裁切，不得借此改变构图或裁掉源海报信息 |

## 笔触分配（必须写进提示词）

| 对象 | 笔触 |
|---|---|
| 人物 / 面部 | **短促的轮廓笔触**，贴合五官与面部体积 |
| 衣物 / 物体 | **有节奏的重复笔触**，顺布料褶皱与物体转折成组排列 |
| 建筑 | **较有秩序的线性笔触**，更长更直，顺结构方向 |
| 自然元素 | **更流动有机的笔触**，随形起伏（风、水、草木的走向） |

## 严格禁止的颜色与效果

- ❌ 平滑数字渐变、软件羽化过渡
- ❌ 机械重复纹理（像贴了重复笔刷图章）
- ❌ 水彩透明感、丙烯哑光平涂、塑料质感、喷枪气泵式均匀喷色
- ❌ 数字滤镜感（磨皮、锐化、油画滤镜插件那种「糊一层」的效果）
- ❌ 过度旋涡化（把一切结构都卷成漩涡）
- ❌ 文字、签名、边框、水印
- ❌ 强行加入原图不存在的梵高元素：星空、向日葵、柏树、麦田、乌鸦等
