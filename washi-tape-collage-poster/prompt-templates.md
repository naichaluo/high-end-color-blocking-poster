## 现有海报 → 手账纸胶带拼贴风（主模板）

```text
把提供的源海报重绘成「精致手账纸胶带拼贴插画」风海报，Image 1 是唯一内容与视觉参考。

【画布】保留源海报的原始尺寸与宽高比（不要改成正方形，不要裁切版式）。

【严格保留原图内容】保留原始图片的主体、人物/动物/建筑/物体的身份特征、动作姿态、空间关系、
主要构图和视觉焦点，不改变原图所表达的场景内容。

【商业内容必须完整保留】务必保留源海报的全部商业内容与文案：品牌 logo 与字样、主标题、
全部副标题与卖点、价格与券额数字、日期、电话、URL、二维码及其位置、底部服务与法务信息、
以及所有产品/规格标签文字。逐字列出：[把源海报上的文字逐条填在这里]。
所有文字必须清晰准确、可读，数字一个都不能改。不得把文字或 logo 化为不可读色块。
不要新增、编造或改写任何文案。
【功能性资产保护】二维码/条码/logo 必须保持完整、可识别、可扫描：二维码保持完整清晰可扫描，
不要撕碎、不要用纸片或胶带覆盖、不要错位歪斜、不要做成拼贴碎片。

【视觉语言】手工纸艺拼贴（paper collage）× 手账素材（journal collage）× 撕纸拼贴（torn paper collage）
× 纸胶带拼贴（washi tape collage）。
底纸为温暖的米白色、奶油白、旧纸张色，具有真实的手账本纸张质感。

主体由大量不规则撕裂的彩色纸片、半透明纸张、旧杂志纸、手工染色纸、薄水彩纸和纸胶带逐层拼贴组成。

不要表现为普通数字绘画，而要明显具有"真实手工制作"的感觉：
- 纸张边缘自然撕裂、不规则、略微翘起；
- 不同纸片之间存在明显的重叠关系；
- 可以看到纸张纤维、细微褶皱、颗粒、纤维毛边、干燥颜料痕迹和轻微透明感；
- 部分纸片颜色深浅不均匀，存在自然的手工染色和颜料晕染；
- 局部纸片略微错位，呈现真实手工拼贴产生的不完美感。

主体的明暗、轮廓和体积由不同颜色和深浅的纸片拼接形成，而不是用传统线稿描绘。
使用少量概括性的纸片表达细节，避免过度精细；保留关键轮廓和特征，但将细节适当简化为具有设计感的几何纸片。

【色彩】低饱和、柔和、复古的手账配色：米白、奶油色、灰蓝、雾蓝、浅棕、赭石、卡其、橄榄绿、砖红、淡黄色。
整体色彩自然、克制、温暖，具有复古旅行手账和生活方式杂志的感觉。
主体的实际颜色要保留源海报的主要色彩信息，只做低饱和化处理，不改变色相归属。品牌色保留可识别。

【构图】背景保持大量留白，不要填满整个画面。主体周围可以散落少量撕纸、纸胶带、半透明纸片和手绘色块，
形成自然的手账排版感。保留源海报的信息顺序与层级关系（品牌/标题 → 主体 → 卖点/优惠 → QR/行动区 →
服务/法务），但可按手账拼贴的松弛排版重新排布；不得为了留白美学删减或弱化必需信息。

【纸胶带固定效果】加入少量真实纸胶带：半透明米色胶带、灰色胶带、旧纸胶带；胶带边缘不规则；
能够看到胶带半透明后的底层纸张；胶带像是真实贴在纸面上，而不是画出来的装饰。

【最终效果】像一本高级旅行手账中撕下来的手工拼贴页面，具有真实的纸张触感、手工制作痕迹和轻微的不完美，
简洁、安静、文艺、温暖、复古、高级。

【约束】不要混入其他项目或其他参考图的内容；不要改变价格、券额、套餐值、电话号码、二维码、品牌名与活动口径。
避免：普通数字绘画感、填满整个画面、信息堆积、随机装饰堆砌、3D 质感、机械居中和模板化排版、
把文字变成色块、改成正方形。
```

## 出图前自检

| 检查 | 期望 |
|---|---|
| 画布尺寸 | **保留源海报原始尺寸与比例** |
| 内容保真 | 主体、身份特征、姿态、空间关系、主要构图、视觉焦点**严格保留**；场景内容未改变 |
| 底纸 | 米白/奶油/旧纸色，真实手账本纸张质感 |
| 留白 | **大量留白，画面未被填满**；留白即底纸色 |
| 撕纸边 | 自然撕裂、不规则、略微翘起 |
| 重叠 | 纸片之间有明显重叠关系 |
