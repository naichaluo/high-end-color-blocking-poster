# Washi Tape Collage Poster / 手账纸胶带拼贴海报

把普通海报/产品描述/营销主视觉，重绘成 **精致的手账纸胶带拼贴插画**。

**最终效果**：像一本高级旅行手账中撕下来的手工拼贴页面——真实的纸张触感、手工制作痕迹、轻微的不完美，**简洁、安静、文艺、温暖、复古、高级**。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `paper-collage-poster`（剪纸/纸艺拼贴）、`torn-paper-relief-poster`（撕纸立体浮雕）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：保留原图的主体、人物/动物/建筑/物体的**身份特征、动作姿态、空间关系、主要构图和视觉焦点**，**不改变原图所表达的场景内容**。
- **视觉语言**：手工纸艺拼贴（paper collage）× 手账素材（journal collage）× 撕纸拼贴（torn paper collage）× 纸胶带拼贴（washi tape collage）。
- **底纸**：温暖的米白色、奶油白、旧纸张色，具有**真实的手账本纸张质感**。
- **构成**：主体由大量**不规则撕裂的彩色纸片、半透明纸张、旧杂志纸、手工染色纸、薄水彩纸和纸胶带**逐层拼贴组成。
- **必须像真实手工，不是数字绘画**：纸边自然撕裂略翘、纸片明显重叠、可见纸张纤维/细微褶皱/颗粒/纤维毛边/干燥颜料痕迹/轻微透明感、部分纸片深浅不均（手工染色与晕染）、局部纸片略微错位。
- **造型方式**：主体的明暗、轮廓和体积**由不同颜色和深浅的纸片拼接形成，而不是用传统线稿描绘**；少量概括性纸片表达细节，**避免过度精细**；细节简化为有设计感的几何纸片。
- **配色**：低饱和、柔和、复古的手账配色（米白、奶油、灰蓝、雾蓝、浅棕、赭石、卡其、橄榄绿、砖红、淡黄）；自然、克制、温暖，复古旅行手账与生活方式杂志感。**主体实际颜色保留源海报主要色彩信息**（仅低饱和化）。
- **构图**：**背景保持大量留白，不要填满整个画面**；主体周围可散落少量撕纸、纸胶带、半透明纸片和手绘色块，形成自然**手账排版感**。
- **纸胶带固定**：少量**真实**纸胶带（半透明米色/灰色/旧纸），边缘不规则、**透出底层纸张**、像**真贴在纸面上**而非画出来的装饰。
- **画布**：保留源海报**原始尺寸与宽高比**。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；可做成手账式排版（手写标签纸/纸条/打字机字体）但必须清晰可读；**不得把文字或 logo 化为不可读色块**。
- **留白靠布局，不靠删信息**：不得为了留白美学删减必需信息。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：低饱和复古手账色盘、纸张与纸胶带材质。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `washi-tape-collage-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：留白是否够、撕纸边与重叠是否有、纸胶带是否"真贴"、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图 → 排版叠回原文字与二维码。
