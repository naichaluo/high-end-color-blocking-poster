# 手账纸胶带拼贴 · Palettes

**低饱和、柔和、复古的手账配色**。整体色彩自然、克制、温暖，具有**复古旅行手账和生活方式杂志**的感觉。

## 色盘

| 色 | 角色 | 说明 |
|---|---|---|
| 米白 / 奶油白 | 底纸 | 画面**最大面积**，真实手账本纸张质感；大量留白就是它 |
| 旧纸张色 | 底纸层次 | 泛黄旧纸、牛皮纸色，用于垫底纸片与胶带下的底层 |
| 灰蓝 / 雾蓝 | 主体色 | 天空、水面、冷调主体 |
| 浅棕 / 赭石 / 卡其 | 主体色 | 木色、土色、器物、食品 |
| 橄榄绿 | 主体/点缀 | 植物、品牌绿（须保留可识别） |
| 砖红 | 强调 | 小面积焦点 |
| 淡黄 | 点缀 | 暖光、果实、纸胶带 |

**主体色准优先**：主体的实际颜色（产品、包装、品牌色、人物/动物/建筑的识别色）要保留源海报的主要色彩信息，只做**低饱和化处理**（降纯度、加灰调、复古化），**不改变色相归属、不换色系**。

## 纸张与材质

- **底纸**：米白/奶油/旧纸色，哑光，有真实手账本纸张的纤维与轻微颗粒。
- **拼贴纸片**：不规则撕裂的彩色纸片、半透明纸张、旧杂志纸、手工染色纸、薄水彩纸。
- **纸片特征**：撕裂边自然不规则、略微翘起；纸片之间明显重叠；可见纤维、细微褶皱、颗粒、纤维毛边、干燥颜料痕迹、轻微透明感；部分纸片颜色深浅不均匀（自然手工染色与颜料晕染）；局部略微错位。

## 纸胶带

半透明米色胶带、灰色胶带、旧纸胶带：

- 边缘**不规则**（不是整齐切边）；
- 能**看到胶带半透明后的底层纸张**；
- 像**真实贴在纸面上**，有轻微褶皱与气泡感，而不是画出来的装饰。

## 用色规则

- **整体低饱和**：降纯度、略加灰、偏复古；避免荧光、艳俗、高对比。
- **大量留白**：底纸色占画面最大面积，不要填满；留白不是"没画完"，是手账的呼吸。
- **明暗与体积靠纸片**：由不同颜色和深浅的纸片拼接形成，不用传统线稿描绘。
- **细节靠概括纸片**：少量几何纸片表达，避免过度精细。
- **品牌色**：以低饱和但可识别的方式保留。
- **文字承载区**：保持干净、低细节的米白/奶油底纸，保证叠加的精确文字有足够对比。
