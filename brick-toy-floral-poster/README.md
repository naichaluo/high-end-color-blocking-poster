# Brick Toy Floral Poster / 乐高积木花卉海报

把普通海报 / 产品描述 / 营销主视觉，重绘成 **塑料积木（乐高式）花卉海报**。

**最终效果**：一朵**由塑料积木逐块拼搭**的巨型花朵——花瓣带**圆角拼接层次**、块间有细接缝与**圆形凸点**，**绿色积木**做花茎与叶片；**3D 玩具渲染 + 柔和影棚灯光**打出宽柔高光与**细腻柔和阴影**；铺在**米白底**上，套用**复古艺术海报版式**——顶部小字衬线装饰字符位、底部大号手写花体英文标题位，**浅淡粉米白柔和配色**，**高级印刷海报质感**。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `isometric-healing-blocks`（等距治愈积木）、`clay-animation-poster`（黏土动画）、`plush-animation-poster`（毛绒/羊毛毡）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：锁住源海报的产品名、卖点、价格、日期、URL、二维码、法务文案、品牌色与用户给定措辞。
- **画布**：保留源海报**原始尺寸与宽高比**。风格**默认竖版构图**；源海报是竖版即照此执行，源海报是横版时**保留源比例**并把版式等比适配，**不要为凑竖版而拉伸或裁切**。
- **主体结构**：把源海报主体整体转译成**一株完整积木模型**（花朵 + 绿积木花茎 + 绿积木叶片全部由积木构成）；**只搭一株**，不散落无关积木；积木**互锁、对齐、承重合理**，不悬空、不错位、不穿插。
- **花瓣层次**：花瓣带**积木圆角拼接层次**，层与层之间有**清晰拼接台阶**。
- **材质（核心）**：**塑料积木颗粒质感**——注塑塑料的细腻哑光光泽、边缘轻微倒角、极轻微模具纹理、圆角外缘、块间**细接缝线**、暴露面**圆形凸点（stud）/凹槽**；**干净玩具塑料**，不脏不旧不刮花、不透明、不金属、不玻璃、不陶瓷；**不要平滑无缝的整体塑料块**（拼搭痕迹必须看得见）。
- **光影**：**3D 玩具渲染 + 柔和影棚灯光**——大面积柔光、**宽而柔**的高光带、克制光比、单一主光偏上方；积木与花瓣层叠处有**细腻柔和的接触阴影**让拼接层次可读；投影淡、边缘柔、范围收拢。**禁止**硬边强对比灯、戏剧性聚光、彩色灯光污染、过曝死白、噪点。
- **配色**：**浅淡粉米白柔和配色**——米白/浅米白底承担大量留白，花朵浅粉/淡粉/藕粉/奶粉 + 极浅白粉做亮部，茎叶柔和绿（主绿 + 深一档柔绿）；低到中等饱和、明亮干净。**主体识别色以同色系柔和版本保留，不换色系**。禁止艳丽刺眼、荧光、脏灰、重暗调、高对比撞色。
- **版式**：**复古艺术海报版式**——顶部**小字衬线装饰字符位** + 底部**大号手写花体英文标题位**（可与主体轻微重叠但不遮挡关键结构）+ 简约文艺、大量留白、克制装饰线；主体居中占宽约 45%–60%、高约 40%–55%，不贴边不出血。
- **排版文字内容**：顶部装饰位与底部标题位**只能用源海报自身的标题/主体名或其英文译名**；**不得照抄**风格样例的 `FLEUR` / `Pink Chrysanthemum`，**不编造**作品名或承诺，**不加署名**（如 `prompt by awen`）。源海报无英文时，顶部装饰位可保留为**排版留白/占位**。
- **画面干净**：**不要人物**、不要多余杂物、不要杂乱背景、不要飘落的散积木；要有**高级印刷海报质感**（细腻印刷网纹/纸张质感），不是屏幕渲染图。
- **文字保留**：逐字保留源海报标题与全部文案（价格、券额、日期、电话、URL、法务字样）；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**；手写花体易乱码，精确信息一律走受控层。
- **功能性资产保护**：二维码 / 条码 / logo 必须**完整、可识别、可扫描**——不得被积木颗粒化、拆成圆角块、被接缝/阴影切断、倒角变形或压暗；最佳做法是**原样贴回**。
- **信息层级**：品牌/标题 → 主体 → 卖点/优惠 → QR/行动区 → 服务/法务；海报式版式可重排位置，但**不得删减、弱化或省略**任何必需信息。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度，也不借用风格样例的装饰英文名与其他积木风格。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界（含与等距积木/黏土/毛绒的区分表）。
- `palettes.md`：浅粉米白柔和色盘、塑料积木材质、影棚光影与版式规则。
- `prompt-templates.md`：积木海报主模板 + 纯视觉底图模板 + Style preset + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `brick-toy-floral-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的**主模板**，把源海报的文字**逐条填进**模板的「逐字列出」与「待填入内容」（顶部装饰位、底部大号标题位）。
3. 确认主体结构清单：花朵形态与花瓣层数、花茎走向、叶片数量与角度、整体姿态。
4. 出图后按自检表核对：积木颗粒质感、拼接台阶、影棚光影、**文字/价格/二维码是否完整保留**。
5. 要文字零误差就用两层流程：出**纯视觉底图** → 排版叠回原文字与二维码。
