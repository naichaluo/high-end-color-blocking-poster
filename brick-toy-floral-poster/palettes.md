# 乐高积木花卉 · Palettes

**浅淡粉米白柔和配色** + **塑料积木的注塑材质**。整体明亮、干净、甜美但不俗气——是**高级玩具品牌的产品海报**，不是儿童玩具盒封面。

## 色盘

| 色 | 角色 | 说明 |
|---|---|---|
| 米白 / 浅米白 | 底色 | 画面**最大面积**；柔和、干净、微暖，承担全部留白 |
| 极浅暖灰 | 底色层次 | 桌面/背景的极轻微明暗过渡，让投影有落点 |
| 浅粉 / 淡粉 | 花朵主色 | 花瓣积木的主色，明亮、奶感、不艳 |
| 藕粉 / 奶粉 | 花朵层次 | 内层花瓣、花心周围，与主粉形成**同一色系的明度层次** |
| 近白积木 | 花朵高光层 | 最外层或最亮花瓣，用**极浅的白粉色**积木，不纯白 |
| 柔和绿 | 花茎 / 叶片 | 不刺眼、不荧光的玩具绿；比自然绿更柔、更奶 |
| 深一档柔绿 | 茎叶暗部积木 | 让茎叶有拼接层次，仍属同一绿色系 |

**色彩纪律**：

- 花朵的颜色层次**靠同一粉色系不同明度的积木**实现，而不是靠写实渐变；
- 茎叶用**两档柔和绿**（主绿 + 深一档柔绿）表现层次；
- 整体**低到中等饱和**，明度高，画面干净通透；
- **主体色准优先**：若源海报主体有明确识别色（品牌色、产品色），积木使用**该色系的柔和版本**，保留识别度，**不换色系**；
- 禁止：艳丽刺眼、荧光色、脏灰、重暗调、高对比撞色、大面积纯黑。

## 塑料积木材质

**注塑塑料（injection-moulded plastic）**，具体到可核对的特征：

- **表面**：细腻哑光光泽，边缘有轻微倒角，表面有**极轻微的模具纹理**；
- **颗粒特征**：圆角外缘、块与块之间**细接缝线**、暴露面上可见**圆形凸点（stud）/ 凹槽**；
- **拼接台阶**：花瓣层与层之间有**清晰的拼接台阶**，每一层轮廓是圆角积木块外缘；
- **状态**：干净玩具塑料——**不脏、不旧、不刮花、不透明、不金属、不玻璃、不陶瓷**；
- **禁止**：平滑无缝的整体塑料块（拼搭痕迹必须看得见）、软塌变形、融化感、积木互相穿插。

## 灯光与阴影

**3D 玩具渲染 + 柔和影棚灯光**：

- **主光**：大面积柔光箱式的柔和光，方向**偏上方且统一**，全程只有一个主光方向；
- **高光**：**宽而柔**的高光带，不是硬点高光、不是镜面反射；
- **接触阴影**：积木之间、花瓣层叠之间存在**柔和的接触阴影**，使拼接层次可读；
- **投影**：投在底色/桌面上的投影**淡、边缘柔、范围收拢**；
- **光比**：克制（明暗差不过分）；
- 禁止：硬边强对比影棚灯、戏剧性聚光、彩色灯光污染、杂乱环境反射、过曝死白、噪点、重 HDR。

## 版式与印刷质感

- **竖版构图**（源海报为竖版时）；**顶部小字衬线装饰字符位**；**底部大号手写花体英文标题位**；
- **简约文艺、大量留白、克制装饰线**；
- **高级印刷海报质感**：细腻的印刷网纹/纸张质感、干净的墨色边缘——**不是**屏幕渲染图直接导出；
- **文字承载区**：顶部装饰带与底部标题带保持**干净、低细节的米白底**，保证衬线小字与手写花体都有足够对比；
- 不要把文字压在积木密集处；不要让投影落在文字上。
