# Crystal Glass Floral Poster / 水晶玻璃花卉海报

把普通海报/产品描述/营销主视觉，重绘成一张 **当代艺术展览海报**：花卉主体全部是**通透水晶玻璃**，**每片花瓣边缘带细腻金色描边**，**暖金色光线穿过玻璃投射细碎通透光斑**，落在**做旧浅米白纹理纸**上，外面套**双层细白色圆角画框**，顶部是大号复古衬线标题位 + 小字副标题位，**高级简约居中排版**。

**最终效果**：像美术馆当代艺术展览的海报/图录页——安静、克制、通透、高级、干净。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `felt-floral-poster`、`lace-embroidery-poster`、`vintage-engraving-floral-poster`、`brick-toy-floral-poster`、`plush-animation-poster`、`knitted-yarn-poster`、`impasto-miniature-landscape` 或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：主体身份、花卉种类与花瓣结构、姿态、空间关系、主要构图与视觉焦点**严格保留**；主体身份不换，**只把材质换成水晶玻璃**。
- **材质（核心）**：**所有花瓣完整为通透水晶玻璃**——有真实厚度与内部体积、花瓣厚薄变化、内部透光、迎光侧一道明亮细高光；**不是**磨砂塑料、**不是**平板亚克力、**不是**水波纹玻璃。
- **颜色**：玻璃质感的**明黄 → 暖金渐变黄**，由花瓣根部向边缘渐变，根部略浓、边缘更透亮；只允许极克制的内部细节（极轻色散、细微气泡流纹），**不得有脏点杂质裂纹**。
- **金色描边（核心）**：**每片花瓣边缘带细腻金色描边**——细、均匀、连续，像金箔包边或金线勾边；**不要**粗重金框、**不要**整朵镀金、**不要**金属感。
- **光影（核心）**：**暖金色明亮光线穿过玻璃**，在纸面**投射细碎通透光斑**（碎光斑、小光点、柔和月牙亮区），离玻璃越近越密越亮；光斑是**光**，不是装饰图案（不得做成星芒/闪片/几何图形）。主光是**柔和影棚漫射柔光**，无硬边强阴影。
- **背景**：**做旧浅米白纹理纸**，纸纤维、轻微颗粒、淡淡做旧；**画面干净无多余杂物**。
- **画框**：**双层细白色圆角画框**，等比内缩、圆角克制、**无线条花纹无阴影浮雕**。
- **排版**：**高级简约居中**——大号复古衬线标题位（全大写宽字距）+ 小号宽字距副标题位。
- **标题位文字内容用源海报自身的标题/主体名（逐字）**；副标题位沿用"小号、宽字距、全大写"的形式，内容取源海报自带文案；**不得虚构展览名、年份、策展人、艺术家署名**；**不加** `prompt by awen` 之类署名。
- **画布**：保留源海报**原始尺寸与宽高比**；3:4 仅在源海报本身约为 3:4 或用户明确要求时使用。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**。
- **功能性资产**：二维码/条码/logo 必须**完整、可识别、可扫描**，不得被玻璃、光斑、金边或画框覆盖/错位；其所在区域保持干净米白纸面。
- **留白靠布局，不靠删信息**：不得为了"干净美学"删减必需信息。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度、花种或展览名。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：明黄玻璃/暖金光斑色盘与材质光影处理。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + Style preset + 出图前自检表 + 常见失败修法。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `crystal-glass-floral-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：玻璃是否真的通透有厚度、金边是否够细、光斑是否"是光不是贴纸"、白框是否够细、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图（标题/副标题/二维码区留成干净纸面）→ 排版叠回原文字与二维码。
