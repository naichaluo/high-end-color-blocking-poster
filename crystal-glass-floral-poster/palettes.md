# 水晶玻璃花卉海报 · Palettes

**明黄玻璃 × 暖金光 × 做旧浅米白纸**。整体是**暖调、干净、通透、展览级**的配色：颜色几乎全部来自玻璃主体与光斑，纸面与白框只做安静的承载。

## 色盘

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 做旧浅米白 | `#F2EDE4` / `#EFE9DE` | 背景纸 | 画面**最大面积**；暖调浅米白纹理纸，有纤维与轻微做旧 |
| 明黄（玻璃亮部） | `#FFD24A` / `#F7C838` | 主体高光 | 玻璃受光最亮处，接近光源方向的通透亮黄 |
| 渐变黄（玻璃中调） | `#F2B322` / `#E8A317` | 主体主色 | 花瓣主要面积，由根部向边缘渐变 |
| 暖金（玻璃厚部/暗调） | `#D0911F` / `#C07F17` | 主体体积 | 玻璃厚度处，浓度最高，**面积要小** |
| 暖金光线 / 光斑 | `#FFE7A8` → `#FFF6DC` | 光效应 | 穿过玻璃的暖金光与细碎光斑，边缘柔和衰减 |
| 细腻金色描边 | `#C9A227` / `#D4AF37` | 花瓣轮廓 | 每片花瓣边缘的 gilded rim，**细、均匀、连续** |
| 纯白 | `#FFFFFF` | 画框 | 双层细白色圆角画框，**只用线条，不做填充** |
| 极浅暖灰 | `#E3DCD0` / 透明度 8%–15% | 接触阴影 | 玻璃与纸面之间的柔和浅阴影 |

**叶与茎（若源海报有）**：换为**半透明玻璃绿**——`#B7D3A8`（亮）→ `#7FA06B`（厚部），同样带细金边与透光，**饱和度低于玻璃花瓣**，不得抢主体。

**文字色**：标题与副标题用**深暖灰褐** `#4A423A` 或**近黑** `#2F2B27`（在做旧米白纸上对比足够、气质克制）；不要用纯黑、不要用金色做正文。

## 材质与光影

### 水晶玻璃（核心材质）

- **通透**：能透过花瓣看到后层花瓣与纸面纹理，透光处更亮。
- **有厚度**：花瓣有真实的玻璃体积感——根部厚、边缘薄；厚部颜色更浓，薄边几乎无色只有高光。
- **边缘高光**：每片花瓣迎光侧有一道明亮细高光线。
- **金色描边**：花瓣轮廓一圈**细腻金色包边**（金箔/金线感），粗细不超过花瓣宽度的约 1/40；**不要**把整片花瓣描成粗金框。
- **克制内部细节**：允许极轻微色散与细微气泡/流纹，**但不得出现脏点、杂质、裂纹、指纹**。

### 暖金光斑（caustics）

- 光源方向：**单侧上方暖金色明亮光线**，穿过玻璃后在纸面投射**细碎通透光斑**。
- 光斑形态：细碎的亮斑、小光点、柔和的月牙形亮区；离玻璃越近越密越亮，向四周自然衰减。
- 光斑是**光**，不是装饰图案：不得做成规则几何图形、不得画成星芒或闪片贴纸。
- 整体仍是**柔和影棚漫射柔光**：不要硬边投影、不要戏剧性聚光、不要镜头光晕。

### 纸面

- 做旧浅米白纹理纸：细腻纸纤维、轻微颗粒、淡淡的做旧痕迹（轻微不匀、极浅的旧痕）。
- **干净无多余杂物**：不加水渍、不做重做旧、不加折痕污渍、不铺满装饰。

### 双层细白圆角画框

- **两层**极细白线，等比内缩（外层离画面边缘略远，内层再内缩一段固定距离）；
- **圆角**半径克制（约画面短边的 2%–4%），不要大圆角卡片感；
- 线宽极细、均匀；**不要花纹、不要双色、不要阴影浮雕、不要粗框**。

## 用色规则

- **暖调统一**：全画面只有暖金黄一个彩色家族 + 米白纸 + 白框；**不要出现蓝、紫、绿的大面积跳色**（玻璃绿叶是唯一的例外，且必须低饱和）。
- **低饱和 & 高通透**：玻璃靠"亮 + 透 + 金边"表现，不靠"艳"。避免荧光黄、避免塑料感的死黄。
- **面积分配**：纸面白/米白 55%–70% → 玻璃主体 20%–35% → 金色描边与光斑 5%–10%。
- **对比靠明度**：玻璃亮部与纸面接近时，用**金边 + 浅阴影 + 光斑**拉开层次，不要用加大饱和度解决。
- **文字承载区**：保持干净、低细节的米白纸面，保证叠加的精确文字有足够对比；文字区**不得被光斑打乱**。
- **品牌色**：若源海报有品牌色，允许以**低饱和的玻璃色**形式在主体上保留可识别度，不得改色系。
- **功能性资产区**：二维码/条码/logo 所在区域**不加光斑、不压金边、不加阴影**，保持干净的米白纸面以便原样贴回。
