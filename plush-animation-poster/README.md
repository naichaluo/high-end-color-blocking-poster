# Plush Animation Poster

把普通海报/产品描述/营销主视觉，重绘成**毛绒 / 羊毛毡定格动画**风格的广告：柔软纤维表面、手作微缩道具、温柔微距浅景深、温馨自然配色。

这是一个**独立** Skill，不与 `clay-animation-poster`、`torn-paper-relief-poster`、`paper-collage-poster`、`high-end-color-blocking-poster` 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。源海报只提供商业事实，本 skill 只涂毛绒视觉处理。
- **两层流程**：视觉层（毛毡背景、毛绒道具、针织细节、图标）与受控层（精确标题/价格/品牌/二维码/服务条款）分开；文字、logo、QR 用原素材叠加，不交给图像模型乱造。
- **毛绒风格**：羊毛毡/针织/绒球/绒毛纤维的软表面，圆润不规整轮廓，缝线/压合边缘，微型定格布光，浅景深——不是普通 3D 高光。
- **构图**：保留源海报的信息顺序和主布局逻辑（顶部品牌/标题 → 中部产品场景 → 优惠模块 → QR/行动区 → 服务/法务区），除非用户要求重设计。

## 配套文件

- `SKILL.md`: 核心规则、触发条件、工作流、质量门、污染检查、边界。
- `palettes.md`: 毛绒适配配色与材质处理。
- `prompt-templates.md`: 可复用提示词模板（风格迁移 / 纯视觉底图 / 从文案新做 / 校验清单）。
- `examples/`: 示例需求与提示词应用。

## 快速使用的三句话

1. 先用 `skill` 工具加载 `plush-animation-poster`。
2. 以原海报为参考图（`image`），提示词写「保留主体+全部文字，只改材质为毛绒定格动画」。
3. 出图后核对文字；若要求零误差，改用「去文字纯视觉底图 + 排版叠加文字」的两层方案。
