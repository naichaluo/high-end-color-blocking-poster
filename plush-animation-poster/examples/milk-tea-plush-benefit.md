# 示例：奶茶卖点海报 → 毛绒定格动画风

## Brief

- 产品：某奶茶（低温鲜奶 + 当季水果）
- 卖点：新鲜、自然、轻负担、好心情
- 品牌色：奶油白 + 薄荷绿 + 蜜桃粉
- 类型：竖版促销海报
- 需求：把普通奶茶海报重绘成毛绒定格动画风，保留原有文案与信息层级

## Locked (保留)

- 品牌名 / 文案 / 价格 / 优惠额度 / 图标 / 底部服务与法务信息
- 原有信息层级：顶部标题 → 中部奶茶场景 → 下方优惠模块 → 底部服务条

## Reinterpret (重释)

- 材质：羊毛毡 + 针织 + 绒球，软质微缩场景
- 场景：一只毛绒奶茶杯坐在毛毡小桌上，旁边是毛毡水果切片和绒球叶子，背景是淡绿毡墙
- 光：柔和的微缩影棚光，暖调，浅景深
- 隐喻：一杯「手作温暖的好心情」

## Plush Palette（Warm Milk-Tea Cream）

- 背景：黄油奶油 / 淡桃 / 燕麦
- 主体：奶白 / 焦糖 / 水果粉 / 蜂蜜
- 点缀：柔和可可 / 薄荷 / 缎带奶油
- 材质：针织杯套、毛毡蛋糕、绒布浆果、缝线细节

## Verdict

毛绒动画风只改变视觉语言——信息层级、文案、Logo、二维码、价格全部按源海报锁定，文字用精确叠加层处理，绝不让模型去重画商业文字。
