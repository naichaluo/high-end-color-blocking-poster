# 分层剪纸海报 · Palettes

**冷调艺术纸、一层一色、深度只靠阴影**。整个色盘的铁律是：

> **每一层都使用单一的、未经调和的颜色。**
> 深度通过**层间阴影**和**堆叠顺序**来表现，**绝不通过层内明暗变化来体现**。

## 色盘结构

| 层位 | 色（参考） | 说明 |
|---|---|---|
| **后层 · 天空** | 柔和奶油色 `#F0E7D6` | **画面上方 40% 的平坦天空背景层**，纯色不堆叠 |
| 远层 | 浅天蓝 `#A8C6D8` | 远处轮廓、远景块面 |
| 中远层 | 灰蓝绿 `#7C9A99` | 中景建筑/物体 |
| 中层 | 矿物蓝 `#5B7C9B` | 主要主体的主体色之一 |
| 中近层 | 暖砂岩色 `#CBB79B` | 近景建筑面、地面 |
| 近层 | 柔和珊瑚色 `#D79A86` | 前景小面积焦点、植物/器物 |
| **最外层 · 深色** | 深海军蓝 `#2B3A55` | 最外层的重量感与收边 |
| 前景切割边 | 深海军蓝 或 暖砂岩色 | **堆叠最前面的那道前景切割边缘**，用来收住整个堆叠 |

> 上方 hex 只是**参考锚点**，说明「冷调艺术纸」的区间。
> 实际取色以**源海报主体的识别色为本**，做**冷调化 + 艺术纸化**处理，**不改变色相归属**。

## 三套可直接选用的方案

### A. 七层标准配置（推荐起点）
柔和奶油（天空）→ 浅天蓝 → 灰蓝绿 → 矿物蓝 → 暖砂岩 → 柔和珊瑚 → 深海军蓝（最外 + 前景切割边）。
共约 7 张平面纸，冷调为主，暖砂岩与柔和珊瑚提供受光侧的少量温度。

### B. 蓝绿清冷版
柔和奶油（天空）→ 浅天蓝 → 灰蓝绿 → 矿物蓝 → 深海军蓝 → 灰蓝绿（回跳一层做近景）→ 深海军蓝。
更克制、更冷，适合主体本身偏冷色的产品与建筑。

### C. 砂岩暖光版
柔和奶油（天空）→ 暖砂岩 → 浅天蓝 → 灰蓝绿 → 矿物蓝 → 柔和珊瑚 → 深海军蓝。
暖砂岩比例提高，但**最外层仍是深海军蓝收边**，保证冷调骨架不散。

## 用色规则

- **一层一色，未调和**：不允许某一层内部出现两个色相或明暗渐变。
- **深度不靠色**：不要用「越远越浅、越近越深」的空气透视来造深度——那是**大气雾霾**，本风格禁止。深度靠**物理间隔 + 层间阴影**。
- **层数 6–8**：少于 6 层会失去堆叠感，多于 8 层会失去「单色干净」的气质。
- **主体色准**：主体（产品 / 门店 / 建筑 / 场景）的实际颜色保留源海报主要色彩信息，只做冷调化与艺术纸化。
- **品牌色**：以可识别的方式落在对应的一整层上（例如品牌主色 = 主体那一层），**不跨层杂糅**。
- **天空层永远是最靠后的那一层**，纯柔和奶油色、低细节。
- **系列一致性**：同一批海报必须使用**同一套色彩方案**，这是系列作品浑然一体的关键。
- **文字承载区**：标题区、卖点条、行动区落在**未切割的单色纸面**上，保证叠加文字的对比度。

## 光线与阴影规则（最关键）

| 项 | 规则 |
|---|---|
| 光源 | **柔和地从左上角照射**，均匀地分布在所有纸层上 |
| 阴影位置 | **只在层与层之间**——上层投向后层的投影，表现为后层表面上的柔和暗带 |
| 阴影性质 | **柔和、漫射、短暂**；**轻柔，绝不生硬** |
| 层内 | **不得出现阴影，不得出现渐变**（一层纸就是一个纯色平面） |
| 硬阴影 | **完全禁止** |
| 深度来源 | **层间阴影 + 堆叠顺序**，除此之外没有别的深度要素 |
| 层间缝隙 | 缝隙处呈现**柔和的自然光晕**（纸张极薄，光从缝里透出） |
| 纸张厚度 | 每层顶部边缘**只有纸张厚度的痕迹反射光线** |

## 艺术纸材质

- **哑光艺术纸表面**：无反光、无塑料感、无金属感。
- **纤维纹理**：每一层都可见**细腻均匀的纤维纹理**。
- **切割边**：**干净、利落、清晰**——这是本风格最重要的触感来源。
- **禁止**：老化纸张、棕色滤镜、棕褐色调、泛黄、撕裂边缘、褶皱、闪光/金粉、霓虹色、金色。
