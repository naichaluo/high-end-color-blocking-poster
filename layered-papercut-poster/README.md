# Layered Papercut Poster / 分层剪纸海报

把普通海报 / 产品描述 / 营销主视觉，重绘成 **触感丰富的分层剪纸（layered paper-cut）海报**。

**最终效果**：像一张**由多层剪纸堆叠而成、单侧柔和打光的照片**——立体感强，却柔和精致。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `paper-collage-poster`（纸艺拼贴）、`papercraft-travel-diorama`（纸艺旅行微缩立体场景）、`torn-paper-relief-poster`（撕纸浮雕）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **主体 70% / 剪纸层叠 30%**：把源海报的**唯一视觉主体**（产品 / 门店 / 建筑 / 场景）当作海报的“地标”；**每个主体占用单独的纸张层**；主体**保留现实轮廓与基本比例，并主导周围的一切**；**简化表面细节，但绝不简化结构**。
- **6–8 层单色纸**：画面由 **六到八层**不同深度的剪纸构成，**每一层都是单一的、未经调和的颜色**，前后堆叠，**彼此之间有真实的物理间隔**。
- **⭐ 阴影是唯一的深度要素**：每层向**后层**投射**柔和、漫射、短暂**的阴影（**轻柔，绝不生硬**）；**层内不得有阴影、不得有渐变**——一层纸就是一个纯色平面。
- **无透视、无大气雾霾、无渲染**：深度**只**由**堆叠顺序 + 层间阴影**给出。
- **⭐ 一切都是切割边 + 切割孔洞**：每一处边缘都是**干净利落的切割边**，只有**纸张厚度的痕迹在顶部边缘反光**；细节靠**切割孔洞**（窗洞、拱形、结构肋条、栏杆缝隙）**露出后层**，而不是画上去的。
- **光从左上**：柔和地从左上角照射，均匀分布在所有纸层上。
- **构图**：上方 **40% 为平坦天空背景层**；主体在画面中下方构建；次要元素按**从后向前**落层（远处轮廓 → 近处物体 → 树木/前景植物 → 地面/水体），**最前面放一道前景切割边缘**。
- **标题**：上方中心、**单独切割**的大写无衬线字形、**宽字距**、**略微位于天空层前方**，并投出**与其他景物相同的柔和阴影**。
- **配色**：冷调艺术纸——矿物蓝、灰蓝绿、浅天蓝、暖砂岩、柔和珊瑚、深海军蓝（外层）+ 柔和奶油色（后层天空），**约 7 张平面纸**，**每层单一未调和颜色**。
- **质感**：哑光艺术纸、细腻均匀纤维纹理、切割边清晰、纸张极薄、层间缝隙柔和自然光晕；**干净现代、无做旧**。
- **画布**：保留源海报**原始尺寸与宽高比**（docx 原规格 2:3 竖版，但以源海报实际比例为准，不裁切不拉伸）。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**。
- **标题区改写规则**：docx 原文的「［城市名称］」位 → 对应为**源海报标题区**，排版形式保留；**文字内容一律用源海报自身文案，不编造城市名/地名/装饰性英文标题**。
- **功能性资产保护**：二维码、条码、logo 必须**完整、可识别、可扫描**——**不得切割、不得镂空、不得当成孔洞处理、不得被纸层覆盖或错位**。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：冷调艺术纸色盘、每层单色规则、层间阴影与光线规则、艺术纸材质。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 与其他纸艺 skill 的区别（最常被混淆）

| skill | 逻辑 | 深度来源 | 边缘 |
|---|---|---|---|
| **本 skill**：分层剪纸 | **6–8 整层单色纸前后堆叠** | **层间柔和阴影 + 堆叠顺序**（无透视无雾霾） | **干净切割边** |
| `paper-collage-poster`：纸艺拼贴 | **碎纸片拼成**主体 | 纸片重叠 | **撕裂、翘起、错位** |
| `papercraft-travel-diorama`：纸艺微缩立体 | **手工纸模型微缩场景**（舞台 + 立体小建筑） | 模型透视 + 浅景深摄影 | 手工模型边 |
| `torn-paper-relief-poster`：撕纸浮雕 | 撕裂纸张浮雕 | 纸张厚度浮雕 | **撕裂边**（本 skill 禁止撕裂） |

## 快速上手

1. 先 `skill` 加载 `layered-papercut-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板，并明确写出「哪些结构必须在简化中保留」。
3. 出图后按自检表核对：**层数与单色**、**层间柔和阴影是否唯一深度来源**、**是否无透视无雾霾**、**是否全部为切割边**、**细节是否为切割孔洞**、**标题是否单独切割且投出相同阴影**、**二维码是否未被切割**。
4. 要文字零误差就用两层流程：出纯视觉底图（标题区/卖点条/QR 区留干净纯色纸面）→ 排版叠回原文字与二维码。
