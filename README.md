# Poster Design Skills

两个可独立复用的广告海报设计 Skill：

## 1. High-End Color-Blocking Poster

高级感撞色海报：受控的 2–3 色配色、大色块、大留白、现代编辑排版与轻微纸张印刷质感。

- [查看 Skill](high-end-color-blocking-poster/SKILL.md)
- [查看使用说明](high-end-color-blocking-poster/README.md)

## 2. Paper Collage Poster

剪纸 / 纸艺拼贴广告海报：通过分层纸张、裁切边缘、纸纤维与投影，将普通海报转化为纸艺广告创意。

- [查看 Skill](paper-collage-poster/SKILL.md)
- [查看参考方法](paper-collage-poster/references/paper-collage-poster-method.md)

两个 Skill 相互独立，可以分别安装和调用；除非明确要求，不会自动叠加使用。
