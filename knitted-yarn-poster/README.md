# Knitted Yarn Poster / 针织毛线艺术海报

把普通海报/产品描述/营销主视觉，重绘成 **针织毛线手工艺术风**广告：**整个画面全部由粗毛线、钩针编织、绒线手工制作而成**。

**🅰 核心原则：只取材质与风格，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `plush-animation-poster`（毛绒/羊毛毡）、`fabric-patchwork-poster`（布艺拼接）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **全部毛线化**：画面里每一个物体、人物、景物都是毛线钩织而成——产品、水果、吉祥物、植物、道具、装饰，全部是钩针/棒针作品。
- **清晰线圈纹理**：看得见一针一针的线圈（V 形针脚）、辫子针边缘、起针/收针痕迹、缝合接口。
- **纱线毛絮**：毛线表面有细密绒毛与飞絮，轮廓边缘带毛茸茸的光晕。
- **手工布艺质感**：填充饱满、轻微不规整，针距有变化，收口留手工痕迹。
- **柔和室内柔光** + **干净浅米色背景** + **静物俯拍（平铺）**。
- **精致手工艺术品 / 高级质感 / 超高细节**：像被精心拍摄的高级手工艺术作品，不是儿童手工或毛线玩具。
- **画布**：保留源海报**原始尺寸与宽高比**；中央紧凑针织静物组合占宽高 **72%–78%**，四边连续近等宽留白。
- **信息层级**：保留源海报顺序与主布局（品牌/标题 → 产品场景 → 优惠模块 → QR/行动区 → 服务/法务区），并留出平静低细节区供精确文字叠加。
- **两层流程**：视觉层（毛线场景、道具、线圈质感）与受控层（精确标题/价格/券额/品牌/二维码/服务条款）分开；文字、logo、QR 用原素材叠加。
- **必须保留文字**：不得把源海报文字与 Logo 化为不可读色块，不得删改价格、券额、日期、电话、URL、二维码或法务字样。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。
- **禁止**：动漫、扁平矢量、3D 渲染、塑料玩具感、羊毛毡（needle-felt）、拼布绗缝、模糊滤镜、水印、把文字变成色块。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：浅米底色 + 从源海报提取的毛线色盘。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `knitted-yarn-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：毛线化是否彻底、线圈与毛絮是否可见、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图 → 排版叠回原文字与二维码。
