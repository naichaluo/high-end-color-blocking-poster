# 针织毛线 · Palettes

底色固定为**干净浅米色**；毛线颜色从源海报提取，**品牌色必须保留可识别**。

## 底色

| 色 | 说明 |
|---|---|
| 浅米 / 象牙 | 背景平底色，干净素净、无杂物；也是文字待叠区的承载色 |

## 毛线色（从源海报提取）

| 角色 | 说明 |
|---|---|
| 品牌主色 | 源海报的品牌色，用**毛线**呈现，必须保留可识别 |
| 品牌辅助色 | 源海报的辅助色，同样毛线化 |
| 中性毛线 | 奶油、燕麦、浅驼、灰米——用于填充与过渡，让画面有呼吸 |
| 深色毛线 | 深驼、炭灰、深棕——用于轮廓、深色物件、文字承载区的对比 |
| 点缀毛线 | 源海报里的高饱和小面积色（朱红、姜黄、苔绿、藏蓝等），只做小面积焦点 |

## 用色规则

- 毛线颜色**取自源海报**，不引入原图没有的色系。
- 每团毛线颜色**纯粹、不混浊**，靠线圈纹理表现明暗，而不是靠加黑或加深。
- 深色毛线不要大面积铺满；主要面积留给浅色毛线，保持"干净浅米 + 柔和"的整体气质。
- **文字承载区**：用浅米/奶油毛线的低细节平区，或直接留出干净的浅米底，保证叠加的精确文字有足够对比。
- 若品牌色是高饱和色，把它限制在一个主焦点（如产品主体），其余退到中性毛线色。
