# Lace Embroidery Poster / 蕾丝刺绣海报

把普通海报/产品描述/营销主视觉，重绘成一张 **温柔精致的复古手工蕾丝海报**：**温暖白色做旧纸张**背景上，一块由**白色镂空蕾丝布料裁剪而成**的**蕾丝框**——边缘有**针孔、花边与浅浮雕阴影**；框内嵌着一幅**迷你花卉小画**（淡蓝花朵蓝白渐变、花朵微微凸起、浅绿枝叶是刺绣），像嵌在框中的迷你花卉刺绣作品；画面**上下点缀大型立体蕾丝英文字母**，字母像**白色蕾丝布料拼贴在纸面**上，带**细腻针孔纹理与柔和阴影**；**底部是细小装饰文字位**。竖版 3:4，**柔和自然光、浅阴影、构图干净高级**。

**最终效果**：像一件手工蕾丝作品贴在旧纸上——温柔、精致、复古、手工感强、干净高级。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `fabric-patchwork-poster`（布艺拼接）、`felt-floral-poster`（毛毡花卉）、`paper-collage-poster`（纸艺拼贴）、`torn-paper-relief-poster`（撕纸浮雕）、`knitted-yarn-poster`、`crystal-glass-floral-poster` 或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：主体身份、花卉种类与花朵结构、姿态、空间关系、主要构图与视觉焦点**严格保留**；主体身份不换，**只把表现材质换成蕾丝与刺绣**。
- **背景**：**温暖白色做旧纸张**——细腻纸纤维、轻微颗粒、淡淡做旧；**不要水渍污渍、不要重做旧、不要折痕**。
- **蕾丝框（核心）**：由**白色镂空蕾丝布料裁剪而成**——可见**镂空网眼 + 克制的蕾丝花型**；边缘有**细密针孔**与**波浪/小齿花边**；**浅浮雕阴影**、像真布片贴上去**微微凸起**。**不要**粗木框/金属框/塑料相框/双线纸框。
- **框内小画（核心）**：**一幅**迷你花卉小画——**蓝白渐变花瓣**、花心略深、**花朵微微凸起**、**浅绿色刺绣叶片**（可见绣线与针脚方向）；框内底色温暖白、干净低细节。只有一幅小画、一个焦点。
- **蕾丝字母（核心）**：**上下各一组大型立体蕾丝字母**，字形内有**网眼与花型**、边缘有**针孔**、**微微凸起**带**柔和阴影**；白色蕾丝布感，**不描黑边、不做金属/塑料/玻璃质感、不发光**。
- **光影**：**柔和自然光、浅阴影**；无硬阴影、无强方向光。
- **版式**：竖版 3:4 上下—中心布局：上方字母 → 中部蕾丝框 → 下方字母 → 最底部细小装饰文字位；左右基本对称、边距从容。
- **配色纪律**：以**白与暖白**为主；唯一彩色是框内低饱和**淡蓝花朵 + 浅绿枝叶**；**无第三种抢眼杂色**；不要与结构无关的**竖向装饰条/竖纹**。
- **文字内容**：蕾丝字母位与底部装饰文字位**保留排版形式**，文字内容用**源海报自身的标题、主体名或自带文案（逐字）**；**不虚构**花名、系列名、年份、署名；**不加** `prompt by awen` 之类署名。
- **蕾丝字母不得替代源海报的商业文案**：源海报原有的标题、卖点、价格必须仍然存在且可读。
- **画布**：保留源海报**原始尺寸与宽高比**；3:4 仅在源海报本身约为 3:4 或用户明确要求时使用。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**。
- **功能性资产**：二维码/条码/logo 必须**完整、可识别、可扫描**，不得被网眼、针孔、花边或阴影覆盖/错位/虚化；其所在区域保持干净平整的暖白纸面。
- **留白靠布局，不靠删信息**：不得为了"干净高级"删减必需信息。
- **材质边界**：不要毛毡毛绒、不要线圈/钩针、不要碎花布印花、不要拼布、不要毛边散线、不要明线针脚、不要纽扣/流苏、不要剪纸纸片、不要撕纸边、不要玻璃折射与金边。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度、花种。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：暖白纸 × 纯白蕾丝色盘、蕾丝/刺绣材质与光影处理。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + Style preset + 出图前自检表 + 常见失败修法。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `lace-embroidery-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：蕾丝是否有网眼/针孔/花边、框内是否只有一幅刺绣小画、上下蕾丝字母是否"像布贴上去"、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图（字母位、底部装饰位、正文与二维码区留成干净暖白纸面）→ 排版叠回原文字与二维码。
