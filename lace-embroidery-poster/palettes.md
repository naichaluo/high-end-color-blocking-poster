# 蕾丝刺绣海报 · Palettes

**暖白做旧纸 × 纯白镂空蕾丝 × 淡蓝花朵 × 浅绿刺绣枝叶**。整体是**低饱和、温柔、干净**的手工配色：画面以白与暖白为主，彩色只出现在框内那幅迷你花卉小画上，且必须压得很轻。

## 色盘

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 温暖白（纸底） | `#F7F2E9` / `#FAF6EF` | 背景 | 画面**最大面积**；暖白偏米，有细腻纸纤维与淡淡做旧 |
| 纸面做旧痕 | `#EFE7DA` | 纸底层次 | 极浅的不匀与旧痕，**克制**，不要污渍水渍 |
| 纯白蕾丝 | `#FFFFFF` / `#FDFCFA` | 蕾丝框、蕾丝字母 | 主体结构色；靠**网眼、针孔、厚度与阴影**与纸面区分，**不靠描边** |
| 极浅暖灰 | `#E7E1D6` | 浅浮雕阴影 | 蕾丝框、字母下方与内侧的**浅阴影**，透明度低（约 6%–12%） |
| 淡蓝（花瓣） | `#BFD8EA` → `#E8F1F8` | 框内花朵 | **蓝白渐变**：花瓣根部偏蓝、边缘趋于白 |
| 淡蓝灰（花心） | `#A8C6DC` | 框内花朵 | 花心略深，**面积很小** |
| 浅绿（刺绣枝叶） | `#A9C3A2` / `#9BB894` | 框内叶片 | 浅绿色**绣线**枝叶，可见针脚方向 |
| 深一档浅绿 | `#8AA983` | 枝叶层次 | 只用于绣线层次，面积小 |
| 细小装饰文字 | `#8A8073` | 底部文字 | 暖灰褐，极小号，低调不抢视觉 |

**主体色准优先**：框内主体的实际颜色（源海报的花色、产品色、品牌色）要保留源海报的主要色彩信息，只做**低饱和化 + 刺绣化**处理（降纯度、加柔、转为绣线质感），**不改变色相归属、不换色系**。

## 材质

### 白色镂空蕾丝布料（核心材质）

- **镂空网眼**：hexagonal / net mesh，网孔均匀细密，能透过网眼看到底下的暖白纸面。
- **蕾丝花型纹样**：花卉或几何花窗式纹样，**克制、不繁复**，不要满铺到没有呼吸。
- **针孔**：边缘一圈细密小圆孔，像裁片时的针脚痕。
- **花边**：scalloped / picot 波浪或小齿状花边，边缘柔软。
- **浅浮雕**：布片**微微凸起**，下方与内侧有浅阴影——是"贴上去的布"，不是印上去的图案。
- **不要**：粗木框/金属框/塑料相框、双线纸框、描黑边、印花布图案、明线缝合、毛边散线、纽扣、流苏。

### 刺绣（框内小画）

- **绣线可见**：花瓣与叶片的颜色由绣线堆出，可见细密针脚与走线方向。
- **花朵微微凸起**：有刺绣的浅浮雕厚度，不是平面色块。
- **花瓣蓝白渐变**：根部略蓝、边缘趋白；**花心**略深。
- **叶片为浅绿色刺绣**：走线顺叶脉方向，**不要**写实油画叶片。

### 蕾丝字母

- 字母字形内部是**蕾丝网眼与花型**，边缘有**针孔纹理**；
- 整体**微微凸起**（像一层薄蕾丝布贴在纸面），带**柔和阴影**；
- **白色**，靠网眼、针孔、厚度、阴影与纸面区分；**不描黑边、不做金/银/金属/塑料/玻璃质感、不发光**。

### 纸面

- 温暖白做旧纸：细腻纸纤维、轻微颗粒、淡淡做旧（轻微不匀、极浅旧痕）。
- **保持干净**：不要水渍、不要污渍、不要重做旧、不要折痕、不要撕边。

## 用色规则

- **白主体、淡彩点缀**：纯白蕾丝与暖白纸是主对比；彩色只出现在框内小画（淡蓝 + 浅绿），**面积 ≤10%**。
- **低饱和**：避免荧光、艳俗、高饱和跳色；避免把蕾丝做成彩色布。
- **面积分配**：暖白纸 60%–75% → 白色蕾丝框与字母 15%–30% → 框内淡蓝花朵 5%–10% → 浅绿枝叶 ≤5%。
- **对比靠结构与阴影**：白色对白色时，用**网眼、针孔、浅浮雕阴影**拉开层次，**不要**加大饱和度或描深边。
- **禁止杂色**：除白色蕾丝与暖白纸之外不出现第三种抢眼杂色；**不要**出现多余的白色竖条纹、竖向装饰条、竖向文字块等与结构无关的竖向元素。
- **文字承载区**：保持干净、低细节的暖白纸面，**不压蕾丝花型、不加网眼、不加阴影**，保证叠加的精确文字有足够对比。
- **功能性资产区**：二维码/条码/logo 所在区域保持**干净平整的暖白纸面**——不加网眼、不加针孔、不加花边、不加阴影，以便原样贴回。
