## 常见失败与修法

| 症状 | 修法 |
|---|---|
| 蕾丝变成印花布 | 明确"镂空网眼 + 针孔 + 花边 + 浅浮雕"，加 `openwork lace net mesh, pin holes, scalloped edging, low relief` |
| 一片白糊在一起 | 保留白色但要求"靠网眼、针孔、浅浮雕阴影与厚度拉开层次"，并加"浅阴影"而不是加描边 |
| 蕾丝被描了黑边 | 明确"白色蕾丝字母不描黑边、不做金属/塑料质感"，用针孔与阴影代替轮廓线 |
| 框内出现写实照片花卉 | 明确"迷你花卉**刺绣**小画：绣线可见、花朵微微凸起、叶片为浅绿刺绣" |
| 出现碎花布/拼布/明线 | 加 `no floral print fabric, no patchwork, no visible stitching seams, no buttons, no frayed edges` |
| 画面出现杂色 | 明确"以白与暖白为主，唯一彩色是框内低饱和淡蓝与浅绿，不得出现第三种抢眼杂色" |
| 冒出多余的白色竖条/竖纹 | 明确"不要出现与结构无关的竖向装饰条、竖纹、竖向文字块" |
| 蕾丝字母顶替了源海报标题 | 明确"蕾丝字母不得替代或遮挡源海报的商业文案"，并把源海报原文逐字钉进提示词 |
| 二维码被网眼糊掉 | 二维码区单独声明"干净平整暖白纸面，无网眼无针孔无阴影"，并用原素材叠回 |
