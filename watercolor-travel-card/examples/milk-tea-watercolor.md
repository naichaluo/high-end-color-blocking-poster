# 示例：奶茶卖点海报 → 水彩旅行卡片风

## Brief

- 产品：某奶茶（低温鲜奶 + 当季水果）
- 卖点：新鲜、自然、轻负担、好心情
- 品牌色：奶油白 + 薄荷绿 + 蜜桃粉
- 类型：竖版促销海报
- 需求：把普通奶茶海报重绘成水彩旅行卡片风，保留原有文案与信息层级

## Locked (保留)

- 品牌名 / 文案 / 价格 / 优惠额度 / 图标 / 底部服务与法务信息
- 原有信息层级：顶部标题 → 中部奶茶场景 → 下方优惠模块 → 底部服务条

## Reinterpret (重释)

- 材料：暖象牙冷压纸 + 透明水彩 + 细钢笔线
- 场景：奶茶杯做成透明水彩主件，右侧一条旅行档案栏（圆孔打孔撕页），左侧水彩晕染留白
- 隐喻：一杯「被旅行记忆收藏的清甜」

## Palette (Moss And Rice)

- 纸张：暖象牙棉纸
- 水彩：鼠尾草绿 / 苔绿 / 暖燕麦
- 点缀：杏色 / 奶油 / 灰紫
- 细节：水痕、颜料沉降、轻微未完成边缘

## Verdict

水彩风只改变视觉语言——信息层级、文案、Logo、二维码、价格全部按源海报锁定，文字用精确叠加层处理，绝不让模型去重画商业文字。
