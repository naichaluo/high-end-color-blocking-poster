# Watercolor Travel Card

把普通海报/产品描述/营销主视觉，重绘成**水彩旅行卡片**风格的广告：透明水彩 + 细钢笔线 + 右侧旅行档案栏（圆孔打孔撕页），安静、通透、克制、独立的旅行手账感。

这是一个**独立** Skill，不与 `impasto-miniature-landscape`、`isometric-healing-blocks`、`papercraft-travel-diorama`、`pixel-dissolve-landscape`、`observational-pen-wash` 等合并规则，除非用户明确要求组合风格。

## 关键点

- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。源海报只提供商业事实，本 skill 只涂水彩视觉处理。
- **两层流程**：视觉层（水彩场景、钢笔线主件、档案栏）与受控层（精确标题/价格/品牌/二维码/服务条款）分开；文字、logo、QR 用原素材叠加，不交给图像模型乱造。
- **风格**：暖象牙冷压纸 + 透明水彩（颜料沉降、水痕、留白高光）+ 细钢笔线 + 打孔档案栏。不是水粉、油画、卡通、塑料3D。
- **构图**：保留源海报信息顺序和主布局逻辑，留出平静纸面给标题与文字。

## 配套文件

- `SKILL.md`: 核心规则、触发条件、工作流、质量门、污染检查、边界。
- `palettes.md`: 水彩旅行卡片配色与材质处理。
- `prompt-templates.md`: 可复用提示词模板（风格迁移 / 纯视觉底图 / 从文案新做 / 校验清单）。
- `examples/`: 示例需求与提示词应用。

## 快速上手的四句话

1. 先 `skill` 加载 `watercolor-travel-card`。
2. 以原海报为参考图（`image`），提示词写「保留主体+全部文字，只改材质为水彩旅行卡片」。
3. 出图后核对文字。
4. 要零误差就用两层流程：纯水彩视觉底图 + 排版叠回原文字。
