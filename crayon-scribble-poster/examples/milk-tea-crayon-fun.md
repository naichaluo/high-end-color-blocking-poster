# 示例：奶茶卖点海报 → 蜡笔涂抹手绘风

## Brief

- 产品：某奶茶（低温鲜奶 + 当季水果）
- 卖点：新鲜、自然、轻负担、好心情
- 品牌色：奶油白 + 薄荷绿 + 蜜桃粉
- 类型：竖版促销海报
- 需求：把普通奶茶海报重绘成蜡笔涂抹手绘风，保留原有文案与信息层级

## Locked (保留)

- 品牌名 / 文案 / 价格 / 优惠额度 / 图标 / 底部服务与法务信息
- 原有信息层级：顶部标题 → 中部奶茶场景 → 下方优惠模块 → 底部服务条

## Reinterpret (重释)

- 材料：蜡笔 + 纸纹，粗线立体涂抹、叠色、留白
- 场景：一只蜡笔涂的奶茶杯站在暖奶油纸上，旁边画一个蜡笔太阳、几片涂鸦叶子、洒几颗星星
- 笔触：粗犷自信的叠色涂抹，略带不规整的蜡笔边，充满童趣能量
- 隐喻：一杯「画出来的快乐好心情」

## Palette (Fresh Fruit Pop)

- 纸张：暖米白 / 淡桃
- 蜡笔：青柠绿 / 橘子橙 / 莓果粉 / 明黄
- 点缀：白高光 / 深青绿描边
- 细节：柑橘切片涂鸦、叶子笔刷、弹跳记号

## Verdict

蜡笔风只改变视觉语言——信息层级、文案、Logo、二维码、价格全部按源海报锁定，文字用精确叠加层处理，绝不让模型去重画商业文字。
