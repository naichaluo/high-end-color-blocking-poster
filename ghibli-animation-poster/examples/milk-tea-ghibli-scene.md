# 示例：奶茶卖点海报 → 吉卜力手绘动画风

## Brief

- 产品：某奶茶（低温鲜奶 + 当季水果）
- 卖点：新鲜、自然、轻负担、好心情
- 品牌色：奶油白 + 薄荷绿 + 蜜桃粉
- 类型：竖版促销海报
- 需求：把普通奶茶海报重绘成吉卜力手绘动画风，保留原有文案与信息层级

## Locked (保留)

- 品牌名 / 文案 / 价格 / 优惠额度 / 图标 / 底部服务与法务信息
- 原有信息层级：顶部标题 → 中部奶茶场景 → 下方优惠模块 → 底部服务条

## Reinterpret (重释)

- 材料：水彩 + 喷枪手绘，柔和晕染、纸纹颗粒
- 场景：奶茶杯放在一个洒满阳光的草坡小茶馆前，远处是软丘与积雨云，一杯热饮冒着暖雾
- 光：午后暖阳 + 柔和光斑 + 轻薄雾气，温馨治愈
- 隐喻：一杯「被阳光吻过的自然好心情」

## Palette (Sunlit Meadow Green)

- 天空：淡粉蓝 / 奶油云
- 地面：暖草绿 / 金黄麦浪 / 象牙小径
- 点缀：柔和矢车菊 / 暖赭 / 蜂蜜黄
- 材质：蓬松云朵、野花点、远山、小木屋

## Verdict

吉卜力风只改变视觉语言——信息层级、文案、Logo、二维码、价格全部按源海报锁定，文字用精确叠加层处理，绝不让模型去重画商业文字。
