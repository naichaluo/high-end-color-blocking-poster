# Ghibli Animation Poster

把普通海报/产品描述/营销主视觉，重绘成**吉卜力式手绘动画**风格的场景：水彩喷枪晕染、柔和天光、田园怀旧、温馨治愈的绘本质感。

这是一个**独立** Skill，不与 `plush-animation-poster`、`clay-animation-poster`、`torn-paper-relief-poster`、`paper-collage-poster`、`high-end-color-blocking-poster`、`crayon-scribble-poster` 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。源海报只提供商业事实，本 skill 只涂手绘动画视觉处理。
- **两层流程**：视觉层（手绘风景、产品道具、云朵、枝叶）与受控层（精确标题/价格/品牌/二维码/服务条款）分开；文字、logo、QR 用原素材叠加，不交给图像模型乱造。
- **风格**：水彩/喷枪手绘、透明晕染、柔雾光斑、田园怀旧、纸纹颗粒——不是照片渲染或扁平矢量。
- **构图**：保留源海报信息顺序和主布局逻辑，留出平静的天空/地面留白区给标题与文字。

## 配套文件

- `SKILL.md`: 核心规则、触发条件、工作流、质量门、污染检查、边界。
- `palettes.md`: 水彩/田园配色与材质处理。
- `prompt-templates.md`: 可复用提示词模板（风格迁移 / 纯视觉底图 / 从文案新做 / 校验清单）。
- `examples/`: 示例需求与提示词应用。

## 快速使用的三句话

1. 先用 `skill` 工具加载 `ghibli-animation-poster`。
2. 以原海报为参考图（`image`），提示词写「保留主体+全部文字，只改材质为吉卜力手绘动画」。
3. 出图后核对文字；若要求零误差，改用「去文字纯视觉底图 + 排版叠加文字」的两层方案。
