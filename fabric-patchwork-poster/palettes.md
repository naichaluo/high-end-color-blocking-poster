# Fabric Patchwork Poster Palettes

Use these fabric palettes to translate the source poster's colors into cloth materials while keeping the brand's recognizable color signal. Do not override official brand colors when they are content-critical.

## Sage And Brick

Best for lifestyle, home, food, and warm everyday campaigns.

- base cloth: off-white linen, natural canvas
- patch fabric: sage green, brick red gingham, cream floral print
- accents: muted terracotta, tan twine, soft brown thread
- mood: warm, homey, gentle
- detail: frayed edges, running stitches, fabric buttons

## Lilac And Cream

Best for tea, bakery, gift, and cozy member offers.

- base cloth: warm cream linen, pale oat
- patch fabric: dusty lavender, milky white, soft peach
- accents: cocoa thread, cream ribbon, tiny bow
- mood: sweet, soft, nostalgic
- detail: heart shapes, round buttons, cross-stitch marks

## Moss And Honey

Best for green tea, natural, wellness, and organic campaigns.

- base cloth: pale celadon, natural canvas
- patch fabric: moss green, honey gold, warm oat
- accents: dark olive thread, twine, small felt leaf
- mood: calm, organic, grounded
- detail: stitched leaves, frayed weave, patch pockets

## Charcoal And Mustard

Best for premium, artisanal, and modern-craft campaigns.

- base cloth: charcoal canvas, grey denim
- patch fabric: mustard, slate blue, natural ecru
- accents: white running stitch, brass button, string
- mood: crafted, considered, warm-cool
- detail: square buttons, sharp stitch lines, woven texture

## Palette Rules

- Keep the source brand's recognizable color signal, expressed as cloth color.
- Use 2-4 complementary fabrics plus a neutral base cloth.
- Keep a matte woven surface and soft natural light so text stays readable.
- Add a stitch/thread accent color and one button or string detail for warmth.
- If text is overlaid later, reserve a calmer, lower-detail fabric zone behind it.
