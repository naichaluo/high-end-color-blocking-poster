# 示例：奶茶卖点海报 → 布艺拼接裁剪手缝风

## Brief

- 产品：某奶茶（低温鲜奶 + 当季水果）
- 卖点：新鲜、自然、轻负担、好心情
- 品牌色：奶油白 + 薄荷绿 + 蜜桃粉
- 类型：竖版促销海报
- 需求：把普通奶茶海报重绘成布艺拼接裁剪手缝风，保留原有文案与信息层级

## Locked (保留)

- 品牌名 / 文案 / 价格 / 优惠额度 / 图标 / 底部服务与法务信息
- 原有信息层级：顶部标题 → 中部奶茶场景 → 下方优惠模块 → 底部服务条

## Reinterpret (重释)

- 材料：棉麻 + 格纹 + 碎花布拼贴，毛边流苏、手缝虚线、布艺纽扣
- 场景：奶茶杯做成布贴主件，坐在一块绗缝布面上；旁边几块碎花布、格纹布、一个布纽扣和一颗布爱心
- 缝线：沿布块边缘一圈白色手缝线，针距不一；局部交叉缝/锁针
- 隐喻：一杯「一针一线缝出的温暖好心情」

## Palette (Lilac And Cream)

- 底布：暖奶油亚麻 / 淡燕麦
- 拼布：薰衣草紫 / 奶白 / 淡蜜桃
- 点缀：可可色线 / 奶油缎带 / 小蝴蝶结
- 细节：布爱心、圆扣、交叉缝记号

## Verdict

布艺风只改变视觉语言——信息层级、文案、Logo、二维码、价格全部按源海报锁定，文字用精确叠加层处理，绝不让模型去重画商业文字。
