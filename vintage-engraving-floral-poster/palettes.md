# 复古刻版画花卉 · Palettes

**低饱和、冷调、做旧的植物图鉴配色**。整个画面只由「墨绿灰线的排线」+「浅豆绿米白的做旧纸底」+「淡绿细线相框」三层构成，克制到几乎没有第四种颜色。

## 色盘

| 色 | 角色 | 说明 |
|---|---|---|
| 浅豆绿米白 | 纸底 | 画面**最大面积**；做旧纸张的底色，偏冷偏灰 |
| 米白 / 象牙白 | 纸底提亮 | 纸底的亮部，让高光处的排线几乎消失 |
| 墨绿灰 | 排线主线 | 主体的**唯一**线稿颜色；深、灰、偏冷，不是纯黑 |
| 深墨绿 | 排线暗部 | 花瓣褶皱最深处、花心、叶隙——靠**加密排线**而非换色得到 |
| 翠绿（低饱和） | 叶片 | 叶片的绿，压灰压暗，与墨绿灰线自然衔接 |
| 浅豆绿 / 淡绿 | 相框线 | **双层细线**复古相框，比纸底略深一点点 |
| 极淡灰绿 | 阴影/纸斑 | 做旧斑驳、纸张不均匀色斑、细微投影 |

**色彩纪律**：

- 主体**不填色**——体积**全部靠线条疏密**表现；允许极少量淡墨/淡色薄罩统一重心，但**不得成为主色面**。
- 严禁高饱和、鲜艳、荧光、暖橙、玫红——会出现"彩铅插画感"，破坏版画气质。
- 严禁纯黑粗描边：线条是**墨绿灰**的钢笔线，不是黑马克笔。

## 排线语言（材质核心）

**墨绿灰调钢笔排线线稿** + **细腻素描排线纹理**：

| 技法 | 用途 |
|---|---|
| 平行排线（hatching） | 花瓣的基础明暗，线距均匀、方向顺花瓣走向 |
| 交叉排线（cross-hatching） | 褶皱转折处、花心、叶隙的最深暗部 |
| 短线 / 破线 | 花瓣卷边边缘、叶尖，让轮廓透气 |
| 点刻（stipple） | 花蕊、细小过渡面，避免出现灰色平涂 |
| 疏线 / 断线 | 高光处，排线几乎消失，露出纸底本色 |

**体积规则**：亮部线稀 ← → 暗部线密；转折处加密；**体积靠排线密度而非灰色涂抹**。禁止柔和渐变、喷枪、写实阴影。

## 纸底做旧

- 淡雅**浅豆绿米白**做旧纸张：冷、灰、低饱和；
- 纸面质感：细微**纸张纤维**、**斑驳**、淡淡的岁月痕迹、**轻微不均匀色斑**；
- 边界纪律：**不要**重污渍、不要撕边、不要焦边、不要水渍流痕——是**老图鉴的书页**，不是烧焦的旧信；
- 做旧强度以**不干扰文字可读性**为准；二维码/条码/logo 区域必须保持干净（见 SKILL.md 的功能性资产保护条款）。

## 相框

- **双层淡绿细线条复古相框**：外线 + 内线，两层**间距克制**，四边等距；
- 线条**细**、颜色**淡**（比纸底略深一档），**不抢主体**；
- **禁止**：粗重金框、繁复花角纹样、立体阴影、圆角卡纸、多层嵌套花边。

## 文字承载区

- **顶部横带**：供超大复古书写英文标题位使用；保持**低细节、干净纸面**，可留出轻微的纸底亮部；
- **右下角**：供小号英文花名标注使用，同样保持干净；
- 底部信息区（价格/券额/QR/服务条）：保持**干净、低细节的浅豆绿米白纸面**，保证叠加的精确文字有足够对比；
- 不要把文字压在排线密集处；不要用相框线切过文字。
