# Vintage Engraving Floral Poster / 复古刻版画花卉海报

把普通海报 / 产品描述 / 营销主视觉，重绘成 **复古刻版画（copperplate engraving）花卉海报**。

**最终效果**：一页**老植物图鉴**——墨绿灰调的**钢笔排线线稿**用线条疏密塑造花瓣褶皱的柔和体积，**淡雅浅豆绿米白做旧纸底**衬底，**双层淡绿细线条复古相框**把画面收成一张标本图版，**顶部超大复古书写英文标题位**、**右下角小号英文花名**，竖版 3:4，**柔和高级低饱和**、**文艺植物图鉴风格**。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `observational-pen-wash`（钢笔淡彩）、`riso-print-redesign-poster`（RISO 丝网印刷）、`watercolor-travel-card`（水彩旅行卡片）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：锁住源海报的产品名、卖点、价格、日期、URL、二维码、法务文案、品牌色与用户给定措辞。
- **画布**：保留源海报**原始尺寸与宽高比**。风格**默认竖版 3:4**；源海报本身是 3:4 即照此执行，源海报是其他比例时**保留源比例**并把图鉴排版等比适配，**不要为凑 3:4 而拉伸或裁切**。
- **主体形态忠实**：层叠卷边的花瓣、自然弯折的修长花茎、翠绿色叶片与叶脉、**大小不一**的花苞；只保留**一个**核心植物主图，不换成与源海报无关的另一种花。
- **线稿语言（核心）**：**墨绿灰调钢笔排线线稿** + **细腻素描排线纹理**（平行排线、交叉排线、短线破线、点刻）；**用线条疏密表现柔和褶皱花瓣的体积**——亮部线稀、暗部线密、转折加密，高光处排线几乎消失、露出纸底。**体积靠排线密度，不靠灰色涂抹**；禁止渐变、喷枪、写实阴影、纯黑粗描边、水彩/油画笔触。
- **纸底**：淡雅**浅豆绿米白做旧纸张**（冷、灰、低饱和），有细微纸纤维、斑驳、淡淡岁月痕迹、轻微不均匀色斑；**不是**重污渍、撕边、焦边。
- **复古相框**：**双层淡绿细线条**相框，间距克制、四边等距、线条细而淡、不抢主体；**无**金框、繁复花角、立体阴影、圆角卡纸。
- **排版形式保留**：**顶部超大复古书写英文标题位** + **右下角小号英文花名位** + 简约复古排版、大量留白、克制细分隔线。
- **排版文字内容**：**只能用源海报自身的标题/主体名或其英文译名**；右下花名用源海报主体名的英文译名。**不得照抄**风格样例的装饰英文名（`SUMMER GREEN BLOOM`、`GREEN LISIANTHUS`、`FLEUR` 等），**不编造**作品名或承诺，**不加署名**（如 `prompt by awen`）。源海报无英文时，标题位可保留为**排版留白/占位**。
- **文字保留**：逐字保留源海报标题与全部文案（价格、券额、日期、电话、URL、法务字样）；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**；复古手写体易乱码，精确信息一律走受控层。
- **功能性资产保护**：二维码 / 条码 / logo 必须**完整、可识别、可扫描**——不得被排线覆盖、被做旧纸纹/斑驳侵蚀、被相框细线压住或切断、错位；最佳做法是**原样贴回**。
- **信息层级**：品牌/标题 → 主体 → 卖点/优惠 → QR/行动区 → 服务/法务；图鉴式排版可重排位置，但**不得删减、弱化或省略**任何必需信息（留白靠布局腾出来，不靠删信息）。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度，也不借用风格样例的装饰英文名。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界（含与钢笔淡彩/RISO/水彩卡片的区分表）。
- `palettes.md`：墨绿灰调与浅豆绿米白做旧纸底色盘、排线技法与相框规则。
- `prompt-templates.md`：图鉴主模板 + 纯视觉底图模板 + Style preset + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `vintage-engraving-floral-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的**主模板**，把源海报的文字**逐条填进**模板的「逐字列出」与「待填入内容」（顶部标题、右下花名）。
3. 确认主体形态清单：花瓣卷边、花茎弯折、叶片叶脉、花苞大小节奏。
4. 出图后按自检表核对：排线是否成立体积、相框层数、纸底做旧是否适度、**文字/价格/二维码是否完整保留**。
5. 要文字零误差就用两层流程：出**纯视觉底图** → 排版叠回原文字与二维码。
