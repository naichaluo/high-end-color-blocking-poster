# 示例：[源海报标题] → 复古刻版画花卉 / 植物图鉴

> 本示例演示**通用做法**。使用时把方括号内容替换成**当前源海报**的真实信息，**不要照抄任何其他项目的品牌、文案或优惠额度**，也**不要照抄风格样例里的装饰英文名**。

## Brief

- 源海报：[源海报名称，例如「XX 品牌 · 花卉主题季」海报]（[原始尺寸，例如 1080×1440] 竖版 3:4）
- 需求：重绘成**复古刻版画花卉 / 植物图鉴**风，**保留全部文字与商业信息**，**保留原图尺寸比例**
- 主体：[源海报的花卉主体，例如：浅绿洋桔梗]

## 主体形态清单（逐项保留）

| 项 | 内容 |
|---|---|
| 花瓣 | [层叠卷边形态，翻卷方向与褶皱位置] |
| 花茎 | [修长、自然弯折的走势与朝向] |
| 叶片 | [翠绿色叶片数量、角度、叶脉] |
| 花苞 | [大小不一的节奏，与盛开花朵的位置关系] |
| 姿态 | [整体朝向、疏密、是否有下垂/上扬] |

> 若源海报主体不是花卉而是产品/器物：用**同等细致的植物学结构语言**重绘其真实形态（例如包装的折面按花瓣层叠处理、瓶身弧线按花茎弯折处理），**但不得换成另一种花**。

## 排版位（形式保留，内容取自源海报）

| 位 | 形式 | 内容来源 |
|---|---|---|
| 顶部横带 | 超大复古书写/衬线英文标题，宽字距 | **源海报自身的标题或主体名**（可用英文译名）：[填] |
| 右下角 | 小号斜体/衬线英文花名标注 | **源海报主体名的英文译名**（源海报已有英文名则照用）：[填] |
| 若源海报无英文 | 标题位保留为**排版留白/占位** | 不得为填位而编造英文作品名 |

**明确不做**：照抄 `SUMMER GREEN BLOOM` / `GREEN LISIANTHUS` / `FLEUR` / `Pink Chrysanthemum` 等风格样例的装饰英文名；加 `prompt by awen` 之类署名；编造价格、承诺或与源海报无关的作品名。

## Reinterpret（视觉重释）

- **纸底**：淡雅浅豆绿米白做旧纸张，冷灰低饱和；细微纸纤维、斑驳、淡淡岁月痕迹、轻微不均匀色斑（不重污渍、不撕边、不焦边）
- **线稿**：墨绿灰调钢笔排线；平行排线走花瓣走向、交叉排线压褶皱转折、短线破线走卷边、点刻做花蕊与过渡；亮部线稀、暗部线密、高光处排线几乎消失露出纸底
- **体积**：**完全靠排线密度**，不用灰色涂抹、不用渐变、不用写实阴影
- **相框**：双层淡绿细线条，外线 + 内线，间距克制、四边等距
- **构图**：主体居中偏上（框内宽约 55%–70%、高约 50%–65%）；花茎向下延伸收在右下花名位上方；四周大量安静留白
- **质感**：柔和高级低饱和色调 + 版画肌理/雕版印痕
- **明确不做**：水彩晕染、喷枪渐变、3D、塑料感、鲜艳高饱和、卡通矢量、纯黑粗描边

## 文字处理

- 首选**两层流程**：先出「纯视觉底图」（纸底 + 相框 + 排线花卉 + 顶部标题带与右下花名位只留空间不填字，所有文字区留成干净纸面），再把原海报的标题、价格、券额、日期、电话、URL、二维码、服务信息**精确叠回**。
- 若直接让模型渲染：提示词里**逐字引用**全部文案与数字，出图后逐项核对；复古手写体易乱码，精确信息优先走受控层。
- **功能性资产保护**：二维码/条码/logo 位置保留、**完整可识别可扫描**，不得被排线覆盖、被做旧斑驳侵蚀、被相框线压住或切断、错位；**建议用原素材叠回**。
- **不新增、不编造**任何文案；**不加署名**。
