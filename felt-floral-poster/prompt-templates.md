## 现有海报 → 毛毡花卉杂志风（主模板）

```text
把提供的源海报重绘成「毛毡花卉 · 复古花卉杂志」风海报，Image 1 是唯一内容与视觉参考。

【画布】保留源海报的原始尺寸与宽高比（不要改成正方形，不要裁切版式）。
本风格原生版式为竖版：若源海报是竖版或用户明确要求竖版，按源海报比例输出（如 1200×1600，宽高取 16 的倍数）；
若源海报是横版或其他比例，以源海报比例为准，不得为了凑竖版而裁切或拉伸。

【严格保留原图内容】保留原图的主体身份、花卉种类与花朵结构、姿态、空间关系、主要构图和视觉焦点，
不改变原图所表达的内容。主体的身份不换，只把材质换成羊毛毡。

【商业内容必须完整保留】务必保留源海报的全部商业内容与文案：品牌 logo 与字样、主标题、全部副标题与卖点、
价格与券额数字、日期、电话、URL、二维码及其位置、底部服务与法务信息、以及所有产品/规格标签文字。
逐字列出：[把源海报上的文字逐条填在这里]。
所有文字必须清晰准确、可读，数字一个都不能改。不得把文字或 logo 化为不可读色块。
不要新增、编造或改写任何文案；不要虚构拉丁学名、品种编号、产地、年份或花名。
【功能性资产保护】二维码/条码/logo 必须保持完整、可识别、可扫描：二维码保持完整清晰可扫描，
不要被毛毡纤维、毡片层次、窗口边、卡片或阴影覆盖，不要错位歪斜、不要变形、不要虚化，
所在区域保持干净平整。

【视觉语言】复古花卉杂志海报（vintage floral magazine poster）× 羊毛毡面料（wool felt fabric）
× 舒适平面排版（comfortable flat editorial layout）× 复古植物图鉴（vintage botanical plate）。

【背景】深雾紫高级纯色背景：大面积纯色平铺、不透明、无渐变、无杂点、无纸纹、无底纹、无装饰边框。

【版面结构（自上而下，规整三段式）】
1）顶部：大号米白色复古衬线标题位（居中或偏左的规整排版）；
2）标题下方：极小号、宽字距、规整的一行（或两行）小字文案位；
3）画面中间：一个圆角方框窗口居中，圆角半径中等、边框克制，窗口内放毡质主体；
4）底部：一张米白文本卡片，卡片左侧大字体标注主体名/花名，卡片无多余装饰边框。

【窗内主体材质（核心）】花朵、花杆、叶片全部是软乎乎羊毛毡面料质感：
清晰毛毡肌理、蓬松柔软毛绒纹理、边缘微微起绒有细短纤维翘出；
花瓣与叶片像从厚毡片裁切后叠贴上去，边缘有毡片厚度，层次是"毡片叠毡片"；
体积由多层深浅不同的毡片叠加形成，不靠线稿与强烈明暗。
若画面为花卉：数朵盛放的花自然错落，花杆优雅弯曲，花蕊带淡黄调。
不要针织线圈、不要钩针针法、不要毛线辫、不要缠绕纱线、不要印花布、不要毛边散线、不要明线针脚、不要纽扣、不要蕾丝、不要流苏。

【光影】整体光影柔和朦胧、柔和漫射光影：不要硬阴影、不要强方向光；
毡片之间是柔和的层次阴影；窗口有一点点内阴影让窗口凹进底色里；
允许轻微朦胧感，但细节精致饱满、高清，不要糊成一团。

【配色】深雾紫纯色底 #4B3F5E；米白 #F2EBDF（标题与底部卡片）；纯白毡花瓣 #FBF8F2；
花蕊淡黄 #E8D6A3；花杆叶片柔和灰绿 #7C9A72；阴影为深雾紫加深 10%–18%。
低饱和、冷静与温暖并置，不要高饱和跳色。

【排版纪律】文字排版干净规整、边距从容；无多余装饰边框；
不要散落的装饰小元素、不要胶带贴纸、不要手绘涂鸦、不要花纹底纹。

【硬性禁止（极重要）】圆角方框窗口的右下角（以及任何角）**完全不要出现关闭叉号**：
绝对不要生成 × 或 X 图标、关闭按钮、窗口控件、UI 图标、铅笔/箭头等界面元素。
这是一个"窗口形状的版面元素"，不是真正的软件窗口。

【文字内容规则】标题位文字内容必须使用源海报自身的标题或主体名（逐字），不得编造与源海报无关的作品名或花名；
小字文案位沿用"极小号、宽字距、规整"的形式，内容用源海报自带的副标题/说明文案逐字填写，没有就留干净留白；
底部卡片左侧大字体用源海报自身的主体名/产品名（逐字）。
不要加「prompt by awen」之类署名。

【构图】保留源海报的信息顺序与层级关系（品牌/标题 → 主体 → 卖点/优惠 → QR/行动区 → 服务/法务），
但可按杂志封面的规整三段式重新排布；不得为了"排版干净"删减、弱化或省略源海报的必需信息。

【最终气质】像一本老植物学杂志的封面：安静、舒适、手作、复古、高级，平面而不做作。

【约束】不要混入其他项目或其他参考图的内容；不要改变价格、券额、套餐值、电话号码、二维码、品牌名与活动口径。
避免：关闭叉号与任何 UI 图标、多余装饰边框、写实鲜花照片、针织毛线纹理、布艺拼布、玻璃反光、
画面物体扭曲变形、文字错乱错漏、杂物冗余、颜色杂乱跳脱、画面模糊崩坏。
```

## 常见失败与修法

| 症状 | 修法 |
|---|---|
| 窗口右下角出现 `×` / 关闭按钮 | 提示词里单独一行强调「圆角方框窗口的任何角都绝对不要出现关闭叉号、×、关闭按钮、窗口控件或任何 UI 图标」；生图后仍未去掉就局部重绘覆盖 |
| 毛毡变成针织/毛衣纹理 | 加 `felted wool fabric, matted fibre, no knit, no crochet, no stitch loops`，并明确"毡片裁切叠贴" |
| 毛毡变成毛绒玩具长毛 | 明确"短绒毡面、纤维细密交错"，并加 `no long plush fur, short felted fibre only` |
| 背景出现渐变或杂点 | 明确"纯色平铺、无渐变、无杂点、无纸纹、无底纹" |
| 加了装饰花纹边框 | 明确"无多余装饰边框、无花边框、无虚线框、无双线相框" |
| 画面糊成一片 | 保留"柔和朦胧"但同时要求"细节精致饱满、高清，不要糊、不要雾散" |
| 底部卡片没有花名 | 明确"米白文本卡片左侧用大字体标注主体名/花名"，并把它写成受控层文字 |
| 模型自己编花名/学名 | 在提示词中把标题位与卡片花名用源海报原文逐字钉死，并写明"不得虚构拉丁学名或品种编号" |
