# 毛毡花卉杂志海报 · Palettes

**深雾紫纯色底 × 米白羊毛毡 × 淡黄花蕊 × 柔和绿花杆**。整体是**低饱和、冷静、温暖并置**的杂志配色：底色大面积深、毡质主体亮而软、文字规整克制。

## 色盘

| 色 | 参考色值 | 角色 | 说明 |
|---|---|---|---|
| 深雾紫 | `#4B3F5E` / `#463A57` | 背景 | 画面**最大面积**；高级纯色平铺，**无渐变、无杂点、无底纹** |
| 深雾紫（浅一档） | `#5A4D6E` | 窗口内底 | 窗口内部可略浅一档做柔和衬托；也可用米白 |
| 米白（标题/卡片） | `#F2EBDF` / `#F6F1E7` | 标题、卡片 | 顶部大号衬线标题色 + 底部文本卡片底色 |
| 纯白毡（花瓣） | `#FBF8F2` | 主体主色 | 花瓣毡片主色，柔软不刺眼（不要冷白 `#FFFFFF`） |
| 淡黄花蕊 | `#E8D6A3` / `#EFDFAE` | 主体点缀 | 花蕊的淡黄调，**面积小**，是画面唯一的暖色点 |
| 柔和绿（花杆/叶） | `#7C9A72` / `#8FAE86` | 花杆、叶片 | 优雅弯曲的毡质花杆与叶片；饱和度低、偏灰绿 |
| 深绿（层次暗部） | `#63795C` | 花杆暗面 | 只用于毡片层次，面积小 |
| 柔和投影 | 深雾紫加深 10%–18% | 阴影 | 毡片层次阴影与窗口内阴影，**柔和、无硬边** |
| 文字（卡片上） | `#3E3550` | 卡片文字 | 米白卡片上的深紫灰文字 |

**主体色准优先**：主体的实际颜色（产品、包装、品牌色、花卉识别色）要保留源海报的主要色彩信息，只做**毡化 + 低饱和化**处理（降低光泽、加绒感、略降纯度），**不改变色相归属、不换色系**。

## 材质

### 羊毛毡（核心材质）

- **毡化纤维表面**：细密交错的纤维绒面，可见清晰毛毡肌理与细微起伏。
- **蓬松柔软毛绒纹理**：边缘微微起绒，有细短纤维翘出，触感柔软。
- **裁切毡片**：花瓣、叶片、花杆像从厚毡片裁切后叠贴，边缘有毡片厚度、边口略钝。
- **毡片叠毡片**：体积靠多层毡片的深浅叠加形成，**不靠线稿或强烈明暗**。
- **不要**：针织线圈、钩针针法、毛线辫、缠绕纱线、印花布、毛边散线、明线针脚、纽扣、蕾丝、流苏。

### 背景

- 深雾紫**高级纯色**：平面、不透明、**无渐变、无杂点、无纸纹、无底纹、无装饰边框**。
- 唯一允许的背景变化是**窗口的内阴影**（柔和、浅）带来的层次。

### 文本卡片

- 米白素净卡片，**无多余装饰边框**（无花边框、无虚线框、无双线相框）。
- 卡片左侧大字体放主体名/花名（源海报逐字）；其余位置放源海报必要信息。
- 卡片与深雾紫底之间用**极浅柔和阴影**分开，卡片本身不加纹理。

## 光影

- **柔和漫射光影**、**整体光影柔和朦胧**（hazy）：没有硬阴影、没有强方向光、没有投影射线。
- 毡片之间是**柔和的层次阴影**，让叠层关系可读但不脏。
- 窗口有**一点内阴影**，让窗口"凹"进深雾紫底里。
- 允许轻微朦胧感，但**细节精致饱满、高清**——不要糊、不要雾散、不要降低清晰度。

## 用色规则

- **底深、主体亮**：深雾紫与米白/纯白毡是主对比；花蕊淡黄与花杆灰绿是唯二点缀，面积要小。
- **低饱和**：避免荧光、艳俗、高饱和跳色；避免把毛毡做成彩色塑料。
- **面积分配**：深雾紫底 55%–70% → 米白卡片与标题 10%–20% → 毡质主体 15%–30% → 淡黄/灰绿点缀 ≤5%。
- **文字对比**：深雾紫底上用米白文字；米白卡片上用深紫灰文字。保证叠加的精确文字有足够对比。
- **品牌色**：以低饱和但可识别的毡色保留，不得改色系。
- **功能性资产区**：二维码/条码/logo 所在区域保持**干净平整**——不加毛绒纤维、不加窗口边、不加阴影，以便原样贴回。
