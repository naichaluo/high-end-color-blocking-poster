# Felt Floral Poster / 毛毡花卉杂志海报

把普通海报/产品描述/营销主视觉，重绘成一张 **竖版复古花卉杂志海报**：**深雾紫高级纯色背景**，顶部**大号米白色复古衬线标题位**与其下的小字文案位，画面中间一个**圆角方框窗口**，窗口内是**软乎乎羊毛毡材质的花卉主体**（清晰毛毡肌理、蓬松柔软毛绒纹理、优雅弯曲的毡质花杆），**整体光影柔和朦胧**，底部一张**米白文本卡片**（左侧大字体标注主体名/花名），**舒适平面海报排版**，**复古植物图鉴**气质。

**最终效果**：像一本老植物学杂志的封面——安静、舒适、手作、复古、高级。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `plush-animation-poster`（毛绒/羊毛毡定格动画）、`knitted-yarn-poster`（针织毛线）、`fabric-patchwork-poster`（布艺拼接）、`crystal-glass-floral-poster`、`lace-embroidery-poster` 或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：主体身份、花卉种类与花朵结构、姿态、空间关系、主要构图与视觉焦点**严格保留**；主体身份不换，**只把材质换成羊毛毡**。
- **背景**：**深雾紫高级纯色**——平面、不透明、**无渐变、无杂点、无底纹、无装饰边框**。
- **顶部标题位**：**大号米白色复古衬线**标题位（居中或偏左、规整）；**标题下方**是**极小号、宽字距**的小字文案位。
- **中间窗口**：**圆角方框窗口**，圆角中等、边框克制、带柔和内阴影；窗口内是毡质主体。
- **毛毡材质（核心）**：花朵、花杆、叶片**全部是软乎乎羊毛毡面料**——**清晰毛毡肌理 + 蓬松柔软毛绒纹理**，边缘微微起绒有细短纤维翘出；花瓣像**厚毡片裁切后叠贴**，体积靠**毡片叠毡片**，**不靠线稿与强烈明暗**。
- **花杆形态**：**优雅弯曲**，数朵花自然错落，花蕊带淡黄调。
- **光影**：**柔和漫射、整体光影柔和朦胧**（hazy），无硬阴影、无强方向光；但**细节精致饱满、高清**，不糊。
- **底部卡片**：**米白文本卡片**，**卡片左侧大字体标注主体名/花名**（源海报逐字）；**无多余装饰边框**。
- **硬性禁止**：**圆角方框窗口的任何角（尤其右下角）完全不要出现关闭叉号**——不要 `×`/`X` 图标、关闭按钮、窗口控件、UI 图标。
- **标题/小字/花名文字内容**：一律用**源海报自身的标题、主体名或自带文案（逐字）**；**不虚构**花名、拉丁学名、品种编号；**不加** `prompt by awen` 之类署名。
- **画布**：保留源海报**原始尺寸与宽高比**。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**。
- **功能性资产**：二维码/条码/logo 必须**完整、可识别、可扫描**，不得被毛毡纤维、毡片层次、窗口边、卡片或阴影覆盖/错位/虚化；其所在区域保持干净平整。
- **留白靠布局，不靠删信息**：不得为了"排版干净"删减必需信息。
- **材质边界**：不要针织线圈/钩针/毛线辫/缠绕纱线、不要印花布/毛边散线/明线针脚/纽扣/蕾丝/流苏、不要长绒毛玩具感、不要玻璃反光。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度、花种。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：深雾紫 × 米白毛毡色盘、毛毡材质与光影处理。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + Style preset + 出图前自检表 + 常见失败修法。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `felt-floral-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：底色是否纯色无渐变、毛毡肌理是否清楚、"**窗口右下角有没有冒出关闭叉号**"、底部卡片有没有花名、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图（标题位/小字位/卡片文字区/二维码区留成干净空区）→ 排版叠回原文字与二维码。
