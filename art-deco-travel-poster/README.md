# Art Deco Travel Poster / 装饰艺术旅行海报

把普通海报 / 产品描述 / 营销主视觉，重绘成 **1930 年代豪华装饰艺术（Art Deco）旅行海报**。

**最终效果**：像一张 1930 年代印刷厂出品的**收藏级目的地旅行海报**——醒目、戏剧化、几何化、博物馆级克制，主体的宏伟感来自**低角度仰视 + 向顶部汇聚的流线造型 + 硬朗平面光**。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `landmark-geometric-poster`（几何地标艺术）、`layered-papercut-poster`（分层剪纸）、`watercolor-travel-card`（水彩旅行卡片）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **主体 70% / 装饰 30%**：把源海报的**唯一视觉主体**（产品 / 门店 / 建筑 / 场景）当作海报的“地标”，必须一眼就能读出「这就是主角」；装饰艺术几何具有组织性，但**从不占据主导**。
- **低角度仰视**：主体从**下方视角**观察，高耸并**向顶部汇聚**；保留其现实世界的可识别轮廓与基本比例，简化表面细节但**绝不简化结构**。
- **对角线骨架**：整张画面建立在**从左下角到右上角的强烈对角线**上；三到五个次要元素（道路/轨道/桥/河流/运河/海岸线/柜台边缘/桌沿/产品长轴/台阶）沿对角线延伸。
- **装饰母题**：流线型的宏伟造型、完美的弧线、笔直的垂直线、重复的速度线、阶梯式退台、同心光束。
- **硬光**：明亮的平面 vs **单一色调的阴影**，**没有柔和的过渡**。
- **淡奶油色圆盘**：主体后方一个风格化的发光圆盘，**清冷而宁静，绝不是炽热的日落景象**。
- **配色铁律**：**六到八种冷调低饱和色**，**始终以深邃低饱和藏青作为唯一阴影色调**；暖色仅作**受光面上的少量点缀**（天空、水体、阴影里没有暖色）；纯色平面，**除光线之外没有渐变**。
- **质感**：纸张上**平整的印刷油墨**，纹理均匀细腻，干净现代；**无老旧纸张、棕色滤镜、棕褐色、泛黄**。
- **构图**：**上三分之一留白**（干净天空 + 圆盘 + 标题区）；**顶部中央标题区**为**大写几何无衬线、宽字距、单一纯色**。
- **画布**：保留源海报**原始尺寸与宽高比**（docx 原规格 2:3 竖版，但以源海报实际比例为准，不裁切不拉伸）。
- **文字保留**：逐字保留源海报标题与全部文案；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**。
- **标题区改写规则**：docx 原文的「［城市名称］」位 → 对应为**源海报标题区**，排版形式保留，**文字内容一律用源海报自身文案，不编造城市名/地名/装饰性英文标题**。
- **功能性资产保护**：二维码、条码、logo 必须**完整、可识别、可扫描**，不得被光束、速度线、阶梯退台等装饰几何覆盖、切割或倾斜。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：冷调低饱和色盘、藏青唯一阴影规则、印刷油墨质感。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `art-deco-travel-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：70/30 是否守住、对角线是否成立、藏青是否是唯一阴影色、暖色是否只出现在受光面、标题区文字是否**逐字来自源海报**、二维码是否完整可扫描。
4. 要文字零误差就用两层流程：出纯视觉底图（标题区/卖点条/QR 区留干净）→ 排版叠回原文字与二维码。
