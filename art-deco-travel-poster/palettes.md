# 装饰艺术旅行海报 · Palettes

**冷调、低饱和、纯色平面、博物馆级处理**。整个色盘的铁律只有一条：

> **始终以深邃的低饱和度藏青色作为唯一的阴影色调。**
> 全图所有阴影必须是**同一个藏青**，不允许第二种阴影颜色，不允许阴影里出现暖色。

## 色盘结构

| 角色 | 色（参考） | 说明 |
|---|---|---|
| **唯一阴影色** | 深邃低饱和藏青 `#1E2A44` / `#23324D` | **全图所有阴影**都用它；整张海报的色彩统一性靠它 |
| 冷调深色 | 深青 `#2E4A5A`、墨蓝绿 `#274A4E` | 主体暗面结构、远景块面 |
| 冷调中色 | 灰蓝 `#6C8296`、青蓝 `#4E7F8C`、蓝绿 `#5E8F92` | 建筑面、水面、次要元素 |
| 冷调亮色 | 冷调天蓝 `#8FB0C9`、浅灰青 `#A9C2CB` | 天空（上三分之一）、受光平面 |
| 圆盘色 | 淡奶油色 `#F2E8D5` | **仅用于主体后方那个风格化发光圆盘**；清冷、宁静，不是暖太阳 |
| 中性亮面 | 冷白 `#EDF0F1`、浅冷灰 `#D5DBDE` | 高光平面、标题字色 |
| **暖色点缀** | 低饱和暖珊瑚 `#C98A7A`、浅陶土 `#BE8B76` | **仅限受光平面的极小面积点缀（≤5% 画面）**，绝不进入阴影、天空与水体 |

> 上方 hex 只是**参考锚点**，目的在说明「冷、低饱和、纯色平面」的区间。
> 实际取色以**源海报主体的识别色为本**，做**冷调化 + 低饱和化**处理，**不改变色相归属**。

## 三套可直接选用的方案

### A. 深蓝天际（最经典）
深藏青阴影 → 墨蓝绿主体暗面 → 青蓝主体亮面 → 冷调天蓝天空 → 淡奶油色圆盘 → 冷白高光。
暖色点缀：受光立面上极少量暖珊瑚（≤5%）。

### B. 青绿都会
深藏青阴影 → 深青主体暗面 → 蓝绿主体亮面 → 浅灰青天空 → 淡奶油色圆盘 → 冷白高光。
暖色点缀：暖砂色只出现在最靠近光的那一个受光面。

### C. 夜蓝收藏版
深藏青阴影（大面积）→ 深青主体 → 灰蓝亮面 → 冷白细高光 → 淡奶油色圆盘成为全图唯一亮点。
这一套最戏剧化，适合主体本身是深色产品或夜间门店。

## 用色规则

- **冷调主导**：蓝色和青色承担天空、水面和**所有阴影**。
- **暖色只做点缀**：仅出现在**受光平面**上，小面积、低饱和；**天空、水体、阴影区一律不得出现暖色**。
- **纯色平面**：除光线之外**没有渐变**。光的表达靠「亮面 / 暗面」两块纯色直接对比，不靠晕染过渡。
- **硬光**：明亮平面 vs 单一色调阴影，**没有柔和过渡**。
- **装饰几何用色**：同心光束、速度线、阶梯退台只用**冷调色阶 + 藏青**推进，靠明度与重复制造节奏，不要彩度爆炸。
- **主体色准**：主体（产品 / 门店 / 建筑 / 场景）的实际颜色保留源海报的主要色彩信息，只做冷调化与低饱和化。
- **品牌色**：以低饱和但**可识别**的方式保留；品牌暖色（如品牌黄/品牌红）若必须出现，压缩为受光面上的小面积点缀，并**不得**成为阴影色。
- **文字承载区**：标题区、卖点条、行动区保持**低细节的纯色平面**（冷白 / 淡奶油 / 藏青），保证叠加的精确文字有足够对比。

## 严格禁止的颜色与色调

- ❌ 黄色、芥末色、赭色、金色、琥珀色
- ❌ 暖调日落色、橙色天空、任何暖调光源
- ❌ 整体色调偏暖
- ❌ 柔和渐变、彩色滤镜、棕色滤镜、棕褐色调、泛黄
- ❌ 霓虹色、荧光色
- ❌ 第二种阴影色（阴影必须是同一个藏青）

## 材质与印刷感

- **纸张上平整的印刷油墨**：色块边缘干净、实心、无锯齿感噪点。
- **纹理均匀细腻**：极细的均匀颗粒，**干净现代**。
- **无做旧**：没有老旧纸张、没有磨损、没有斑驳、没有 grunge、没有仿旧叠印。
- **无 3D**：不用高光渐变、不用投影模糊、不用材质反射来做立体感——立体感只来自**平面明暗对比与几何汇聚**。
