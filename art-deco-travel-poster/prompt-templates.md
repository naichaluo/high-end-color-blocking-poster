# 装饰艺术旅行海报 · Prompt Templates

把方括号内容替换成当前源海报的事实。**源海报是唯一内容源**，不需要风格参考图。

## 现有海报 → 装饰艺术旅行海报风（主模板）

```text
把提供的源海报重绘成「1930 年代豪华装饰艺术（Art Deco）旅行海报」风海报，Image 1 是唯一内容与视觉参考。

【画布】保留源海报的原始尺寸与宽高比（不要改成正方形，不要裁切版式，不要为了凑 2:3 而拉伸或重排）。

【严格保留原图内容】保留原始图片的主体、人物/物体/建筑的身份特征、动作姿态、空间关系、
主要构图和视觉焦点，不改变原图所表达的场景内容。

【主体 70% / 装饰 30%】把源海报的视觉主体当作这张海报的“地标”：
- 主要主体（一到两个）：［写出主体的独特形状与识别特征，不要只写名称］，
  从下方视角观察，使其高耸并向上汇聚，必须保留现实世界中的可识别轮廓与基本比例；
- 次要元素（三到五个）：［道路/轨道/桥/河流/运河/海岸线/柜台边缘/桌沿/产品长轴/地平线/台阶等］，
  安排成沿对角线延伸，把视线从左下推向右上；
- 装饰几何占 30%，具有组织性但绝不占据主导。

【装饰风格处理】
- 整张画面以从左下角到右上角的强烈对角线为基础；
- 主要主体从低角度仰视，高耸入云，向顶部汇聚；
- 使用流线型的宏伟造型、完美的弧线、笔直的垂直线、重复的速度线、阶梯式退台、同心光束；
- 硬朗的戏剧性光线：明亮的平面与单一色调的阴影形成对比，没有柔和的过渡；
- 主体后方是一个风格化的淡奶油色圆盘，散发着光芒——清冷而宁静，绝不是炽热的日落景象。

【构图】上三分之一留白，用于干净的天空、圆盘和标题区。
顶部中央是标题区：使用大写字形、几何无衬线字体、字距拉开、单一纯色
（中文标题对应为字面方正、加粗、字距拉开的几何感无衬线体）。
信息顺序按装饰艺术的几何分区重新排布：品牌/标题 → 主体场景 → 卖点/优惠 → QR/行动区 → 服务/法务。
不得为了留白美学删减、弱化或省略源海报的必需信息。

【色彩】六到八种冷色调的低饱和度色彩：蓝色和青色承担天空、水面和所有阴影。
始终以深邃的低饱和度藏青色作为唯一的阴影色调（全图阴影必须是同一个藏青）。
暖色调仅作为受光平面上的少量点缀，绝不进入阴影、天空与水体。
纯色平面，除光线之外没有渐变，采用博物馆级低饱和度处理。
主体的实际颜色保留源海报的主要色彩信息，只做冷调化与低饱和化，不改变色相归属。

【质感】纸张上平整的印刷油墨，纹理均匀细腻，干净现代。
没有老旧纸张、棕色滤镜、棕褐色或泛黄的背景。

【商业内容必须完整保留】务必保留源海报的全部商业内容与文案：品牌 logo 与字样、主标题、
全部副标题与卖点、价格与券额数字、日期、电话、URL、二维码及其位置、底部服务与法务信息、
以及所有产品/规格标签文字。逐字列出：[把源海报上的文字逐条填在这里]。
所有文字必须清晰准确、可读，数字一个都不能改。不得把文字或 logo 化为不可读色块。
标题区文字一律使用源海报自身的标题，不要编造城市名、地名或装饰性英文标题。
不要新增、编造或改写任何文案。
【功能性资产保护】二维码/条码/logo 必须保持完整、可识别、可扫描：二维码保持完整清晰可扫描，
不要被对角线、光束、速度线、阶梯退台或任何装饰几何覆盖、切割、错位，保持水平不倾斜；
不要做旧、不要压暗、不要模糊。

【最终效果】一张 1930 年代印刷厂出品的收藏级目的地旅行海报：醒目、戏剧化、几何化、博物馆级克制。

【约束】不要混入其他项目或其他参考图的内容；不要改变价格、券额、套餐值、电话号码、二维码、品牌名与活动口径。
避免：黄色、芥末色、赭色、金色、琥珀色、暖调日落色、橙色天空、整体色调偏暖、柔和渐变、
照片写实主义、3D、霓虹色、仿旧效果、做旧效果、卡通效果、水印、新增标志、
第二种阴影色、把文字变成色块、改成正方形。
```

## 出图前自检

| 检查 | 期望 |
|---|---|
| 画布尺寸 | **保留源海报原始尺寸与比例**；未为了凑 2:3 裁切或拉伸 |
| 内容保真 | 主体、身份特征、空间关系、主要构图、视觉焦点**严格保留**；场景内容未改变 |
| 70/30 | 主体承担“地标”角色约 **70%**；装饰几何约 **30%** 且从不主导 |
| 低角度 | 主要主体从**下方视角仰视**，高耸并**向顶部汇聚**，独特轮廓保留 |
| 次要元素 | **三到五个**支撑元素，沿**左下→右上对角线**延伸 |
| 对角线骨架 | 整张画面建立在强烈的左下→右上对角线上 |
| 装饰母题 | 流线型宏伟造型 / 完美弧线 / 笔直垂直线 / 重复速度线 / 阶梯退台 / 同心光束，至少 3 种同时存在 |
| 光线 | **硬朗戏剧性**：明亮平面 vs 单一色调阴影，**没有柔和过渡** |
| 圆盘 | 主体后方有**风格化淡奶油色发光圆盘**，清冷宁静，**不是炽热日落** |
| 上三分之一 | 保持为**干净天空留白 + 圆盘 + 标题区**，未被塞满 |
| 标题排版 | 顶部中央，大写字形 / 几何无衬线 / 宽字距 / 单一纯色 |
| 配色数量 | **6–8 种冷调低饱和色** |
| 唯一阴影色 | 全图阴影是**同一个深邃低饱和藏青**，没有第二种阴影色 |
| 暖色限制 | 暖色只在**受光平面**小面积点缀（≤5%）；天空/水体/阴影无暖色 |
| 平面化 | 纯色平面，**除光线之外无渐变**，博物馆级低饱和 |
| 质感 | 纸张上平整印刷油墨、均匀细腻、干净现代；**无做旧/泛黄/棕褐/棕色滤镜** |
| 信息层级 | 品牌/标题 → 主体 → 卖点/优惠 → QR → 服务条，顺序保留 |
| 文字 | **全部逐字保留、可读**；未新增或编造文案，**无编造城市名/装饰英文标题** |
| 价格/券额/日期/电话/URL | 逐字一致，未删改 |
| 二维码 | 位置保留，**完整可扫描**，未被光束/速度线/线条覆盖或切割、未倾斜；建议用原素材叠回 |
| logo/品牌标识 | 完整可识别，未被装饰几何覆盖或风格化撕碎 |
| 温度检查 | 全图无**黄色、芥末、赭色、金色、琥珀、橙色天空、整体偏暖** |
| 风格排除 | 无柔和渐变、无照片写实、无 3D、无霓虹、无做旧、无卡通、无水印、无新增标志 |
| 缩略图测试 | 缩略图下仍能读出主体轮廓、藏青阴影、对角线、顶部标题区 |
| 污染检查 | 未混入其他项目品牌/文案/额度/地名 |
