# 留白平涂小景 · Prompt Templates

把方括号内容替换成当前源海报的事实。**源海报是唯一内容源**，不需要风格参考图。

## 现有海报 → 留白平涂小景（主模板）

```text
把提供的源海报重绘成「留白平涂小景」插画风（画布保留源海报原始尺寸与比例），Image 1 是唯一内容与视觉参考。

【商业内容必须保留】务必保留源海报的布局层级和全部商业内容：品牌 logo、标题、全部文案、
价格与券额数字、日期、电话、URL、二维码及其位置、底部服务与法务信息。文字必须清晰准确、
可读、位置与大小基本不变。不得把文字或 logo 化成不可读色块，不得删改任何数字与条款。

风格锁定：editorial spot illustration、mid-century modern flat illustration、cut-paper collage shapes、
opaque gouache color blocking、matte screen-print finish。像印在暖白纸中央的一张安静小画。

画布与构图：暖白画布，**保留源海报的原始尺寸与宽高比**（不要改成正方形）。四边留白是空的暖白纸（不是画上去的色块）。
源海报的视觉主体重组为中央紧凑场景单元，占画面宽高 72%-78%；四边留白连续、近等宽。

【边界规则】外轮廓不可以是规则矩形，不要出现四条笔直线边界。边界必须由场景自身的形状不规则收口：
天空/远山/树冠/屋顶轮廓打破上缘，地面/台面/台阶自然边缘收下缘，左右由树木、建筑、灯柱、
人物或物件轮廓不规则收口；允许主体、投影或物件自然越过边界延伸到留白上。
不要贴边、不要裁切、不要出血、不要加外框。

信息层级：保留源海报的信息顺序与主布局逻辑——顶部品牌/标题、中部产品场景、下方优惠模块、
QR/行动区、底部服务与法务区，位置关系保持可比。同时为精确文字留出平静、低细节的暖白区域。

投影与重画：正面平视、近似正交投影。空间压成少量二维层，用遮挡、位置和明度区分，前后同等清晰。
用几何剪影和连续色面重画。人物保留脸型、发型、服装大形和接触点，五官衣褶只留少量短笔。
环境与物件保留结构数量后简化。无景深、无虚化、无汇聚透视、无写实材质、无 3D。

色彩与表面：全图约 7-9 色——暖白纸底、暖米灰、钴蓝、深蓝、炭黑、朱橙；原片有自然对象可用深绿；
肤发色随本人。品牌主色必须保留可识别。完整哑光平涂，内部没有水彩刷痕、碎色、白洞或渐变。
纸纹极轻，扫描噪点接近不可见。

约束：不要混入其他项目或其他参考图的内容；不要改变价格、券额、套餐值、电话、二维码、品牌名与活动口径。
禁止：动漫、赛璐璐、矢量贴纸感、水印、矩形画框、把文字变成色块。
```

## 纯视觉底图（用于精确文字后期叠加）

```text

不写任何文字。暖白画布并保留源海报原始尺寸与比例，中央紧凑场景单元占宽高 72%-78%，四边连续近等宽留白，
外轮廓由场景形状不规则收口（非矩形）。约 7-9 色哑光平涂，几何剪影 + 连续色面，正面平视近似正交，
前后同等清晰。为标题、优惠条、二维码区、底部服务条各留出干净区域。
不要生成任何可读文字，不要虚构 logo 或二维码。
```

## 出图前自检

|---|---|
| 画布尺寸 | **保留源海报原始尺寸与宽高比**，暖白纸底，四边留白连续近等宽 |
| 场景单元占比 | 宽高 72%–78% |
| 外轮廓 | **非矩形**，由场景形状不规则收口 |
| 信息层级 | 品牌/标题 → 产品 → 优惠 → QR → 服务条，位置可比 |
| 文字 | **全部保留、可读、位置大小基本不变** |
| 价格/券额/日期/电话/URL | 逐字一致，未删改 |
| 二维码 | 位置保留，可用原素材叠回 |
| 品牌色 | 保留可识别 |
| 投影 | 正面平视、近似正交，前后同等清晰 |
| 重画方式 | 几何剪影 + 连续色面，五官衣褶仅少量短笔 |
| 色彩 | 约 7–9 色、哑光平涂、无渐变/刷痕/白洞 |
| 风格排除 | 无动漫、赛璐璐、矢量贴纸、水印、矩形画框 |
| 污染检查 | 未混入其他项目品牌/文案/额度 |
