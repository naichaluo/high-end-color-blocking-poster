# Flat Spot Poster / 留白平涂小景海报

把普通海报/产品描述/营销主视觉，重绘成 **「留白平涂小景」插画风**广告：像印在暖白纸中央的一张安静小画，**画布保留原图尺寸与比例**。

**风格锁定**：editorial spot illustration、mid-century modern flat illustration、cut-paper collage shapes、opaque gouache color blocking、matte screen-print finish。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**
**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `high-end-color-blocking-poster`、`riso-print-redesign-poster`、`crayon-scribble-poster`、`paper-collage-poster`、`watercolor-travel-card` 等任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。源海报只提供商业事实，本 skill 只涂平涂小景的视觉处理。
- **两层流程**：视觉层（平涂小景场景、几何剪影、装饰形）与受控层（精确标题/价格/券额/品牌/二维码/服务条款）分开；文字、logo、QR 用原素材叠加，不交给图像模型乱造。
- **必须保留文字**：不得把源海报文字与 Logo 化为不可读色块，不得删改价格、券额、日期、电话、URL、二维码或法务字样。
- **画布**：暖白纸底，**保留源海报的原始尺寸与宽高比**（不强制正方形）；源海报视觉主体重组为中央紧凑场景单元，占宽高 **72%–78%**；四边留白连续、近等宽。
- **边界**：外轮廓**绝非规则矩形**——由场景自身的形状不规则收口（天空/树冠/屋顶破上缘，地面/台面收下缘，树木/建筑/人物收两侧），允许主体越过边界延伸到留白；不贴边、不裁切、不出血、不加框。
- **投影与重画**：正面平视、近似正交；空间压成少量二维层，以遮挡、位置和明度区分；**前后同等清晰**；几何剪影 + 连续色面；人物保留脸型、发型、服装大形和接触点，五官衣褶只留少量短笔；无景深、虚化、汇聚透视、写实材质或 3D。
- **色彩**：约 7–9 色（暖白、暖米灰、钴蓝、深蓝、炭黑、朱橙；有自然对象可用深绿；肤发色随本人），品牌主色保留可识别；完整哑光平涂，无刷痕/碎色/白洞/渐变；纸纹极轻。
- **构图**：保留源海报信息顺序与主布局逻辑（品牌/标题 → 产品场景 → 优惠模块 → QR/行动区 → 服务/法务区），并留出平静低细节区供精确文字叠加。
- **禁止**：动漫、赛璐璐、矢量贴纸感、水印、矩形画框、把文字化成色块。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：7–9 色盘、品牌色与文字区规则。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与提示词应用。

## 快速上手

1. 先 `skill` 加载 `flat-spot-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，方括号处填当前海报的事实。
3. 出图后按自检表核对：原尺寸比例、场景占比、边界非矩形、**文字/价格/二维码是否完整保留**。
4. 要零误差就用两层流程：出纯视觉底图 → 排版叠回原文字与二维码。
