# 示例：移动「请你喝奶茶」促销海报 → 留白平涂小景风

## Brief

- 源海报：中国移动云南公司促销海报「移动请你喝奶茶」
- 商业内容：品牌 logo（中国移动）、主标题、副标题（每月20元奶茶券）、
  优惠条（15元/月 + 15GB + 20元饮品券）、二维码、吉祥物、底部服务热线与法规提示
- 类型：竖版促销海报
- 需求：重绘成「留白平涂小景」风，**保留全部文字与商业信息**

| 项 | 内容 |

| 主标题 | 移动请你喝奶茶 |

| 信息层级 | 顶部品牌 → 主标题 → 优惠条 → 中部产品 → 底部服务/二维码 |

## Reinterpret（视觉重释）

- 材质：暖白纸底 + 不透明水粉平涂 + 剪纸拼贴式几何块面 + 哑光丝网印质感
- 场景：两只奶茶杯（橙/紫）为视觉锚点，配哈密瓜、葡萄、吉祥物、缎带横幅，
  绿色植物块作背景
- 投影：正面平视、近似正交；把空间压成三层（前景台面 / 中景杯与水果 / 背景绿植块），
  以遮挡与明度分层，前后同等清晰
- 边界：由绿植块、树冠状起伏、缎带与水果轮廓**不规则收口**，不是矩形画框
- 色彩：约 9 色——暖白、暖米灰、深绿、朱橙、紫、草绿、炭黑、白、赭金

## 文字处理

- 首选**两层流程**：先出「纯视觉底图」（文字区留成干净暖白/暖米灰空区），
  再把原海报的标题、优惠数字、二维码、服务信息**精确叠回**。
- 若直接让模型渲染：必须在提示词里**逐字引用**全部文案与数字，
  出图后逐项核对——尤其 `15`、`15GB`、`20`、`10086`、二维码不可错漏。
