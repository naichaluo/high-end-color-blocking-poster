# 留白平涂小景 · Palettes

全图约 **7–9 色**。默认色盘如下；**品牌色必须保留可识别**，原片有自然对象时可用**深绿**，**肤发色随本人**。

## 默认 7–9 色盘

| 色 | 角色 | 说明 |
|---|---|---|
| 暖白 | 纸底 / 留白 | 画布底色与四边留白（画布尺寸随源海报），占最大面积 |
| 暖米灰 | 中间调 / 隔断 | 地面、墙面、台面、家具底座等大面积中性 |
| 钴蓝 | 主色 | 天空、水面、布料等主要色面 |
| 深蓝 | 暗部 / 结构 | 压暗结构、阴影面（平涂暗面，不是渐变） |
| 炭黑 | 最重色 | 轮廓、深色物件、鞋、器物暗部 |
| 朱橙 | 强调 | 小面积焦点：招牌、器物、衣饰、果实 |
| 深绿 | 自然对象（可选） | 仅当原片存在植物/自然对象时使用 |
| 肤发色 | 随本人 | 依原片实际肤色与发色取样 |

## 品牌色与文字区

- **品牌色不得被风格色盘覆盖**：源海报的品牌主色要作为可识别色留在画面里（可作为强调色或主体色）。
- 文字承载区保持**平静、低细节**：用暖白或暖米灰做底，保证叠加的精确文字有足够对比。
- 若品牌色是高饱和色，把它限制在一个主焦点，其余退到纸张、灰调或低饱和辅助色。

## 用色规则

- 每块色面**连续、完整、哑光**；色与色之间以**硬边几何剪影**相接。
- **无**水彩刷痕、碎色、白洞或渐变；不叠色、不做颗粒噪点。
- 以**明度**区分前后层：前后同等清晰，靠遮挡与位置分层，不靠景深虚化。
- 颜色归属追随原片：原片里是什么色，就归到对应色面上。
- 留白（暖白）是构图的一部分，不是"没画完"。
