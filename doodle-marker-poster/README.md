# Doodle Marker Poster / 涂鸦马克笔手绘海报

把普通海报/产品描述/营销主视觉，重绘成 **手绘涂鸦 / 稚拙插画 / 马克笔手绘**风广告。

**整体追求**：稚拙手绘 × 成熟构图 × 大量留白 × 聪明图文关系 × 独立出版物气质。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill，不与 `crayon-scribble-poster`、`flat-spot-poster`、`ghibli-animation-poster` 或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **重新提炼**：提取源海报中最具识别性的主体、轮廓、动作、结构与叙事关系；**删去大部分无关背景和细节**。
- **线条**：松弛、略带抖动和断续感的手绘线条；有轻重变化与手工误差，可重复描、可断开。
- **上色**：马克笔、蜡笔、油画棒般的自然平涂；色块边缘略有溢出或没涂满，保留手工误差，**不做精细渐变**。
- **造型**：简化、符号化、略带夸张；**主体一眼可辨**；不追求写实比例、复杂透视和精细描绘。
- **构图**：**下半部分以大面积暖白/浅色留白为核心**；主体只占**较小到适中**的视觉面积；可**偏心、贴边、悬置、裁切或局部越界**；通过尺度变化、错位和不对称建立节奏与呼吸感。
- **图文关系**：文字与图形必须作为**同一构图系统**设计；文字用轻巧自然的手写字或简洁编辑字体，可沿主体轮廓、动作方向或留白区域排布；**避免机械居中和上下堆叠**。
- **配色**：**主体的色彩必须保留源海报的主要色彩信息**——产品、包装、品牌色与核心人物的实际颜色忠实保留，不改色相。**2–5 色收敛与大面积浅色场只作用于背景/次要装饰**；整体柔和、明快、清爽、治愈，鲜活但不过饱和。
- **画布**：保留源海报**原始尺寸与宽高比**。
- **文字保留**：逐字保留源海报的标题与全部文案；**不新增、不编造标题**；"轻巧排布"体现在字体与位置，**不体现在删字**；不得把文字或 logo 化为不可读色块。
- **留白靠布局，不靠删信息**：不得为了留白美学删减、弱化或省略源海报的必需信息。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。
- **避免**：复杂背景、信息堆积、随机小图标、廉价卡通感、儿童手帐感、3D 质感、机械居中和模板化排版。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界。
- `palettes.md`：2–5 色提取规则与上色方式。
- `prompt-templates.md`：主模板 + 纯视觉底图模板 + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `doodle-marker-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的主模板，把源海报文字**逐条填进**模板。
3. 出图后按自检表核对：留白面积、主体占比与偏心、线条抖动断续、配色是否收敛到 2–5 色、**文字/价格/二维码是否完整保留**。
4. 要文字零误差就用两层流程：出纯视觉底图 → 排版叠回原文字与二维码。
