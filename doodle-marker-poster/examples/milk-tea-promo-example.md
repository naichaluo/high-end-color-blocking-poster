# 示例：移动「请你喝奶茶」促销海报 → 涂鸦马克笔手绘风

## Brief

- 源海报：中国移动云南公司促销海报「移动请你喝奶茶」（1060×1440 竖版）
- 需求：重绘成**手绘涂鸦 / 稚拙插画 / 马克笔手绘**风，**保留全部文字与商业信息**，**保留原图尺寸比例**

## Locked（必须保留）

| 项 | 内容 |
|---|---|
| 品牌 | 中国移动 China Mobile logo 与字样 |
| 主标题 | 移动请你喝奶茶 |
| 副标题 | 每月 20 元奶茶券 · 精致好物随心兑 |
| 优惠条 | 15 元/月 + 15GB + 20 元饮品券 |
| 徽章 | 精选好饮 随心兑换 |
| 产品标签 | 山野酸木瓜 / 多肉葡萄 / 浅草风 / qian cao |
| 二维码 | 右下「扫码办理」二维码（位置保留，用原素材叠回） |
| 服务与法务 | 温馨提示行、服务热线 10086、中国移动云南公司普洱分公司、我们百分努力只为您10分满意 |

## Reinterpret（视觉重释）

- **重提炼**：只留两只奶茶杯 + 一颗切开的瓜 + 一串葡萄 + 老虎吉祥物；**删掉**绿植背景、光斑、装饰藤蔓、缎带上的多余花纹
- **线条**：松弛抖动、断续的手绘轮廓；杯身用重复描的弧线，边缘故意不闭合
- **上色**：马克笔/蜡笔般平涂，色块边缘略溢出，杯口留一点没涂满的手工感
- **造型**：杯子略歪、瓜切面夸张放大、葡萄画成一串圆点符号、老虎简化为圆头+条纹
- **构图**：主体整体**偏左上方**、占中等视觉面积；**下半部分留出大面积暖白**，让优惠数字与二维码落在留白里
- **图文关系**：主标题沿杯子左上轮廓倾斜排布；副标题在留白里横向手写；优惠数字作为"图形化的字"与杯子错位呼应；二维码贴右下角、略越出主体群的范围
- **主体配色**：**忠实保留原图**——橙汁杯的暖橙黄、葡萄杯的紫、哈密瓜的橙、葡萄的紫黑、老虎的橙黄加黑条纹、品牌绿，一律按原色相保留
- **背景配色**：收敛到少量色——大面积暖白场 + 草绿（品牌）点缀 + 深褐色手绘线

## 文字处理

- 首选**两层流程**：先出「纯视觉底图」（文字区留成干净浅色空区），再把原海报的标题、优惠数字、二维码、服务信息**精确叠回**。
- 若直接让模型渲染：提示词里**逐字引用**全部文案与数字（含 `15`、`15GB`、`20`、`10086`），出图后逐项核对。
- **不新增标题**：源海报原有标题「移动请你喝奶茶」就是本构图的标题元素。
