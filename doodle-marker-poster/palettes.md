# 涂鸦马克笔 · Palettes

**主体色准优先**：主体的色彩必须保留源海报的主要色彩信息（产品、包装、品牌色、核心人物的实际颜色忠实保留）。
**背景与次要装饰**才做 2–5 色收敛，并以大面积浅色场保持高级感与统一性。

## 色盘构成

| 角色 | 说明 |
|---|---|
| 主体色 | **忠实取源海报主体的实际颜色**（产品色、包装色、品牌色、核心人物色），逐项保留，不做风格化偏色 |
| 背景/留白场 | 暖白、米白、浅奶油、浅灰米——占画面**最大面积**，是留白与高级感的来源 |
| 次要装饰色（1–2 种） | 从源海报提取的次要色，用于背景元素、装饰笔触、次要符号 |
| 深色线 | 炭灰、深褐、深墨蓝——手绘线条与少量文字 |
| 点缀色（≤1 种） | 高饱和小面积色（朱橙、柠檬黄、草绿等），只做点睛 |

**收敛原则：背景与次要装饰控制在 2–5 种彩色 + 浅色场 + 深色线；主体颜色按源海报实际需要保留，不受该上限约束。**

## 用色规则

- **主体忠实原色**：产品、包装、品牌色、核心人物的实际颜色**逐项保留**——不改色相、不换色系、不做风格化偏色（不把品牌绿调成灰绿、不把产品红调成粉），明度关系也随原图。
- **收敛只作用于背景与次要元素**：留白场、背景、装饰笔触、次要符号才做 2–5 色收敛与降低纯度。
- **柔和、明快、清爽、治愈**：指的是**整体气质与背景处理**，鲜活但不过饱和；主体色准优先于气质。
- **大面积浅色背景**保持整体高级感与统一性；彩色面积由源海报本身决定，不为"收敛"而削主体。
- 上色方式：**马克笔、蜡笔、油画棒般的自然平涂**——色块边缘略有溢出或没涂满，保留手工误差；**不做精细渐变**。这是**材质变化**，不是**色相变化**。
- 颜色归属追随源海报：源海报里是什么色，就归到对应形上。
- **文字承载区**：保持大面积浅色低细节，保证叠加的精确文字有足够对比；深色文字用深色线色。
