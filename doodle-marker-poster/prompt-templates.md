# 涂鸦马克笔 · Prompt Templates

把方括号内容替换成当前源海报的事实。**源海报是唯一内容源**，不需要风格参考图。

## 现有海报 → 涂鸦马克笔手绘风（主模板）

```text
把提供的源海报重绘成「手绘涂鸦 / 稚拙插画 / 马克笔手绘」风海报，Image 1 是唯一内容与视觉参考。

【画布】保留源海报的原始尺寸与宽高比（不要改成正方形，不要裁切版式）。

【商业内容必须完整保留】务必保留源海报的全部商业内容与文案：品牌 logo 与字样、主标题、
全部副标题与卖点、价格与券额数字、日期、电话、URL、二维码及其位置、底部服务与法务信息、
以及所有产品/规格标签文字。逐字列出：[把源海报上的文字逐条填在这里]。
所有文字必须清晰准确、可读、位置可重新排布但不得改变字形含义，数字一个都不能改。
不得把文字或 logo 化成不可读色块，不得新增、编造或改写任何文案。

【风格锁定】Hand-drawn Doodle Lifestyle Illustration / Naive Illustration / Marker Drawing：
- 线条：松弛、略带抖动和断续感的手绘线条；线条有轻重变化与手工误差，可重复描、可断开。
- 上色：马克笔、蜡笔、油画棒般的自然平涂；色块边缘略有溢出或没涂满，保留手工误差，不做精细渐变。
- 造型：简化、符号化、略带夸张；主体一眼可辨；不追求写实比例、复杂透视和精细描绘。
- 重新提炼源海报中最具识别性的主体、轮廓、动作、结构与叙事关系；删去大部分无关背景和细节。
- 构图：下半部分以大面积暖白或浅色留白为核心；主体只占较小到适中的视觉面积；
  主体可偏心、贴边、悬置、裁切或局部越界；通过尺度变化、错位和不对称关系建立节奏与呼吸感。
- 文字与图形作为同一构图系统设计：文字用轻巧自然的手写字或简洁编辑字体，
  可沿主体轮廓、动作方向或留白区域排布；避免机械居中和上下堆叠。
- 配色（重要）：**主体**（产品、包装、品牌色、核心人物）的**实际颜色必须忠实保留源海报的主要色彩信息**——
  不改色相、不换色系、不做风格化偏色，明度关系也随原图。
  **背景与次要装饰**才做 2-5 色收敛；整体柔和、明快、清爽、治愈，鲜活但不过饱和，
  以大面积浅色背景保持高级感和统一性。
- 整体追求：稚拙手绘 × 成熟构图 × 大量留白 × 聪明图文关系 × 独立出版物气质。

【信息层级】保留源海报的信息顺序与层级关系（品牌/标题 → 主体场景 → 卖点/优惠 → QR/行动区 →
服务/法务），但允许按本风格的松弛不对称构图重新排布。不得为了"留白美学"删减、弱化或省略
源海报的必需信息——留白是靠布局腾出来的，不是靠删信息换来的。

【约束】不要混入其他项目或其他参考图的内容；不要改变价格、券额、套餐值、电话号码、二维码、
品牌名与活动口径。
避免：复杂背景、信息堆积、随机小图标、廉价卡通感、儿童手帐感、3D 质感、机械居中和模板化排版、
把文字变成色块、改成正方形。
```

松弛抖动断续的手绘线条 + 马克笔/蜡笔/油画棒般的手工平涂；造型简化符号化略带夸张，主体一眼可辨。

背景与次要装饰收敛到 2-5 种源海报色；整体柔和明快清爽治愈，不过饱和。
保留源海报原始尺寸与比例。把所有文字区域留成干净、低细节的浅色空区，不写任何文字。
为标题、卖点条、优惠区、二维码区、底部服务条各留出干净区域。

## 出图前自检

| 检查 | 期望 |
|---|---|
| 画布尺寸 | **保留源海报原始尺寸与比例** |
| 留白 | 大面积暖白/浅色场，下半部分尤其明显 |
| 主体视觉面积 | 较小到适中；偏心/贴边/悬置/裁切/局部越界 |
| 节奏 | 由尺度变化、错位、不对称建立，非机械居中 |
| 线条 | 松弛、抖动、断续，有轻重与手工误差 |
| 上色 | 马克笔/蜡笔/油画棒平涂，略有溢出或没涂满，无精细渐变 |
| 造型 | 简化、符号化、略夸张，但**一眼可辨** |
| 主体色彩 | **忠实保留源海报主要色彩信息**（产品色/包装色/品牌色/人物色，不改色相，明度随原图） |
| 背景配色 | 背景与次要装饰收敛到 2–5 种源海报色 + 浅色场 + 深色线；柔和明快不过饱和 |
| 图文关系 | 文字与图形同一构图系统；沿轮廓/动作方向/留白排布；不机械居中、不上下堆叠 |
| 信息层级 | 品牌/标题 → 主体 → 卖点/优惠 → QR → 服务条，顺序保留 |
| 文字 | **全部逐字保留、可读**；未新增或编造文案 |
| 价格/券额/日期/电话/URL | 逐字一致，未删改 |
| 二维码 | 位置保留，可用原素材叠回 |
| 品牌色 | 保留可识别 |
| 风格排除 | 无复杂背景、信息堆积、随机小图标、廉价卡通、儿童手帐、3D、模板化排版 |
| 污染检查 | 未混入其他项目品牌/文案/额度 |
