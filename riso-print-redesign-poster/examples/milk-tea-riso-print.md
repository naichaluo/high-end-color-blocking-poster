# 示例：奶茶卖点海报 → RISO 丝网印刷几何重绘风

## Brief

- 产品：某奶茶（低温鲜奶 + 当季水果）
- 卖点：新鲜、自然、轻负担、好心情
- 品牌色：奶油白 + 薄荷绿 + 蜜桃粉
- 类型：竖版促销海报
- 需求：把普通奶茶海报重绘成 RISO 丝网印刷几何风，保留原有文案与信息层级

## Locked (保留)

- 品牌名 / 文案 / 价格 / 优惠额度 / 图标 / 底部服务与法务信息
- 原有信息层级：顶部标题 → 中部奶茶场景 → 下方优惠模块 → 底部服务条

## Reinterpret (重释)

- 材料：RISO 丝网印刷，硬边轮廓抖动、套准纸缝、局部半色调
- 场景：奶茶杯转成几何色块质量，构成一个视觉锚点；旁边一个来源于源图的次要"印章"模块，如一片叶子或一个杯盖
- 配色：薄荷绿（主墨）+ 蜜桃 + 奶油，中性自然白纸，黑为次要
- 构图：保留源信息层级，但用几何质量重新组织，留出干净墨区给标题与文字

## Palette (Fresh Green And Peach)

- 纸张：中性自然白
- 墨色：叶绿（主）/ 蜜桃 / 奶油
- 次要：深绿，极少黑
- 细节：干净大色块、套准偏移、稀疏半色调点缀

## Verdict

RISO 风只改变视觉语言——信息层级、文案、Logo、二维码、价格全部按源海报锁定，文字用精确叠加层处理，绝不让模型去重画商业文字。
