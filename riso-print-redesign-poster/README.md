# RISO Print Redesign Poster

把普通海报/产品描述/营销主视觉，重绘成 **Rustfield 式 RISO 丝网印刷几何重绘**风格的广告：硬边印刷轮廓、2-3 色油墨、套准纸缝、几何质量转换、中性白纸。

这是一个**独立** Skill，不与 `ghibli-animation-poster`、`crayon-scribble-poster`、`monument-valley-poster`、`plush-animation-poster`、`clay-animation-poster`、`torn-paper-relief-poster`、`paper-collage-poster`、`high-end-color-blocking-poster` 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度。源海报只提供商业事实，本 skill 只涂 RISO 印刷视觉处理。
- **两层流程**：视觉层（几何墨色块、产品图形构造、印章模块、装饰记号）与受控层（精确标题/价格/品牌/二维码/服务条款）分开；文字、logo、QR 用原素材叠加，不交给图像模型乱造。
- **风格**：RISO 丝网印刷——硬边印刷轮廓 + 2-3 色油墨 + 套准纸缝 + 局部半色调 + 中性自然白纸 + 黑色次要。不是水彩、蜡笔、craft 拼贴或通用颗粒滤镜。
- **两档强度**：`标准 RISO`（默认，干净编辑感）/ `加强 RISO`（更强的轮廓抖动、套准纸缝与油墨质感，更利落的几何块面）。说"加强/更strong/更浓"就切到加强档。
- **构图**：保留源海报信息顺序和主布局逻辑，用几何质量重新组织，留出干净墨区给标题与文字。

## 配套文件

- `SKILL.md`: 核心规则、触发条件、工作流、质量门、污染检查、边界、两档风格定义。
- `palettes.md`: RISO 油墨配色与材质处理。
- `prompt-templates.md`: 可复用提示词模板（风格迁移 / 纯视觉底图 / 从文案新做 / 加强档变体 / 校验清单）。
- `examples/`: 示例需求与提示词应用。

## 使用说明

### 一、触发方式（什么时候用这个 skill）

- 让 DSH 自动识别：说「RISO风海报」「丝网印刷海报」「risograph」「套色印刷」「油墨双色」「几何图形重绘」「把普通海报改成 RISO 丝网印刷风」。
- 或在 DSH 里点名：加载 `riso-print-redesign-poster` 后再给需求。

> 不要用这个 skill 处理：普通纯配色、水彩、蜡笔、毛绒、黏土、纸艺、照片写实等不相关的海报需求。

### 二、两档风格怎么选（重点）

skill 默认走**标准 RISO**。想要更强的印刷感就切**加强 RISO**。触发词对照：

| 档位 | 触发词 | 效果 | 对应你满意的版本 |
|---|---|---|---|
| **标准 RISO**（默认） | 说「RISO风」「丝网印刷」即可 | 干净编辑感：平衡轮廓抖动、清晰套准纸缝、少量半色调点缀 | 第一版 |
| **加强 RISO** | 加「加强」「更浓」「更strong」「更硬朗」 | 更强：轮廓抖动更硬、套准纸缝/露纸更明显、油墨半色调与缺墨擦痕更主动、几何更利落 | 加强版 |

> 只要在需求里带上"加强/更浓/更strong"这类词，就自动切到加强档；不提就按标准档。

### 三、出图步骤（图生图编辑）

1. 先用 `skill` 工具加载 `riso-print-redesign-poster`。
2. 以原海报作参考图（`image` 参数，本地路径会自动转 data URI）。
3. 提示词按 `prompt-templates.md` 的"Existing Poster To RISO Print Redesign"模板，替换成你的文案；要加强就在 Style/medium 行换成 **Boosted RISO Variant**。
4. 出图后核对文字（尤其书法大字和底部小字）。

### 四、文字怎么处理（重要）

- **首选（零误差）**：走**两层流程**——先生成"去文字的纯 RISO 视觉底图"，再用排版工具把你的原始标题/logo/二维码/服务条款精确叠回。这样商业文字绝不交给图像模型乱造。
- **次选（省事，但需核对）**：直接在提示词里逐字引用文案，让模型保留；但书法大字、小字可能有个别偏差，出图后必须人工核对。

### 五、已验证记录

- 用 Seedream 5.0 Pro，1024×1536，无 AI 水印，图生图编辑。

## 快速上手的四句话

1. 先 `skill` 加载 `riso-print-redesign-poster`。
2. 以原海报为参考图（`image`），提示词写「保留主体+全部文字，只改材质为 RISO 丝网印刷」；想更强就加"加强"。
3. 出图后核对文字。
4. 要零误差就用两层流程：纯 RISO 视觉底图 + 排版叠回原文字。
