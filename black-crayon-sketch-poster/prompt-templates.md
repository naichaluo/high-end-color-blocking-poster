# 黑白蜡笔速写海报 · Prompt Templates

把方括号内容替换成当前源海报的事实。**源海报是唯一内容源**，不需要风格参考图。

## 主模板：现有海报 → 整幅黑白蜡笔速写

```text
把提供的源海报重绘成「整幅黑白蜡笔速写」风海报，Image 1 是唯一内容与视觉参考。

【画布】严格保留源海报的原始尺寸与宽高比（竖版保持竖版、横版保持横版，不要改成正方形，不要裁切版式）。

【整幅统一（最重要）】画面从四边到中心全部是同一张暖白/米白粗纹纸上的同一种纯黑蜡笔速写：
不保留任何原照片区域、不要照片带、不要彩色照片贴片、不要分栏或拼接、不要"一图两画法"、
不要相框式分隔线。整张画只有一种材质、一种笔触、一种造型语言。

【依据】以提供的源海报为唯一依据，提炼最具辨识度的人物/动物/物体、姿势、互动和故事关系，
转译为极简手绘插画。源海报里复杂的环境不要逐物复制。

【底材】暖白或米白粗纹纸，纸面颗粒必须可见，带轻微纸张纤维。

【造型】主体以圆润、厚重、略笨拙的轮廓表现，保持一眼可辨；多人/多物场景只保留最重要的互动与关系，
不逐物复制复杂环境。

【笔触】主要使用纯黑蜡笔、炭笔、干刷、摩擦与反复叠加笔触。
黑色形体必须呈现纸张颗粒、断裂边缘、浓淡不均、自然留白、轻微抖动与人工不完美感。
禁止平滑矢量填充、渐变、3D、写实阴影和大面积灰色水洗。

【白色负空间】大块黑色内部大胆使用白色负空间表现脸部、眼睛、口鼻、窗户、开口或关键特征；
面部仅用少量黑点和短线提示，不做写实肖像。负空间是掏出来的纸白，不是画的白色。

【亮色点睛】加入极少量亮色点睛笔触，面积严格控制在 5% 以内，只用于强化视觉焦点、动作方向或情绪。
亮色优先提取源海报中的代表色、高光色、服装色或环境强调色；若原图缺少合适颜色，
可使用互补色、冷暖对比色或高辨识度强调色。颜色以蜡笔、粉彩或粗糙手绘线条出现，
不做平滑色块，不喧宾夺主；原则上只用 1 种主亮色，最多 2 种。

【构图与留白】保持极简、克制与大量负空间，只突出一个核心动作、人物关系或故事，主体居中或略偏侧。
环境最多保留地面线、草地、雨、烟、道路、风、阴影等少量粗糙符号，不要重建完整场景。

【排版文字位（形式保留，内容必须来自源海报）】
沿负空间、地面线或动作方向自然融入 1 个简短英文标题位，以及 1–2 句极小英文辅助文字，
采用克制编辑字体结合笨拙手写或蜡笔字体，可轻微与插画重叠，但不能遮挡主体。
标题位与辅助文字的排版形式必须保留，但文字内容只能取自源海报自身：标题、主体名（可用其英文译名）、
或源海报已有的副标题/卖点短句。不得编造新的作品名、品牌名、价格或承诺；
不得加入 "prompt by awen" 之类署名；不得替代或遮挡源海报的商业文案。
若源海报没有英文，标题位可保留为排版留白/占位。
待填入内容：[把源海报的标题、主体名、已有副标题/卖点逐条填在这里]

【商业内容必须完整保留】务必保留源海报的全部商业内容与文案：品牌 logo 与字样、主标题、
全部副标题与卖点、价格与券额数字、日期、电话、URL、二维码及其位置、底部服务与法务信息、
以及所有产品/规格标签文字。逐字列出：[把源海报上的文字逐条填在这里]。
所有文字必须清晰准确、可读，数字一个都不能改。不得把文字或 logo 化为不可读色块。
不要新增、编造或改写任何文案。文字区域保持干净、低细节的暖白纸面，供后期精确叠回。

【功能性资产保护】二维码/条码/logo 必须保持完整、可识别、可扫描：二维码保持完整清晰可扫描，
不要用蜡笔或炭笔覆盖、不要用白色负空间掏空、不要压暗、不要错位歪斜。

【信息层级】保留源海报的信息顺序与层级关系（品牌/标题 → 主体场景 → 卖点/优惠 → QR/行动区 →
服务/法务）。不得为了留白美学删减、弱化或省略任何必需信息。

【最终气质】像"旧时代黑白儿童绘本被当代高端设计工作室重新出版"：安静、温暖、略幽默、略孤独，
有儿童般稚拙与成熟编辑感，介于独立杂志、旧式绘本与黑白蜡笔速写之间。

【约束】不要混入其他项目或其他参考图的内容；不要改变价格、券额、套餐值、电话号码、二维码、品牌名与活动口径。
避免：彩色蜡笔涂抹感、平滑数字绘画、3D、过饱和、塑料光泽、信息堆积、随机装饰堆砌、机械置中的模板化排版、
把文字变成色块、改成正方形、任何照片残留、任何非速写的分区或分栏。
```

## ⚠️ 已知失效模式：提示词「描述版面」会盖掉参考图（务必先读）

**症状**：风格完全正确（整幅蜡笔速写很漂亮），但**内容整张被换掉**——品牌、价格、日期、活动名全是模型自己编的，源海报的信息一个字都没保留。表现是模型「帮你想」了一张合理的同类海报：例如源图是中国移动「15 元／月享 15GB＋20 元饮品券」，出图却变成某咖啡联名「9.9 元／杯、券后低至 5 元、活动时间 2025.04.20–05.20」。

**成因**：提示词里**用文字描述了画面内容与版面**（例如「上方横幅区、中央的奶茶杯与珍珠、下方活动信息区，横幅上的品牌文案……」）。文字描述一旦足够具体，模型就**优先按文字从零生成**，把参考图降级为「风格／氛围参考」，内容锁定随之失效。**提示词越长、越像一份版面说明书，风险越高。**

**正确做法**：

1. **只描述风格，不描述内容。** 内容一律靠锁定句：「严格以参考图为唯一内容来源；构图、版式、位置、层级、产品、人物、装饰元素全部与参考图完全一致；不新增、不删减、不移动、不改动任何元素。」
2. **第一句就写「只改变绘画风格，不改变任何内容。」** 让模型先建立「这是编辑任务，不是创作任务」的前提。
3. 【商业内容必须完整保留】一段**必须逐字列出源海报的全部文字**。逐字列出＝给模型一份抄写清单；「横幅文案」「底部小字」这类描述性说法＝给它一份创作许可。
4. 不要替模型归纳画面元素（不要写「杯子和珍珠」「人物和背景」），**直接指向参考图**。
5. **出图后逐字对照源海报核验**：品牌名、价格、券额、日期、活动名、电话、法务文案。**风格对了但内容错了是最危险的失败**——图好看，极易被当成成功直接交付。

> 实测：同一张源海报，一份约 700 字的「版面说明书」式提示词产出了整张编造的新海报；换成约 440 字的**纯风格＋内容锁定**提示词后，内容与原图逐字一致、整幅蜡笔风格也正确。**本 skill 的主模板已按此原则写，请勿往【依据】段里添画面描述。**
