# 黑白蜡笔速写海报 · Palettes

**整个画面以黑白为主体，而且是同一种画法**：一张**暖白 / 米白粗纹纸**上，从头到尾由**纯黑蜡笔、炭笔、干刷、摩擦与反复叠加**构成，**没有照片区、没有分栏、没有第二种视觉语言**。**亮色只做点睛，≤5%**。

## 色盘

| 色 | 角色 | 说明 |
|---|---|---|
| 暖白 | 底纸 | 粗纹纸基色，画面**最大面积**；大量负空间就是它 |
| 米白 / 奶油白 | 底纸（备选） | 比暖白略黄一点，更像旧绘本用纸 |
| 纯黑 | 速写主色 | 蜡笔 / 炭笔的**唯一**主体色，浓淡靠**叠加与压力**而非灰阶填充 |
| 纸本灰 | 明暗过渡 | **只能**由黑色笔触的稀疏、摩擦、纸面颗粒自然带出，**不可**用灰色水洗 / 渐变 / 喷枪 |
| 纸白（掏白） | 负空间 | 黑块**内部**的脸部、眼睛、口鼻、窗户、开口——是"从黑里掏出来"的纸白 |
| 亮色点睛 | 焦点 | **≤5% 面积**，1 种主亮色（最多 2 种） |

> 注意：**没有"照片本色"这一行**。源海报的色彩信息只用于**挑选点睛亮色**与**判断明暗关系**，不作为画面中要保留的彩色区域。整幅画是黑白的。

## 亮色点睛规则（严格）

- **面积 ≤ 5%**，只在**一两个**位置出现，绝不成片、绝不铺底。
- **优先级**：源海报中的**代表色 → 高光色 → 服装色 → 环境强调色**。
- 若原图缺少合适颜色：用**互补色、冷暖对比**或**高辨识度强调色**（如正红、橙黄、钴蓝、正绿）。
- **形态**：以**蜡笔、粉彩、粗糙手绘线条**出现——**不做平滑色块**，不做矢量填充，不做均匀平涂。
- **数量**：原则上**1 种主亮色**，必要时**最多 2 种**。
- **用途**：只用于**强化视觉焦点、动作方向或情绪**，不用于填充物体、不做背景、不喧宾夺主。
- **不得**用来"抢救"画面对比度：主体必须靠**黑白本身**成立，亮色拿掉后画面依然完整。

## 纸张与笔触材质

- **底纸**：暖白或米白**粗纹纸**（rough tooth paper），**纸面颗粒必须可见**，带轻微纸张纤维与自然不均匀感。
- **黑色笔触**：纯黑蜡笔、炭笔、干刷、摩擦、**反复叠加**。
- **黑色形体必须具备**：纸张颗粒感、**断裂边缘**、浓淡不均、**自然留白**、轻微抖动、**人工不完美感**。
- **亮部处理**：靠**留出纸白**，不靠白色颜料覆盖；黑块内部的白是**掏出的负空间**，不是画的白色。
- **禁止**：平滑矢量填充、渐变、3D、写实阴影、**大面积灰色水洗**。

## 笔触配方（按部位选择）

| 部位 | 建议笔触 |
|---|---|
| 主体大块暗部 | 蜡笔侧锋**反复叠加** + 干刷摩擦，保留纸纹断裂与不均 |
| 主体轮廓 | 略笨拙的**粗黑蜡笔线**，允许抖动、断裂、粗细突变 |
| 关键特征（脸/眼/口鼻/窗/开口） | **掏白负空间**为主，配**少量黑点与短线**提示 |
| 地面线 / 草地 / 雨 / 烟 / 道路 / 风 / 阴影 | 一条或几条**粗糙符号**，一两笔即止，不铺陈 |
| 点睛亮色 | 蜡笔 / 粉彩一笔或几笔，边缘粗糙、覆盖不匀 |
| 环境背景 | **不画**或只留纸白，靠留白承担 |

## 文字承载区

- 文字区保持**干净、低细节的暖白纸面**，保证叠加的精确文字有足够对比。
- 不要把文字压在黑色笔触密集处；不要用亮色点睛色作为文字底色。
- 排版位（英文标题位、极小辅助文字位）按「Text and brand handling」留出空间，**内容必须取自源海报自身**。
