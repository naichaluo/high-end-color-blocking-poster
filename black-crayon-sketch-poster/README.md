# 黑白蜡笔速写海报 · README

把普通海报 / 产品描述 / 营销主视觉，重绘成**整幅统一的纯黑白蜡笔速写海报**。

**最终效果**：像「**旧时代黑白儿童绘本被当代高端设计工作室重新出版**」——**整幅画面**都画在**暖白/米白粗纹纸**上，全部是**纯黑蜡笔 / 炭笔、干刷、摩擦与反复叠加**的笔触：圆润笨拙的轮廓、大块黑内部用**纸白负空间**掏出五官与开口、**≤5% 的亮色点睛**、沿负空间自然融入的**极简英文编辑字体**。安静、温暖、略幽默、略孤独。

**🅰 核心原则：只改变视觉语言，不改变商业内容——源海报的文字、价格、券额、二维码、品牌一律保留。**

**不需要风格参考图。源海报是唯一内容源。**

这是一个**独立** Skill。**特别注意：本 skill 与 `crayon-scribble-poster`（彩色蜡笔涂抹）完全不同**——本 skill 是**纯黑白**蜡笔/炭笔速写、靠**负空间刻形**、气质是**旧绘本被高端设计工作室再版**的编辑感；`crayon-scribble-poster` 是**彩色**蜡质涂抹、颜色是主角、气质活泼童趣。也不与 `doodle-marker-poster`（涂鸦马克笔）、`observational-pen-wash`（钢笔淡彩）或任何其他海报 skill 合并规则，除非用户明确要求组合风格。

## 关键点

- **内容严格保留**：锁住源海报的产品名、卖点、价格、日期、URL、二维码、法务文案、品牌色与用户给定措辞。
- **画布**：保留源海报**原始尺寸与宽高比**（不改正方形、不裁切版式）。
- **整幅统一（最重要）**：画面**从头到尾**都是同一张粗纹纸上的同一种纯黑蜡笔笔触——**不分区、不分栏、不拼接、不保留任何原照片区域**，不存在"一图两画法"。
- **一个主体**：只保留**一个**视觉主体与**一个**核心动作 / 关系 / 故事；主体居中或略偏侧，避免机械置中。
- **底纸**：**暖白/米白粗纹纸**，纸面颗粒可见，带轻微纸张纤维；纸张本色就是画面最大面积。
- **造型**：轮廓**圆润、厚重、略笨拙**且一眼可辨；多人 / 多物场景**只保留最重要的互动与关系**，不逐物复制复杂环境。
- **笔触**：纯黑蜡笔、炭笔、干刷、摩擦、**反复叠加**；黑色形体必须有**纸张颗粒、断裂边缘、浓淡不均、自然留白、轻微抖动、人工不完美感**。**禁止**平滑矢量填充、渐变、3D、写实阴影、**大面积灰色水洗**。
- **白色负空间（本风格的签名特征）**：大块黑**内部**用纸白表现**脸部、眼睛、口鼻、窗户、开口**；面部只用**少量黑点和短线**，**不做写实肖像**。
- **亮色点睛**：**≤5% 面积**，只用 **1 种主亮色（最多 2 种）**，优先取自源海报的代表色/高光色/服装色/环境强调色；以**蜡笔、粉彩或粗糙手绘线条**出现，**不做平滑色块**，不喧宾夺主；拿掉亮色画面依然成立。
- **留白与构图**：极简、克制、**大量负空间**；环境最多保留地面线、草地、雨、烟、道路、风、阴影等**少量粗糙符号**。
- **排版文字位**：画面含 **1 个简短英文标题位 + 1–2 句极小英文辅助文字**，克制编辑字体结合笨拙手写/蜡笔字体，沿负空间、地面线或动作方向融入，可轻微重叠但**不得遮挡主体**。**内容一律取自源海报自身**（标题 / 主体名 / 既有副标题或卖点短句）；**不编造**作品名、品牌名、价格或承诺；**不加 `prompt by awen` 之类署名**。
- **文字保留**：逐字保留源海报标题与全部文案（价格、券额、日期、电话、URL、法务字样）；**不新增、不编造**；**不得把文字或 logo 化为不可读色块**；精确文字走受控层，不交给蜡笔笔触。
- **功能性资产保护**：二维码 / 条码 / logo 必须**完整、可识别、可扫描**——不得被蜡笔覆盖、被白色负空间掏空、被压暗或错位；最佳做法是**原样贴回**。
- **内容隔离**：绝不借用/混入其他项目、以往对话或其他海报的品牌、文案、优惠额度，也不借用风格样例的装饰英文名。

## 配套文件

- `SKILL.md`：核心规则、触发条件、风格定义、构图、文字与品牌处理、工作流、质量门、边界（含与 `crayon-scribble-poster` 的逐项区分表）。
- `palettes.md`：黑白速写色盘、亮色点睛规则、粗纹纸与笔触材质、笔触配方、文字承载区。
- `prompt-templates.md`：整幅速写主模板 + 纯视觉底图模板 + Style preset + 出图前自检表。
- `examples/`：示例需求与应用。

## 快速上手

1. 先 `skill` 加载 `black-crayon-sketch-poster`。
2. 以源海报为参考图（`image`），用 `prompt-templates.md` 的**主模板**，把源海报的文字**逐条填进**模板的「逐字列出」与「待填入内容」两处。
3. 选定**一个**核心主体与**一个**核心动作 / 关系；把源海报里其余的人与物**大胆删掉**，环境只留少量粗糙符号。
4. 出图后按自检表核对：**整幅是否统一为蜡笔速写、有无照片残留**、粗纹纸颗粒、白色负空间五官、亮色是否 ≤5%、**文字/价格/二维码是否完整保留**。
5. 要文字零误差就用两层流程：出**纯视觉底图** → 排版叠回原文字与二维码。
