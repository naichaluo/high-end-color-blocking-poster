# 示例：[源海报标题] → 整幅黑白蜡笔速写

> 本示例演示**通用做法**。使用时把方括号内容替换成**当前源海报**的真实信息，**不要照抄任何其他项目的品牌、文案或优惠额度**。示例只填了少量占位值，实际制作时必须逐条填全。

## Brief

- 源海报：[源海报名称，例如「XX 品牌 · 秋季新品上市」促销海报]（[原始尺寸，例如 1080×1440] 竖版）
- 需求：重绘成**整幅黑白蜡笔速写**风，**整幅画面统一为蜡笔速写、不保留任何照片区域**，**保留全部文字与商业信息**，**保留原图尺寸比例**
- 核心主体（全画面唯一主角）：[例如：一位牵着孩子的年轻母亲 / 一只趴着睡觉的橘猫 / 一束浅绿洋桔梗 / 一杯奶茶]
- 核心动作 / 关系（只突出这一个）：[例如：母亲低头看孩子 / 猫把脸埋进前爪 / 花茎自然弯折]

## 转译决定（源海报 → 整幅速写）

| 项 | 内容 | 规则 |
|---|---|---|
| 唯一主体 | [源海报里最具辨识度的那一个主体] | 画面上**只有一个**视觉中心，不并列多个不相干主体 |
| 核心动作 | [一个动作 / 关系 / 故事] | 只突出**一个**；其余故事线全部舍弃 |
| 舍弃项 | [源海报里被主动删掉的次要人/物/背景，逐条列出] | 不逐物复制复杂环境 |
| 白色负空间 | [掏出哪些关键特征，例如脸部、眼睛、口鼻、窗框开口] | **纸白**负空间；面部只用少量黑点和短线，不做写实肖像 |
| 亮色点睛 | [取自源海报的哪个颜色，例如服装的砖红色] | **≤5% 面积**，只用 1 种主亮色（最多 2 种），以蜡笔/粉彩线条出现 |
| 环境符号 | [地面线 / 雨 / 风 / 阴影 中的一两项] | 一两笔即止，不重建完整场景 |
| 排版文字位 | 标题位 = [源海报标题或主体名，可用英文译名]；辅助文字 = [源海报已有的副标题/卖点] | **内容取自源海报自身**；不编造；不加署名 |

## Reinterpret（视觉重释）

- **整体**：画布**从头到尾**都是同一张粗纹纸上的同一种纯黑蜡笔笔触——**无照片区域、无分栏、无拼接、无第二种画法**
- **底纸**：暖白粗纹纸，纸面颗粒可见，轻微纸张纤维
- **造型**：主体轮廓圆润、厚重、略笨拙，一眼可辨
- **笔触**：纯黑蜡笔 + 炭笔 + 干刷 + 摩擦 + 反复叠加；断裂边缘、浓淡不均、自然留白、轻微抖动、人工不完美感
- **明暗**：只由笔触稀疏、摩擦与纸面颗粒带出；**不用**灰色水洗 / 渐变 / 喷枪
- **留白**：主体周围大块纸白；文字区留成干净低细节暖白纸面
- **排版文字位**：1 个简短英文标题位（内容取自：[填]）+ 1–2 句极小辅助文字（内容取自：[填]）；克制编辑字体 + 笨拙手写；沿负空间 / 地面线 / 动作方向融入，不遮挡主体
- **明确不做**：彩色蜡笔涂抹、平滑数字绘画、3D、大面积灰色水洗、任何照片残留、任何分区或分栏、编造英文作品名、加署名

## 文字处理

- 首选**两层流程**：先出「纯视觉底图」（所有文字区留成干净暖白纸面空区，英文标题位与辅助文字位只留空间不填字），再把原海报的标题、价格、券额、日期、电话、URL、二维码、服务信息**精确叠回**。
- 若直接让模型渲染：提示词里**逐字引用**全部文案与数字，出图后逐项核对。
- **功能性资产保护**：二维码/条码/logo 位置保留、**完整可识别可扫描**，不得被蜡笔覆盖、被白色负空间掏空、被压暗或错位；**建议用原素材叠回**。
- **不新增、不编造**任何文案；**不加署名**（如 `prompt by awen`）。
